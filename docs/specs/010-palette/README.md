# Palette

Follow the references below only as needed; never upfront.

- ./technology-icons.md - when working on Technology icons: Technology palette category: full-colour AWS / Azure / generic-infra brand icons for architecture diagrams
- ./style-presets.md - when working on Style presets: One-click Presets category: theme colour + border variations for shapes, animated line styles for arrows
- ./palette-drag-ghost.md - when working on Palette drag ghost + drop preview: Drag-to-add shows a live translucent footprint of the shape at the cursor, replacing the browser drag image
- ./palette-favourites.md - when working on Palette Favourites: The palette's default category (listed first, star icon): a 3x3 grid of the user's go-to creation tiles, defaulting to the nine shortcut-worthy ones, with a footer Edit band. Curation in an edit modal in the spirit of iOS Control Centre (search + category pills, per-row Add / Remove, applies immediately); per-browser localStorage persistence with stale-id fallback. Drives a shared palette-tile-defs catalogue that Shapes / Tools / Data / Components / Devices all render from
- ./emoji-icons.md - when working on Emoji section in the Icons tab: Native colour emoji as line-art icon-catalogue entries via a new `text` prim: an Emoji category in the Icons tab (~60 collaboration/status emoji), inheriting search, drag, fold-into-shape, favourites, thumbnails, and MCP render automatically
- ./palette-category-browse.md - when working on Browsing the palette by category: The Icons and Technology tabs browse by category tile with a breadcrumb, the same drill-in the Tools tab uses, replacing their category / provider filter dropdowns; search always runs over the whole catalogue
- ./palette-top-level-categories.md - when working on Palette top-level categories and bands: Behaviour and Data leave the Tools tab to become top-level palette categories; the category dropdown groups into Common / Structure / Decorate / Dynamic bands with Favourites full width above them; Behaviour, Data and Components render as rows with a blurb
- ./stickers.md - when working on Stickers: A Stickers category in the palette's Decorate band: ~193 colour emoji plus word badges in eleven groups (Badges, Reactions, Feelings, Status, Direction, Celebrate, Decorate, Meeting, Work, People, Fun), browsed and searched like the icon catalogues. A sticker IS an icon, so it inherits every add / drag / fold-into-shape / export path; it replaces the Emoji category that sat inside the Icons tab ([Emoji section in the Icons tab](emoji-icons.md)), ids unchanged
- ./build-category.md - when working on The Build palette category: A Common-band palette category for the five elements that HOLD other work: mind node, lane, frame, timeline, table. They were filed by what they look like and scattered across Write / Draw / Data / Components; what groups them is the moment you reach for them, which is when you are deciding how the board is arranged. Tile ids unchanged, so saved Favourites survive the move
