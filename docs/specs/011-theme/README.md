# Theme

Follow the references below only as needed; never upfront.

- ./multicolour-themes.md - when working on Multi-colour (rainbow) themes: Rainbow/palette themes that tint each hierarchy branch a hue
- ./canvas-and-theme-dialog.md - when working on Canvas + Theme dialog: Right-click Change Canvas / Change Theme open a modal with Canvas + Theme tabs (category-browse themes)
- ./custom-themes.md - when working on Custom themes: Build + save your own themes (owner-scoped, D1-backed); reuse + edit from Tab Look & Feel and the Explorer
- ./blueprints/README.md - when implementing a theme spec: the blueprints hold the engineering detail derived from it
