# Whiteboard blueprints

Follow the references below only as needed; never upfront.

- ./whiteboard-round-one.md - when implementing or changing the whiteboard kind, its dock tools, pens, eraser modes, input rules, look or backgrounds
- ./whiteboard-dock.md - when changing the dock's groups, its modes, the Shapes flyout and its search, or the shape slots (pins and frequent)
- ./text-boxes.md - when changing how a whiteboard text box hugs its text: placement, typing, commit, resize, Shift scale
- ./path-tool.md - when implementing or changing the Path tool: the path element, drawing, edit mode, rendering, style
- ./DEFAULTS.md - when a whiteboard blueprint applies a default the spec leaves open
- ./COMPLETENESS.md - when checking which completeness categories a whiteboard blueprint covers
