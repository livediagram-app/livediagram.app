# Workspace

Follow the references below only as needed; never upfront.

- ./folders.md - when working on Folders: Nested folders for diagrams in the Explorer; Unsorted default
- ./share-password.md - when working on Share password: Optional per-diagram password gating share-link view + edit access
- ./teams.md - when working on Teams: Teams with Admin/Member roles, email invites, Explorer section
- ./embeds.md - when working on Read-only embeds (`/embed`): Iframe-able `/embed` share view + Copy-embed-code in Share
- ./share-link-expiry.md - when working on Share-link expiry: Optional link lifetime (week/month/6 months); Inactive section
- ./team-shared-diagrams.md - when working on Team shared diagrams: Per-team folder tree + diagrams every joined member can manage
- ./live-image-share.md - when working on Live image share link: Share-link-scoped `<img>`-able SVG at `/api/share/<code>/image.svg`, served from the snapshot cache ([Diagram SVG snapshots](../006-diagram/diagram-snapshots.md))
- ./hide-from-recent.md - when working on Hide a diagram from Recent: Per-user "Hide from Recent" / "Show in Recent" on the diagram menu in both Explorer surfaces; stored as capped `recentExcludedIds` in the synced preferences blob ([User preferences](../007-editor/user-preferences.md)), filtered before the cap in both Recent lists and in the sidebar badge count; no badge elsewhere
- ./recent-folder-chip.md - when working on Folder location on Recent rows: Each Explorer > Recent row/card names the folder it lives in and links to it (immediate parent only; `Unsorted` for unfiled, team name for team rows, none for shared-with-you); a quiet link rather than a status badge, Explorer page only
- ./favourites.md - when working on Favourite diagrams: Per-user diagram stars in their own D1 table (unlimited, unlike the 4 KB preferences blob), a Favourite/Unfavourite toggle in both diagram menus, and a Favourites view under Personal Space > Dynamic aggregating personal + team stars with the [Folder location on Recent rows](recent-folder-chip.md) source chip
- ./folder-content-previews.md - when working on Folder content previews: A folder card in the Explorer card grid previews what's inside: a centred 2x2 mosaic of up to four sheets (diagram snapshots first, then subfolder glyphs, with a `+N` tile for the overflow) instead of one generic folder icon; reuses the [Diagram SVG snapshots](../006-diagram/diagram-snapshots.md) cached thumbnails and the client-side folder indexes, so no new fetch. Card grid only — the list view keeps its count badge
- ./timeline.md - when working on Timeline: The Explorer's new landing page: a day-grouped feed of everything that happened across your diagrams, teams and account, with same-day stacking and an optional calendar month grid. A `timeline_events` + `timeline_event_scopes` pair emitted inline on the api worker's write paths (one event, many recipients), scope-typed so a per-diagram or per-team feed is later a new scope value, not a migration. Editing coalesces to one event per person per diagram per day. Guests included, and their history migrates on sign-up. Also moves Favourites from Personal Space › Dynamic up into Quick find
- ./activity-page.md - when working on Activity page: New Explorer section at `/explorer/activity`: every open action assigned to you or by you and every unresolved comment thread you are in, across all diagrams you can open, each row opening the editor at the element with its popover ready. Backed by a collaboration index (`collab_actions` / `collab_threads`) written in the same D1 batch as every tab write, `owner_aliases` so guest-era identities survive sign-up, and a lazy per-owner backfill. Sidebar badge counts open actions assigned to you.
