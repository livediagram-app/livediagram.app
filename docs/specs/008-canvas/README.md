# Canvas

Follow the references below only as needed; never upfront.

- ./canvas-and-palette.md - when working on Canvas and palette: The canvas and its floating palette: canvas tools, every element kind, drawing, rich-text labels
- ./isometric-view.md - when working on Isometric view: Navigation tool that tilts the tab into an isometric, extruded-depth view; pans like Hand, read-only
- ./layout-cleanup.md - when working on Layout cleanup: The tab menu's Cleanup band: Auto-align (grid snap) + Auto Layout (deterministic graph layout / Tidy up)
- ./arrow-to-arrow.md - when working on Arrow-to-arrow connections: Snap an arrow endpoint to evenly-spaced points along another arrow's line (sequence-diagram messages)
- ./minimap.md - when working on Minimap: Bottom-left zoomed-out overview + viewport rect; tap/drag to navigate. Desktop, when Activity panel closed
- ./snap-override.md - when working on Snap override (free drag): Hold Cmd/Ctrl while dragging to disable alignment snapping + guides for a free, off-grid placement
- ./arrow-collision-avoidance.md - when working on Arrow collision avoidance at draw time: Freshly drawn arrows get a one-shot gentle curve when the straight line would cross (or graze) an unrelated element, or run flush along the boxes it connects. Applied at the end of the draw gesture as an ordinary curved arrow (`curveOffset`), adjustable or straightenable with the existing handles; repositioning, imports, and auto layout never trigger it
- ./shift-drag-duplicate.md - when working on Shift-drag duplicate: Holding Shift while move-dragging a selection duplicates it on release: the dragged elements stay at the drop point and clones re-fill the origin, one undo step, via the same duplicate machinery as the toolbar action. Move drags only (resize keeps Shift as aspect constraint)
- ./highlighter.md - when working on Highlighter: Wide semi-transparent marker, HELD from the tool dropdown's Edit group (the one tool there that works on an empty canvas): a FreehandElement with `pen: 'highlighter'` (multiply blend, marker yellow), no shape recognition, no close-to-fill; Colour + Strength in the dockable Highlighter Panel; Mode Button tile hands it to a room
- ./polygon-tool.md - when working on Multi-point line / polygon tool: Click-to-place vertex tool committing a FreehandElement with `straightEdges` (no Catmull-Rom smoothing): click near start closes + fills, double-click/Enter finishes open, Backspace removes last vertex, Escape cancels
- ./element-shadows.md - when working on Element shadows: A Shadow category in the element style menu (shapes / stickies / images / link cards): preset tiles (None / Soft / Drop / Lifted / Hard) with hover preview + Offset X/Y, Blur, Opacity sliders on the debounced one-undo-step policy; fixed ink colour, numeric `shadow` field, box-shadow or drop-shadow() per wrapper transparency, feDropShadow defs for export parity, copied by the format painter
- ./arrow-route-behind.md - when working on Arrows pass behind intervening boxes: Arrows break around unrelated boxes they cross (default on, `routeBehind: false` opts out): an SVG mask punches margin-inflated holes per crossed box, frames/text/endpoint-owners never cut, hit band stays unmasked, per-arrow toggle in the Line section
- ./avatar-mode.md - when working on Avatar mode: A canvas tool (shortcut `W`) that drops a Habbo-style walking pixel character into the diagram: click / tap to walk, arrow keys steer, Space hops with a waved flag, right-click on the character toggles male / female, the shirt takes your participant colour, the camera follows near the edges, and the element it stands on gets a "you are here" ring. The canvas is read-only while active (pointer-inert layer + suppressed mutating shortcuts) and picking a palette tile leaves the mode; the character broadcasts as an ephemeral `avatar` presence op so everyone in the room sees everyone walking
- ./laser-panel.md - when working on Laser Panel: While the Laser tool is active, a panel of pen settings — width, colour, trail length, and effect (beam / glow / comet / spark) — over a live preview stroke. The Avatar Panel's twin: same width, same corner, same mobile dock button, present only while its mode is. The pen rides each laser sample so peers see it, and persists per device
- ./spotlight-panel.md - when working on Spotlight Panel: While the Spotlight tool is active, a panel for the light: size, how dark the shroud goes (up to Blackout, for projectors), a soft or crisp edge, and a circle or wide ellipse for lighting a lane. Over a live preview of the shroud. Persists per device; the radius stays session state because clicking the canvas changes it. Local-only, and the panel says so
- ./eraser-panel.md - when working on Eraser Panel: While the Eraser is active, a panel for the brush: Sweep or Tap, a Point/Small/Medium/Large radius (hit-tested by sampling a ring of points), a target filter (Anything / Drawings only / Arrows only), and whether a touch takes one element or its whole group. A ring shows the brush on the canvas, amber whenever a filter is on. Locks still win over every setting
- ./two-pens.md - when working on Two pens instead of a pen and a mode: The Pencil splits into Freehand (kept as drawn) and Shape Pen (a rough shape snaps to the real one); the recognise-shapes banner toggle and its persisted preference are gone, because which pen you picked is now the setting
- ./format-panel.md - when working on Format Panel: While the Format painter is active, a panel deciding which parts of a copied style travel — Fill / Border / Text / Effects / Size, all on by default — plus whether the brush stays loaded or empties after one paint. The field → toggle mapping is exhaustive by test against the painter's own projections, and the panel shows what the brush is holding
- ./element-size.md - when working on The Size category: A Size category in the element menu: exact width / height in canvas pixels, plus the aspect lock (which lived in Layer) and the reset (which lived in Shape, so it only showed for morphable kinds). Boxes are drafts committed on blur or Enter, anchored top-left, clamped 8-20000px, and the lock carries the other dimension
