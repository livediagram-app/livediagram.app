# Import and export blueprint defaults

One row per default applied where a spec is silent or qualitative.

| #   | Blueprint     | Spec silence                                                           | Default applied                                                                                                                                    |
| --- | ------------- | ---------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| D11 | drawio-import | A compressed payload that is not URI-encoded                           | Use the inflated Latin-1 text as it is when `decodeURIComponent` throws                                                                            |
| D12 | drawio-import | PNG chunk integrity                                                    | CRCs are not checked; a truncated chunk ends the walk                                                                                              |
| D13 | drawio-import | Colour values other than hex, `none`, `default`, `light-dark`, `rgb()` | Left unset, so the theme paints them                                                                                                               |
| D14 | drawio-import | Stroke width halfway between two presets                               | The thinner preset                                                                                                                                 |
| D15 | drawio-import | A vertex with no `strokeWidth`                                         | `thin`, draw.io's 1 px, rather than livediagram's `medium` default                                                                                 |
| D16 | drawio-import | An edge with `strokeColor=none`                                        | `opacity: 0`: the connection keeps its ends and label, drawn invisible as in draw.io                                                               |
| D17 | drawio-import | A vertex with no geometry                                              | Skipped and counted `hidden-skipped` (draw.io cannot show it either)                                                                               |
| D18 | drawio-import | Duplicate cell ids                                                     | The last cell wins the id map; every cell is still walked once                                                                                     |
| D19 | drawio-import | "A fixed soft drop shadow"                                             | `{ offsetX: 2, offsetY: 3, blur: 3, opacity: 0.25 }`                                                                                               |
| D20 | drawio-import | How much an icon's box grows to hold its caption                       | 18 px per line down / up; 7 px per character of the longest line plus 16 px of padding across; a lane title 9 px per character plus 16 (bold `sm`) |
| D21 | drawio-import | "A label placed away from the middle"                                  | Geometry `x` more than 0.05 from 0                                                                                                                 |
| D22 | drawio-import | How many unmatched stencil names the summary lists                     | The 5 most frequent, then "…"                                                                                                                      |
| D23 | drawio-import | Font size halfway between two presets                                  | The smaller preset                                                                                                                                 |
| D24 | drawio-import | Name of an unnamed page                                                | `Page n`, n its 1-based position                                                                                                                   |
| D25 | drawio-import | Names of layers beyond the first when unnamed                          | `Layer n`, n its 1-based position                                                                                                                  |
| D28 | drawio-import | "Ink that reads on that fill"                                          | `#1e293b` on a fill `isLightColor` calls light, else `#ffffff`                                                                                     |
| D30 | drawio-import | A single word wider than its imported shape                            | Left as livediagram wraps it (mid-word); no widening, no text shrink (operator decision)                                                           |
