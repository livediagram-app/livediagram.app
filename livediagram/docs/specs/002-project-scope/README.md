- ./secrets-policy.md - when working on Secrets policy: No secrets in source: the repo is public
- ./vulnerability-disclosure.md - when working on security reporting: the vulnerability disclosure policy, security.txt, SECURITY.md
- ./not-in-livediagram.md - when someone asks for Avatar mode, Spaces, furniture or the Spaces templates in livediagram: what moved to livehuddle, what stays, and how old documents keep their retired pieces
- ./third-party-licences.md - when adding a dependency or changing what an app bundles: the generated /licences page, overrides and embedded works
- ./blueprints/README.md - when implementing or changing the licences generator, its tables or the /licences page
