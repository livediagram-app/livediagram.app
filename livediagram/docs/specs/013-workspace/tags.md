# Tags

**Removed (October 2026).** Tags, the coloured labels a person put on their documents, are gone to keep the Explorer
simple: there is no Tags page, sidebar or panel row, tag picker, chip, Tags menu row, `/api/tags` route or
`tags` / `document_tags` table, the index holds no tags (no `/tags` routes, `tag` list filter or `tagIds` on an
item), and an offline document no longer carries tags. A stored document or offline record
that still carries tag fields loads as before, with them ignored. An old `/explorer/tags` link replaces itself with
Home. Tags may come back later.

A card's own tags on the canvas, and the colours they take ([Tag colours](../009-elements/tag-colours.md)), are a
different feature and stay, as do a Community post's tags.
