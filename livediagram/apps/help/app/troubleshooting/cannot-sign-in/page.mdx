Before anything else, the good news: **you do not need to sign in to use livediagram**. The canvas always works without an account, so a sign-in problem never blocks you from building or sharing a document. You can continue as a guest and sort the account out later. With that safety net in mind, here is how to get sign-in working.

## First, keep working

If sign-in is failing and you just want to get on with it, leave the sign-in page and head straight to a [new document](/new) or [the Explorer](/explorer). Everything works: persistence, sharing by link, and real-time collaboration (only publishing to the Community needs an account). When you sign up or sign in later, the documents you built as a guest move into your account automatically, so nothing is lost, and you're offered the chance to move any documents in This Browser. See [working as a guest](/help/getting-started/guest-vs-account/).

## Sign-in checklist

<Figure caption="A wrong code shows an error above the form. Choose Resend code for a fresh one, or Back to change the email.">
  <SignInError />
</Figure>

1. **Check the email code.** Sign-in uses a 6-digit code sent to your email. Look in spam, and choose **Resend code** for a fresh one if the first is slow or has expired. Typing or pasting all six digits submits the code on its own; otherwise choose **Verify**.
2. **Use the same email** you originally signed up with. Signing in with an address that has no account takes you to sign-up instead, with that address filled in; choose **Back** on the code step if you mistyped it.
3. **Reload and retry.** A stalled sign-in form usually clears with a refresh.
4. **Disable interfering extensions.** Privacy or script-blocking extensions can break the sign-in flow. Try an incognito window with extensions off.
5. **Check the Google option.** If you signed up with Google, use **Continue with Google** rather than the email code. It takes you to Google and back in the same tab, so allow the redirect and third-party sign-in for the site if your browser blocks them.

## If it still will not sign in

If sign-in still will not complete after the checklist above, [contact us](/help/contact/) with the email address you are using and the error you see. Keep working as a guest in the meantime, your documents are safe.
