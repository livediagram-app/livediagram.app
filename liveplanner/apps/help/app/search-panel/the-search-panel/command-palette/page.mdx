The [search panel](/help/search-panel/the-search-panel/) isn't only for finding things, it's also a **command palette**: type the name of an action and run it, without hunting through menus. If you've used ⌘K in tools like VS Code, Linear or Slack, this is the same idea.

## Opening it

- **Keyboard:** press `Cmd` / `Ctrl` + `K` anywhere in the editor. The older `Cmd` / `Ctrl` + `.` opens the same panel.
- **Button:** **Search** in the bottom bar opens it too.
- It works in **[Zen mode](/help/tools/zen-mode/)** and on **view-only** links, just like opening search.

Commands only exist inside a plan: on the Explorer page, search finds things but has no actions to run.

## Running a command

Start typing and matching commands appear in an **Actions** group, below any plans or tabs that also match. Click the one you want, or arrow down to it and press `Enter`. Commands match on their name and on a few related words, so "download" finds Export… and "hotkeys" finds Keyboard Shortcuts. At most 10 actions show at once, so type a little more to narrow a long list.

Commands only show once you've typed something, so an empty box just lists places to jump to and never runs an action by accident. Each command does exactly what its button or menu item does: it's the same action under a different name.

## What you can run

The list only offers what applies right now:

- **History:** **Undo** and **Redo**, shown only when there's something to undo or redo.
- **Plan and tab:** **Create New Tab**, **Rename Tab**, **Rename Plan**, **Delete Plan**, and **Share Plan** (for the owner, and not for a plan saved only in this browser).
- **Look:** **Open Theme**, which opens the tab's [Style](/help/user-interface/themes/) dialog.
- **Files:** **Export…** and **Import…**, the tab's [export](/help/tabs/export-tabs/) and [import](/help/tabs/import-tabs/).
- **Settings:** **Open Settings**, and **Keyboard Shortcuts**, which opens Settings on its Keyboard category.
- **View:** **Enter zen mode** (or **Exit zen mode**), and **Collaborators**, which opens the [list of people in the plan](/help/collaboration/live-presence/).

## On view-only links

On a Viewer or Participant link, the palette keeps the commands that change nothing: Enter or Exit zen mode, Export… and Collaborators. Everything that would change the plan simply isn't listed.

<Tip>
  Forgotten where something lives? Press `⌘K`, type the first few letters of what you want to do
  (like "export" or "rename"), and run it.
</Tip>
