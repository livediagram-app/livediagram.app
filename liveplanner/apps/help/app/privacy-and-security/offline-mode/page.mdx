Most projects are saved to liveplanner's servers so you can reach them from any device and share them. **Offline Mode** is the opposite choice: a project saved **only in the browser you made it in**, that is never stored on the server. It suits private, local-first work, or simply wanting a project that physically never leaves your machine.

## Creating a project in This Browser

Offline Mode is chosen per project, so you can keep normal projects and ones in This Browser side by side.

- **If you haven't signed in**, your new projects start in This Browser. Nothing you try out is sent to our servers until you choose to share it, sync it, or sign in and move it to your account (or use the AI assistant on it). Everything you make from the [New Project](/new) screen, and from the links that create a project straight away (a template from the home page, **Start Blank**), starts in This Browser. Use **Sync Project** on one if you would rather it went to the server now.
- **Once you've signed in**, new projects go to your account. To keep one only in this browser, choose **Take Offline** from its menu (see below).
- The project is written to your browser's own storage (IndexedDB) and opens like any other. A **This Browser** badge next to its name in the editor, and the matching **This Browser** pill wherever it is listed (Explorer lists and cards, search results, the Explorer panel and the Trash), mark it so you always know which projects live only in this browser. Hover or focus the pill to read that the project lives only in this browser and that clearing this browser's site data deletes it; click it (in the Explorer lists, the Explorer panel and the Trash) to come back to this guide. The Explorer sidebar's **This Browser** row lists them all.

<Note>
  A project in This Browser is **not synced and not backed up**. It lives only in this browser:
  clearing your site data, or the browser reclaiming storage, will delete it. Keep anything
  important on the cloud, or export a copy.
</Note>

## What's different

A project in This Browser is a normal project: every editor feature works, including shapes, arrows, layers, tabs, themes, undo/redo, and export. Only the features that need the server are unavailable, because there's no server copy to power them:

- **Sharing** needs a project on the server. Opening **Share** on a project in This Browser tells you so and offers **Sync Project**: press it and the project uploads, and the Share options appear in the same dialog, with no reload. Embeds are unavailable until it is synced, for the same reason.
- **Live collaboration** and **teams** don't apply; a project in This Browser is yours alone. Comments still work, but only you see them.
- The AI assistant works while you're online (it reads your current canvas), but not with no connection.
- Images you add are stored **inside the project**, so it stays fully local.
- **Add a Tab to Another Project** is unavailable for a project in This Browser in either direction, and **Duplicate** makes another copy in This Browser rather than uploading one.
- In the Explorer it shows a fixed This Browser picture instead of a thumbnail, because there is no server copy to draw one from.

## Moving to and from your account

You can change your mind at any time, from the project's **⋯** menu in the Explorer.

- **When you sign in** with projects in This Browser, we offer to move them to your account. Every one is ticked; untick any you want to keep in this browser, then **Move**. **Not Now** leaves them where they are, and we only ask again when there are more.

- **Sync Project** uploads a project in This Browser to the cloud. It becomes a normal project, shareable and (when you're signed in) reachable from your other devices, and the copy in this browser is removed.
- **Take Offline** does the reverse: it downloads a cloud project into this browser and then **removes it from your account and every other device**. Because that deletes the server copy for good, we ask you to confirm first.
- **A tab it shares with other projects** (see [Add a Tab to Another Project](/help/tabs/add-to-project/)) stays in those projects, and this browser keeps its own copy. From then on the two are separate: edits on one side no longer reach the other, and syncing the project back brings your copy in as a new tab beside the original.

<Note>
  **Take Offline** is deliberate and irreversible on the server side: once a project is in This
  Browser it exists only in the browser you took it offline in. If it was shared, taking it offline
  also revokes the share links, and a team project leaves the team library. For the owner it is a
  move, not a delete, so it skips the [Trash](/help/account-and-data/trash/); a teammate taking a
  team project offline sends the team's copy to the team Trash. A project in This Browser you
  delete goes to this browser's own Trash.
</Note>
