A [vote](/help/collaboration/session-tools/voting/) is only honest if nobody can read the room before it closes. Two switches sit above **Start vote**, and both apply to everyone on the tab, not just to you.

## Hide cursors

**Hide cursors** is **on by default**. While the vote is open, nobody sees anyone else's pointer, so the group cannot watch each other drift toward a favourite. A Board tab never shows other people's pointers in the first place (see [Live Presence](/help/collaboration/live-presence/)), so on a board this switch changes nothing you can see.

You can still see **who** is in the room: the initials on the tab stay put throughout, and a card someone has open still carries their name.

## Hide running counts

**Hide running counts** is **off by default**. Turn it on for a blind vote: while it runs, each card's counter shows only **your own** dots, so you can still see and retract what you spent, but nobody can watch a total climb and pile on.

</Figure>

**Show results** reveals the real tallies and the winners together.

## Both are fixed for the life of the vote

There is no way to turn them off halfway through, which is the point: end the vote and start another if you want different rules.
