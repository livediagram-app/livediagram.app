An embed places a live copy of a plan inside another page, like a wiki, a doc, Notion, or your own site. It shows the tab's board, Sheet, Dashboard or Form, hides the editor chrome, and stays up to date as the plan is edited.

## What an embed shows

The embed is built from a share link, and it **honours that link's level**: a **Viewer** or **Participant** link embeds a read-only plan, while an **Editor** link embeds an editable one, so readers of the host page can move cards and edit cells right there. Pick the link to match: a Viewer link when the page is for an audience, an Editor link when it is for collaborators.

Inside the frame, the embed:

- shows the tab as it is in the editor: a board's columns and cards, a Sheet's cells, a Dashboard's charts and metrics, or a Form,
- hides the header, the tab bar and the corner buttons, leaving a clean view,
- opens a card's panel when you click the card, to read it, or to edit it through an Editor link,
- keeps a small **Open in liveplanner** badge in the corner that opens the full share view in a new tab,
- skips the "what's your name" prompt: readers join under a random guest name.

Because the embed joins the same realtime room as any viewer, it **live-updates**: when a card moves or a cell changes, the embedded view follows along.

## Adding an embed to a page

<Step n={1}>
  Open the **Share** dialog, choose a level, and press **Create Pass**. (Or use a pass you already
  have.)
</Step>
<Step n={2}>
  On the pass, open **Embed** and choose **Copy embed URL** or **Copy iframe**. The embed address
  looks like `https://liveplanner.app/embed?s=CODE`.
</Step>
<Step n={3}>
  Paste the embed URL into a tool that turns a link into an embed, or paste the iframe into the
  page's HTML.
</Step>

If the plan has a [share password](/help/collaboration/sharing/share-passwords/), readers are asked for it inside the embed frame. A link scoped to [one tab](/help/collaboration/sharing/one-tab/) embeds that tab only.

## When an embed stops working

An embed lives exactly as long as its share link. If you revoke the link, or it [runs out](/help/collaboration/sharing/share-link-expiry/), the frame shows a small not-found message instead of the plan. Create a new pass and copy its embed to bring it back.

## Privacy

An embed only exposes what the share link exposes: a Viewer or Participant link's embed is a read-only view, and only an Editor link's embed can change the plan. Anyone who can read the host page's source can also see the embed address, so treat an editable embed like handing out the edit link itself.
