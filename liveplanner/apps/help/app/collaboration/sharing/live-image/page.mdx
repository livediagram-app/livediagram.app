A live image is a plain image address for a plan that **follows the plan as it changes**: the server keeps a picture of it that is redrawn after each save, so wherever you place the address shows the current state of the plan. It is the companion to an [embed](/help/collaboration/sharing/embeds/): the embed is interactive, while a live image is a single static picture, which is exactly what you need somewhere an `<iframe>` is not allowed, like a **GitHub README** or a Markdown file.

## What the image shows

The image is a flat picture of the tab, drawn from what it holds:

- **A Board** is drawn as its columns with their cards.
- **A Sheet** is drawn as its cells, showing their worked-out values.
- **A Form** is drawn as respondents see it.
- **A Dashboard** is drawn as its page, each metric and chart with its figures.

It shows the tab you pick in the **Live image** menu's **Tab** list (the first tab unless you choose another), or for a link scoped to [one tab](/help/collaboration/sharing/one-tab/), that tab. A tab with nothing on it yet has no image.

## Making a live image

<Step n={1}>
  Open the **Share** dialog, choose a level, and press **Create Pass**. (Or use a pass you already
  have.)
</Step>
<Step n={2}>
  On the pass, open **Live image**, pick the **Tab** it should show when the plan has several, and
  choose **Copy image URL**, **Copy Markdown** or **Copy HTML**.
</Step>
<Step n={3}>
  Paste it where you want the plan to appear: the Markdown in a README, or the HTML `<img>` tag on
  a web page. The image address looks like `https://liveplanner.app/api/share/CODE/image.svg`.
</Step>

Editing the plan updates the image the next time it loads. Browsers and sites may keep a copy for a few minutes, so a page can show the previous version briefly after an edit.

## When it shows nothing

A live image only works for a link that opens without a password. An `<img>` request cannot supply one, so while the plan has a [share password](/help/collaboration/sharing/share-passwords/), its image address shows nothing and the pass offers no **Live image** menu. Remove the password to use a live image, or use an [embed](/help/collaboration/sharing/embeds/), which can ask for the password inside its frame.

A live image also stops working when its share link is revoked or [runs out](/help/collaboration/sharing/share-link-expiry/), so keep the link alive for as long as the image is in use.

## Privacy

A live image only exposes what its share link exposes, as a flat picture with no editing actions.
