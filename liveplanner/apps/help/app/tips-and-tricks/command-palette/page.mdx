You don't need to remember where every button lives. Press `⌘K` (Ctrl+K on Windows and Linux) in any plan, type a few letters of what you want, and pick it. The same box finds plans, tabs, settings and help, and runs commands too.

## A few to try

- `new` and **Create New Tab** adds a tab and opens **Start Planning** on it, ready for a board, sheet, dashboard or form.
- `rename` offers **Rename Tab** and **Rename Plan**.
- `export` opens the tab's **Export…**, for a CSV, an image, a PDF or JSON.
- `share` opens **Share Plan**.
- `zen` hides the editor's chrome so only your board or sheet is on screen; `Z` or `Escape` brings it back.
- `keyboard` opens Settings on its **Keyboard** category, where you can switch shortcuts off.
- `dark` finds the **Theme** setting, so you can switch between light and dark.

Commands sit below the places that match, so `Enter` on its own goes to the first match. Arrow down to the command when you want to run it instead.

See [The Command Palette](/help/search-panel/the-search-panel/command-palette/) for every command it offers, and [Keyboard Shortcuts](/help/tips-and-tricks/keyboard-shortcuts/) for the keys that work without it.
