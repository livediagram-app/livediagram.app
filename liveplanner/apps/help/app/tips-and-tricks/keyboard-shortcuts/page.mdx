Keyboard shortcuts save you a trip to the mouse for the things you do most. A few work everywhere in the editor; boards and sheets add their own keys while you are working in them. `⌘` below is the Command key on a Mac; on Windows and Linux use Ctrl.

## Everywhere in the editor

| Keys               | Does                                                                          |
| ------------------ | ----------------------------------------------------------------------------- |
| `⌘K`               | Open [search and commands](/help/search-panel/the-search-panel/command-palette/) (`⌘.` does the same) |
| `⌘Z`               | [Undo](/help/user-interface/undo/)                                            |
| `⌘⇧Z`              | [Redo](/help/user-interface/redo/) (Ctrl Y works too)                         |
| `Z`                | Turn [Zen mode](/help/tools/zen-mode/) on or off                              |
| `Escape`           | Close what is open, or leave Zen mode                                         |
| `F6`               | Move to the next part of the editor: header, the tab's content, the controls, the tab bar (Shift for the previous one) |

On a view-only link, `⌘K`, `Z` and `Escape` still work, since they change nothing. Undo and redo are for people who can edit.

A key typed into a text box is just a letter: a `z` typed into a card's title never switches on Zen mode.

## On a board

Move to a card with `Tab`, and while it has focus the board takes these keys:

| Keys                  | Does                                              |
| --------------------- | ------------------------------------------------- |
| Arrow keys            | Move between cards                                |
| `Enter` or `Space`    | Open the card                                     |
| `⇧←` / `⇧→`           | Move the card to the previous or next column      |
| `⇧↑` / `⇧↓`           | Move the card up or down its column               |
| `N`                   | Add a card to the card's column                   |
| `Delete` / `⌫`        | Move the card to the Trash                        |

Each move is read out to a screen reader ("#12 moved to In Progress, position 2 of 4"). See [Boards](/help/plan/boards/) and [Cards](/help/plan/cards/).

## In a sheet

A [Sheet](/help/plan/sheets/) works the way spreadsheets usually do:

| Keys                     | Does                                                    |
| ------------------------ | ------------------------------------------------------- |
| Arrow keys               | Move between cells (`⌘` jumps to the edge of the data, Shift extends the selection) |
| `Enter` / `Tab`          | Move down / right (Shift goes back)                     |
| `F2`, or just type       | Edit the cell                                           |
| `Delete` / `⌫`           | Clear the selected cells                                |
| `⌘B` / `⌘I` / `⌘U`       | Bold / italic / underline                               |
| `⌘F` / `⌘⇧H`             | Find / find and replace                                 |
| `⌘D` / `⌘R`              | Fill down / fill right                                  |
| `⌘;` / `⌘⇧;`             | Today's date / the time now                             |
| `Alt↓`                   | Open the cell's dropdown                                |
| `⌘+` / `⌘-` / `⌘0`       | Zoom the sheet in / out / back to 100%                  |

## Turning shortcuts off

Shortcuts are handy, but they are not for everyone: if you dictate into the browser, or use something else that needs the keys, they can get in the way. Open **Settings** from the bottom bar (or run **Keyboard Shortcuts** from `⌘K`), pick **Keyboard**, and flip the **Keyboard Shortcuts** switch at the top.

<Figure caption="Flip the Keyboard Shortcuts switch in Settings so a stray key press never does something you didn't mean.">
  <ShortcutsToggle />
</Figure>

With the switch off, the editor-wide keys above stop, and the browser's own behaviour for those keys comes back. Use the on-screen controls instead: **Undo** and **Redo** sit in the bottom-right corner, and **Search** in the bottom bar. This choice is saved in your browser and stays per device rather than following you across sign-in, so you can keep shortcuts on where you have a full keyboard and off where you don't.
