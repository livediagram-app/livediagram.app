Everything the liveplanner editor does, it does by calling a REST API. That API is open to you too: with an [API token](/help/account-and-data/api-tokens/) your own scripts and integrations can read, create, and update projects, tabs, folders, themes and more, exactly as the app does. Account administration (teams, tokens, deleting the account) stays with the signed-in app.

If you want to connect an AI assistant rather than write code, you usually want the [MCP server](/help/account-and-data/connect-ai-mcp/) instead. It wraps this API in tools Claude and other MCP clients can call directly. To work from a terminal or a coding agent without writing requests yourself, use [the liveplanner CLI](/help/developers/cli/).

## The base URL

The API lives under `/api` on your liveplanner host. On the hosted service that is:

```
https://liveplanner.app/api
```

Every path in these docs is relative to that base, so `GET /projects` means `GET https://liveplanner.app/api/projects`.

## Authenticating in one line

Send an API token as a bearer header on each request:

```bash
curl https://liveplanner.app/api/projects \
  -H "Authorization: Bearer lvd_your_token_here"
```

API tokens are a [signed-in-only](/help/account-and-data/signing-in/) feature. [Authentication](/help/developers/authentication/) covers how to create one and how token access compares to the guest path.

## What you can do

The token-callable surface mirrors the app:

- **Projects and tabs**: list, read, create, rename, copy, and delete projects; start a tab from a template; read a tab as JSON, as a text view or as an SVG picture; change a tab with changesets, and revert one.
- **Cards and card types**: read, add, change, move and delete the cards (items) a project's boards show, and change its card types.
- **Folders**: organise projects into folders, personal or in a team you belong to.
- **Sheets**: read and change the cells of a project's Sheets, their rows and columns, and their titles.
- **Comments**: read, add, reply to, resolve and reopen comment threads, on a tab or on a card.
- **Forms**: build a Form tab's [form](/help/plan/forms/), publish or close its link, and send a test response, the same calls the CLI's `form` commands make.
- **Sharing**: create, list, extend and revoke share links, and set or remove a share password.
- **Trash**: list what you can restore, restore it, or delete it for good.
- **Themes**: manage your saved custom themes.

[Working with Projects](/help/developers/working-with-projects/) walks through the common calls with copy-pasteable examples. [Edit Operations Reference](/help/developers/working-with-projects/edit-operations/) lists the changeset vocabulary, [Plan Items, Sheets and More](/help/developers/working-with-projects/plan-sheets-images/) covers cards, cells, forms and pictures, and [Comments and Presence for Agents](/help/developers/agent-comments-presence/) shows how an agent talks to people and shows what it is doing.

## The full reference

The complete, machine-readable description of every endpoint, request shape, and response shape is published as an **OpenAPI 3.1** project, with no authentication required:

```bash
curl https://liveplanner.app/api/openapi.json
```

Point Postman, an OpenAPI viewer, or a client generator at that URL to explore the whole surface or scaffold a client. Endpoints an external token can use are tagged `x-token-usable`.

<Tip>
  The realtime collaboration WebSocket is not part of the REST reference. The OpenAPI project lists
  the upgrade endpoint, but the live message protocol is intentionally separate.
</Tip>
