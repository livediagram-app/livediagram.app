A **default folder** is where your new projects go when you create one without choosing a place. You can keep one for each of these, listed under **New projects that open as**:

- **Projects**: every new project.
- **Retrospectives**: projects made from any retrospective template.
- **Kanban boards**: projects made from the Kanban template.

A project goes to the most specific default that fits it: a retrospective's or a Kanban board's first, then the one for every project. So a retrospective goes to your Retrospectives folder even if you also have one for Projects. With none set, it lands in My Projects. Your defaults are your own: teammates choose theirs. Default folders are stored with your account or guest identity, not in the browser.

## Setting a default from a folder

Open a folder's menu (its **⋯** button, or right-click the folder) and choose **Use as Default for**. Under **New projects that open as**, tick the kinds of project that should land there; the list stays open so you can tick several in one go. Each kind points at one folder, so ticking it here moves it from wherever it was; unticking it sends those projects back to My Projects.

**My Projects** has the same menu: a ticked entry there means those projects land in My Projects. Choosing an unticked one clears its default folder.

You can use a team's folders too, as long as you are a member of the team. A team's own top level cannot be a default: create inside the team to put a project there.

## Seeing your defaults

A folder that is one of your defaults shows a small mark after its name, in the sidebar, the Explorer's lists and cards, and the editor's Explorer panel: the icon of each kind it receives (two at most, then **+N**). Hover it to read, for example, "Default folder for new retrospectives".

## When you create a project

The New Project wizard never asks where a project goes: choose what you are making, and the project is filed in your default folder for it, or in My Projects when you have none. Pick a template on its start afterwards, and a project made a moment ago moves to that template's default folder, if it has one (a toast says so).

- Starting from inside a folder or a team keeps you there: that folder wins over your default.
- To file one project somewhere else, use **Change Folder** on it afterwards.
- While you try things out as a guest, new projects are saved in this browser instead, so they have no folder until you move them to your account.

## In Settings

**Settings > Projects > Default Folders** lists every kind with the folder it goes to, or My Projects. **Change** picks a folder; **Clear** sends that kind back to My Projects.

If a default folder has been deleted, or belongs to a team you have left, the row says so, for example "Retros (deleted), using My Projects", and new projects go to the next default that fits, or My Projects. Deleting a folder that is one of your defaults warns you first.

<Tip>
  Defaults only decide where a new project starts. Moving a project later, or changing a default,
  never moves projects you already have.
</Tip>
