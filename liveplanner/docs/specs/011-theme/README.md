# Theme

Follow the references below only as needed; never upfront.

- ./multicolour-themes.md - when working on Multi-colour (rainbow) themes: Rainbow/palette themes that tint each hierarchy branch a hue
- ./canvas-and-theme-dialog.md - when working on the Tab Style dialog: a Mashup card (a random look per press) then a carousel of twenty-three Looks, eight of them multi-colour (theme, finish, font and pattern in one click), a Fine-tune list opening the Colours, Finish, Text and Canvas panels
- ./light-and-dark.md - when working on how a theme looks in light and dark mode: every theme's two halves, derived dark/light colours, contrast floor, per-viewer rendering
- ./retired-schemes.md - when a scheme leaves the catalogue, an unknown or `custom:` theme id arrives, or on `migrateStoredTab`, the read path every stored tab takes
- ./blueprints/README.md - when implementing a theme spec: the blueprints hold the engineering detail derived from it
