# Hide from Recent

**Moved to liveworkspace's index (October 2026).** Hiding a project from Recent (`recentExcludedIds` in the preferences blob, the Hide from Recent and Show in Recent menu items) is gone. Recent is the index's list of what you opened last, across every app, and it has no per-item exclusion.

The plan is [one-explorer.md](../../../../liveworkspace/docs/one-explorer.md); the calls and types are in [one-explorer-contracts.md](../../../../liveworkspace/docs/one-explorer-contracts.md) "Items". The Explorer that shows it is the shared package, [`@liveworkspace/explorer`](../../../../packages/explorer/README.md).
