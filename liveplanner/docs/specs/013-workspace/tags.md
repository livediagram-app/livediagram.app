# Tags

**Moved to liveworkspace's index (October 2026).** Tags are the index's: personal, coloured labels on items from any app (`/tags`, `/tags/:id/items/:itemId`). liveplanner's `tags` and `project_tags` tables, `/api/tags`, its tag picker, chips, Tags page and the editor panel's Tags section are gone. The shared Explorer's Tags view and its tag picker read and write the index.

The plan is [one-explorer.md](../../../../liveworkspace/docs/one-explorer.md); the calls and types are in [one-explorer-contracts.md](../../../../liveworkspace/docs/one-explorer-contracts.md) "Folders, tags, favourites, defaults". The Explorer that shows it is the shared package, [`@liveworkspace/explorer`](../../../../packages/explorer/README.md).
