# Tags

**Removed (October 2026).** Tags, the coloured labels a person put on their plans, are gone to keep the Explorer simple: there is no Tags view, tag picker, chip or tag search in the Explorer, and the index holds no tags (no `/tags` routes, `tags` or `item_tags` table, `tag` list filter or `tagIds` on an item). Tags may come back later. (A card's own tags on a board are a different thing and stay.)

The plan is [one-explorer.md](../../../../liveworkspace/docs/specs/004-index/one-explorer.md); the calls and types are in [one-explorer-contracts.md](../../../../liveworkspace/docs/specs/004-index/one-explorer-contracts.md) "Folders, favourites, defaults". The Explorer that shows it is the shared package, [`@liveworkspace/explorer`](../../../../packages/explorer/README.md).
