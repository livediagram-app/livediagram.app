# Default folders

**Moved to liveworkspace's index (October 2026).** liveplanner's default folders (the `placement_defaults` table, `/api/placement-defaults`, the Use as Default for menu, its marker, the wizard's preselection and Settings > Projects) are gone. The index keeps placement defaults per person (`/placement-defaults`), and a guest's move to the account when they sign in; the shared Explorer offers no way to set them yet, so a new plan lands where New was pressed, or at the root of My Work.

The plan is [one-explorer.md](../../../../liveworkspace/docs/one-explorer.md); the calls and types are in [one-explorer-contracts.md](../../../../liveworkspace/docs/one-explorer-contracts.md) "Folders, tags, favourites, defaults". The Explorer that shows it is the shared package, [`@liveworkspace/explorer`](../../../../packages/explorer/README.md).
