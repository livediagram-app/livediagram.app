# Explorer structure

**Moved to liveworkspace's index (October 2026).** The Explorer's sidebar and pages are the shared package's. Its views are Home, My Work, Unsorted, Recent, Favourites, Shared With Me, Trash, Inbox, Timeline, Search, a folder and a team's library, at `/explorer/<view>` ([its README](../../../../packages/explorer/README.md) "Views"). There are no Tags or Themes views: tags and custom themes were removed. The old Activity address opens the Inbox. liveplanner's own sidebar, places-versus-views groups, ARIA tree hook and mobile drawer are gone.

The Explorer lives on liveworkspace.app, once for every app ([site.md](../../../../liveworkspace/docs/site.md) "The Explorer"). liveplanner's Explorer links (the header's Explorer button, the editor's brand menu, the panel's Open Page) go to `https://liveworkspace.app/explorer?from=liveplanner`, which opens filtered to plans, in liveplanner's colours, with liveplanner's logo after liveworkspace's in its header. Items, New (`/new`, filed where it was pressed), share links and help lead back here. The editor's floating Explorer panel is the package's `ExplorerPanel`, inside liveplanner (`apps/editor/app/embed/workbench/ExplorerHost.tsx`).

Every `/explorer` address on liveplanner redirects there, with the rest of the address and `from=liveplanner` (`apps/editor/lib/explorer-redirect.ts`: the Worker answers 302; in development a client redirect does the same). So links already out there keep working, and liveworkspace.app maps the retired ones: `/explorer/profile` and `/explorer?settings=notifications` (every notification email's unsubscribe link, [profile-and-email-notifications.md](../014-identity/profile-and-email-notifications.md)) open notification settings on liveworkspace.app, `/explorer/activity` the Inbox, `/explorer/dynamic` My Work, `/explorer/generated` the Made by AI filter, `/explorer/invites` the account's teams, and `/explorer/offline` liveplanner's This Browser view.

This Browser (plans kept only in this browser) stays in liveplanner, since that storage belongs to its origin: `/offline` lists them, and the panel's footer shows a This Browser row while there are any. The Explorer's sidebar on liveworkspace.app links to it.

The plan is [one-explorer.md](../../../../liveworkspace/docs/one-explorer.md); the calls and types are in [one-explorer-contracts.md](../../../../liveworkspace/docs/one-explorer-contracts.md) "Items". The Explorer that shows it is the shared package, [`@liveworkspace/explorer`](../../../../packages/explorer/README.md).
