# Teams

**Moved to liveworkspace's index (October 2026).** Teams belong to the liveworkspace account and are run in the Explorer: made, renamed, staffed and deleted there, on `liveplanner.app/explorer`, on liveworkspace.app and in the editor's Explorer panel ([liveworkspace/docs/one-explorer.md](../../../../liveworkspace/docs/one-explorer.md) "Teams are run in the Explorer", which holds the journeys). liveplanner no longer keeps a copy: its teams mirror, change-feed cron, team routes and invitations are gone. An account's teams come from its access token's `teams` claim; the Explorer lists them, each with its card (members, run in place) over its library ([Team shared projects](team-shared-projects.md)), and New Team ends the sidebar's Spaces. The editor's panel hands the Explorer a `teamsHost` (`apps/editor/lib/explorer-teams-host.ts`) over liveworkspace's account API, through the router's `/api/workspace/account/…`.

Team members are no longer listed anywhere in liveplanner, so comment mentions, the assignee list on actions and team email notifications have no member source for now and suggest nobody from a team. `GET /api/teams` lists the caller's teams from the token for API clients.

## Making a team

The Explorer makes a team with liveworkspace's account API directly (New Team under Spaces, and the Move dialog's New Team tile). For API clients, `POST /api/teams` `{ name, organisation? }` (`apps/api/src/routes/team-create.ts`, over `makeTeamFor` in `@liveworkspace/index-app`) asks liveworkspace to make it for the person signed in, vouching for them with the access token they sent (`createTeamFor` in `@liveworkspace/auth-client`); they become its admin. A signed-in session only: an API token or a workbench can't make one. It is usable on the very next request: a team the caller's token does not name yet is asked of accounts. It is the same team in every app, and run in the Explorer.

The plan is [one-explorer.md](../../../../liveworkspace/docs/one-explorer.md); the calls and types are in [one-explorer-contracts.md](../../../../liveworkspace/docs/one-explorer-contracts.md) "Sharing and access". The Explorer that shows it is the shared package, [`@liveworkspace/explorer`](../../../../packages/explorer/README.md).
