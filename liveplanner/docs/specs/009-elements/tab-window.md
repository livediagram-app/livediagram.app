# The tab window

Removed from liveplanner (plans/0001-liveplanner-fork.md Phase 4). A Tab Window was an element that showed another tab
of the same project, live, fitted inside it. liveplanner's editor draws Plan's elements only, so the window, its
Shows menu, its export and its telemetry (`UI·Used·TabWindowOpen`, retired in
`apps/telemetry/app/retired-events.ts`) are gone. A Dashboard's slots show other tabs instead
([Plan tabs](../026-plan/plan-tabs.md)).
