# Sheets

Follow the references below only as needed; never upfront.

A **sheet** is a spreadsheet tab on the canvas: a grid of cells with formulas, formatting, sorting and filtering,
placed from Plan mode's **Sheet** palette category and worked on like a Plan board. Its cells live in the
project's sheet store, apart from the canvas.

- ./sheet.md - when working on the Sheet element: placing it, its header, toolbar, formula bar and grid, selection, editing, keyboard, clipboard, fill, rows and columns, formatting, freeze, sort, filter, find, maximise, presence, other modes, exports, CSV
- ./data-validation.md - when working on validation rules: dropdowns, checkboxes, number, date and text rules, where values are checked, the rule editor
- ./conditional-formatting.md - when working on format rules: conditions and styles, colour scales, which rule draws a cell, the Conditional Formatting popover
- ./formulas.md - when working on the formula language: values, number formats, references, operators, functions, arrays and spills, references to other sheets and to Plan cards, errors, recalculation
- ./sheet-store.md - when working on the sheet store: what is stored, writes, rows and columns by id, access, live sync, undo, offline projects, copies, agents, limits
- ./blueprints/README.md - when implementing a sheets spec from its blueprint
