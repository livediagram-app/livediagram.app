# Agents blueprint defaults

One row per default applied where a spec is silent or qualitative.

| #    | Blueprint        | Spec silence                                                                   | Default applied                                                                                                                                                                                                              |
| ---- | ---------------- | ------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| CS1  | agent-changesets | Which migration number                                                         | None: the baseline migration holds the tables and the ws ticket person tag (the held check reads it)                                                                                                                         |
