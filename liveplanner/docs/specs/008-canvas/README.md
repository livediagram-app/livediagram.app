# Canvas

Follow the references below only as needed; never upfront.

**In liveplanner** the canvas is Plan's infrastructure: the canvas host, viewport, selection, history and element
sync carry every tab, since a Board or a Sheet is a canvas element that fills it ([Scope](../002-project-scope/product-scope.md)).
No one draws on it: Plan shows no palette and places no shapes or arrows. The specs here that describe drawing
(arrows, anchors, finishes, the quick style panel, isometric view, the polygon tool) specify livediagram code that is
still in the tree and cited from it; they stay until that code goes ([Build phase](../005-project-roadmap/prototype-scope.md#next)).

- ./canvas-and-palette.md - when working on Canvas and palette: The canvas and its palette strip: canvas tools, every element kind, drawing, rich-text labels
- ./element-menu-quick-bar.md - when working on the element menu's quick bar: Assign Action, Comment, Link and Note, and Clear Styles, above every category
- ./arrow-anchors.md - when working on Arrow anchors and auto-rebind: The sixteen anchor ids, the anchors each shape offers and where they sit, outline projection, the creation anchor, the converging fan, and the auto-rebind that moves an end to the facing side (same position class) only when its drawn path runs through a shape, plus same-side crossing swaps
- ./blueprints/README.md - when implementing a canvas spec that has a blueprint (arrow anchors, labels, bending, quick style panel)
- ./isometric-view.md - when working on Isometric view: Navigation tool that tilts the tab into an isometric, extruded-depth view; pans like Hand, read-only
- ./layout-cleanup.md - when working on Layout cleanup: the command palette's tidiers: Auto-align (grid snap) + Auto Layout (deterministic graph layout / Tidy up: fewer crossings, long-edge lanes, neighbour placement, flow-face anchors, two-bend angled lines); locked elements stay put
- ./arrow-to-arrow.md - when working on Arrow-to-arrow connections: Snap an arrow endpoint to evenly-spaced points along another arrow's line (sequence-diagram messages)
- ./minimap.md - when working on Minimap: Bottom-left zoomed-out overview + viewport rect; tap/drag to navigate. Desktop only
- ./snap-override.md - when working on Snap override (free drag): Hold Cmd/Ctrl while dragging or resizing to disable alignment snapping + guides for a free, off-grid placement
- ./arrow-collision-avoidance.md - when working on Arrow collision avoidance at draw time: Freshly drawn arrows get a one-shot gentle curve when the straight line would cross (or graze) an unrelated element, or run flush along the boxes it connects. Applied at the end of the draw gesture as an ordinary curved arrow (`curveOffset`), adjustable or straightenable with the existing handles; repositioning, imports, and auto layout never trigger it
- ./shift-drag-duplicate.md - when working on Shift-drag duplicate: Holding Shift while move-dragging a selection duplicates it on release: the dragged elements stay at the drop point and clones re-fill the origin, one undo step, via the same duplicate machinery as the toolbar action. Move drags only (resize keeps Shift as aspect constraint)
- ./element-shadows.md - when working on Element shadows: A Shadow category in the element style menu (shapes / stickies / images / link cards): preset tiles (None / Soft / Drop / Lifted / Hard) with hover preview + Offset X/Y, Blur, Opacity sliders on the debounced one-undo-step policy; fixed ink colour, numeric `shadow` field, box-shadow or drop-shadow() per wrapper transparency, feDropShadow defs for export parity, copied by the format painter
- ./arrow-route-behind.md - when working on Arrows pass behind intervening boxes: Arrows break around unrelated boxes they cross (default on, `routeBehind: false` opts out): an SVG mask punches margin-inflated holes per crossed box, frames/text/endpoint-owners never cut, hit band stays unmasked, per-arrow toggle in the Line section; every export draws the same gaps
- ./format-panel.md - when working on Format Panel: While the Format painter is active, a panel deciding which parts of a copied style travel — Fill / Border / Text / Effects / Size, all on by default — plus whether the brush stays loaded or empties after one paint. The field → toggle mapping is exhaustive by test against the painter's own projections, and the panel shows what the brush is holding
- ./element-size.md - when working on The Size category: A Size category in the element menu: exact width / height in canvas pixels, plus the aspect lock (which lived in Layer) and the reset (which lived in Shape, so it only showed for morphable kinds). Boxes are drafts committed on blur or Enter, anchored top-left, clamped 8-20000px, and the lock carries the other dimension
- ./arrow-labels.md - when working on Arrow labels: labels sit on the line with a knockout gap, wrap to a width set by the arrow shape, fall beside the line when too short; export matches
- ./arrow-bending.md - when working on Bending arrows: drag the line to bend it (bow, bend point, segment slide), move frame for free arrows, and the double-press rule that stops fast double-clicks hitting fresh handles
- ./element-indicators.md - when working on Element indicators: the link / note / action / comment marks on an element and a mind root's Edit Outline / Tidy Map commands; Top (default, centred on round shapes), Footer or Off, placed inside any shape's outline with a pip fallback
- ./corner-radius.md - when working on corner presets and how a corner is drawn: None / Small / Medium / Large / Full, never more than a quarter of the shorter side (Full exempt), one shared `cornerRadiusPx` for canvas, exports and hit outlines; where corners are set
- ./quick-style-panel.md - when working on Quick style panel: The left-edge panel of most-used style choices for selected shapes + arrows (7 theme-relative colours, then 3-option rows for width, style, text + icon alignment, Clear Styles), its boundary with the context menu, deterministic placement clear of the Palette, and per-kind style memory for the next user-drawn element
- ./canvas-performance.md - when a change touches how the canvas renders or reacts to a gesture: the budget, the reference board, and the rules that keep cost following what a gesture touches
- ./drag-preview.md - when working on how a move, resize or reshape draws while it lasts, writes on release, and shows live to collaborators
- ./finish.md - when working on Finish: the Flexible / Professional / Sketch / Marker drawing style of a tab and its elements (element follows its tab unless set), what each changes, where it is set, roles
- ./accent-edge.md - when working on Accent edge: A coloured bar along the left, top or bottom of a box shape (square, stadium, card, mind node), clipped to its outline, set from Border, drawn the same in every export
