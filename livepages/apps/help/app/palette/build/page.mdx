The **Build** elements are the ones a diagram is laid _out_ with: the structures that grow as you type (mind node, org chart, flowchart, sequence diagram, entity) and what you arrange and label them with (lane, frame, boundary, diagram key).

The Pages palette doesn't show them: they organise a diagram rather than a page, so the Build pieces a page uses most sit in the categories beside them, the [Stack](/help/palette/stacks/) in **Components** and the [Table](/help/palette/tools/tables/) in **Data**. Any of the others is still a search away: the [search panel](/help/search-panel/the-search-panel/search-add-to-canvas/) (`⌘K` or `Ctrl+K`) adds one when you type its name and pick it under **Add to canvas**, and `F` adds a frame.

What most of them have in common is that **each one holds other work**. A frame gathers a region, a lane carries the steps in a row, and a mind node hangs children off itself.

## The elements

- A **Mind node** is a node that knows its parent. **Tab** adds a child to its right, **Enter** a sibling below, each one connected and selected; start typing to label it, so a whole branch is built from the keyboard. See [Mind Maps](/help/palette/mind-maps/).
- An **Org Chart** is a mind map of people: each node shows an initials disc, a name and a role, **Tab** adds a report below and **Enter** a peer beside it, and the chart lays itself out top down. See [Org Charts](/help/palette/org-charts/).
- A **Flowchart** starts as a **Start** step. **Tab** adds the next step and **Enter** a parallel one, and the whole chart lays itself out after every change; any step can become a Decision, an Input / Output and more, and the chart can run in swimlanes. See [Flowcharts](/help/palette/flowcharts/).
- A **Lane** is a titled horizontal band for swimlane diagrams, its title down its left edge. Dragging the lane carries everything sitting in it, so a row of steps moves as one. See [Lanes](/help/palette/lanes/).
- A **Frame** is a labelled box that groups a section of the canvas. It draws behind its contents and carries them when you move it. Press `F` to add one. See [Frames](/help/palette/build/frames/).
- A **Sequence** diagram shows who calls whom, in order: participants side by side over dashed lifelines and a row per message. Double-click it to write its participants and messages in a dialog, and the diagram lays itself out. See [Sequence Diagrams](/help/palette/sequence-diagrams/).
- A **Diagram Key** lists the line styles and tag colours the tab uses, each with a meaning you type, and keeps itself up to date as the diagram changes. See [Diagram Keys and Tag Colours](/help/palette/diagram-keys/).
- A **Boundary** is a titled, tinted container for a cloud region, a VPC, a cluster or a C4 system. It carries what sits inside it like a frame, and boundaries nested in each other read deeper. See [Boundaries](/help/palette/boundaries/).
- An **Entity** is a class or a table: a title over its fields, for a data model. See [Entities](/help/palette/entities/).

The **Timeline** and the **Sankey** diagram are in the palette's **Concepts** category: see [Timeline](/help/palette/concept-graphics/timeline-rail/) and [Sankey Diagram](/help/palette/concept-graphics/sankey-diagram/).

## Working with them

Each behaves like any other element: select, restyle, lock, and move it freely, and each can carry a [link](/help/canvas/links/), a note, or a [comment](/help/collaboration/comments/) like anything else on the canvas.

Because they hold other work, check what comes with one when you move it: a frame and a lane carry everything whose centre sits inside them, and a mind node carries its whole branch, which is usually what you want and occasionally a surprise. Resizing a frame or a lane never moves its contents.
