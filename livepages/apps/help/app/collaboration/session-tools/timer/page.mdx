The timer time-boxes an activity for the whole room. It lives on the page as a **Timer** element, a small dial that shows the clock for every participant, ticking in sync. A **Stopwatch** element counts up from zero instead, for "let us see how long this takes".

## Adding a timer

Open the [search panel](/help/search-panel/the-search-panel/) (`Cmd` / `Ctrl` + `K`), search for **Timer** (or **Stopwatch**) and add it to the page. You need edit access to run it, and while someone is the [facilitator](/help/collaboration/facilitator/) it is theirs to run.

<Step n={1}>
  Open the timer's **⋯** menu (**Timer options**) to set its length: drag the handle round the dial
  (the coloured wedge is the time; one lap is an hour), tap a preset (1, 3, 5, 10, 15, or 30
  minutes), or use the **−** and **+** buttons for a minute at a time, from one minute up to two
  hours (past an hour, the dial shows an extra ring). The dial also takes the arrow keys, with
  **Home** for one minute and **End** for an hour.
</Step>

<Step n={2}>
  Press the play button on the timer (**Start timer**) to start it for everyone. While it runs, its
  controls pause and resume it, reset it to the start, or clear it.
</Step>

A tab runs one timer at a time. The timer is scoped to the tab, so each tab can have its own. Because it syncs like everything else, anyone who joins late or reloads sees the current time straight away rather than a fresh clock.

## What everyone sees

The timer's face shows the clock, ticking smoothly while it runs. A countdown also **drains**: the face starts fully tinted and empties as the time goes, so someone across the room can read how long is left without parsing the digits. It **pulses when it reaches 0:00** so the room knows time is up. There is no sound. Visitors who can't run the timer see the same face, without its controls.

## How it stays in sync

Rather than sending a tick across the network every second, each participant's clock works out the time locally from a shared anchor point: the moment a countdown will end, or the instant a stopwatch started. Everyone computes the same value from that anchor, so the clock stays in step without constant network chatter. Pausing freezes the value, and resuming re-anchors it.

<Note>
  The clock is shared but not second-perfect across machines: tiny differences in device clocks are
  fine for a session timer. It is there to keep the room roughly together, not to referee a
  stopwatch race.
</Note>
