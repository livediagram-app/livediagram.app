Session tools make a shared document interactive for a live session. There are two: a **timer** for time-boxing an activity (a countdown, or a stopwatch counting up), and **dot-voting** for prioritising as a group. Anyone who can edit the document can run them (or only the [facilitator](/help/collaboration/facilitator/), once someone takes that role), and they sync to everyone in real time.

## Starting a session tool

Each tool starts from a button on the page. Open the [search panel](/help/search-panel/the-search-panel/) (`Cmd` / `Ctrl` + `K`) and search for **Timer**, **Stopwatch** or **Dot Vote** to add that button to the page you are on, then press it to start the tool for everyone. Set a timer's minutes, or a vote's dots each, from the button's right-click menu. The palette strip doesn't offer these buttons.

While a vote runs, a **Vote** button appears in the bottom-right corner, showing how many dots you have left. Press it to open the [Vote panel](/help/collaboration/session-tools/voting/vote-panel/) above it. It goes again when the vote is cleared.

While someone else is facilitating, the buttons say who, and can't be pressed.

The timer and the vote are scoped to a single tab, so different tabs can run different activities, and they ride the same live sync as everything else on the page. That means people who join late or reload simply see what is happening now: a timer mid-countdown, or the votes cast so far, with nothing to set up again.

- **Timer** time-boxes an activity, as a countdown or a stopwatch counting up from zero (one runs at a time). See [The Timer](/help/collaboration/session-tools/timer/).
- **Dot-voting** lets each participant spend a budget of dots on the elements they care about, with live tallies and a results reveal. See [Dot Voting](/help/collaboration/session-tools/voting/).

## Who can do what

Session tools follow the document's roles automatically. Anyone with an **Editor** pass (and the owner, and team members) can run the controls and take part: starting the timer, casting votes. Visitors on a **Participant** pass take part but never run anything: they cast dots, while starting, revealing and clearing stay with editors. Visitors on a **Viewer** pass can still watch, they see the timer ticking and the tallies, but they cannot control the session or cast a dot. Typically the facilitator holds an Editor pass, the team shares a Participant pass, and observers follow a Viewer pass.

**A vote is narrower still.** Anyone who can take part (an Editor or a Participant) can cast dots, but only the person who _started_ the vote (or the facilitator) can end it, reveal the results, clear it, or drive the results walkthrough. Ending a vote can't be undone, so it isn't something a participant should be able to do by accident. See [Dot Voting](/help/collaboration/session-tools/voting/).

What a viewer actually sees during a vote also depends on its privacy settings: with **Hide running counts** on, nobody sees anyone else's dots until the results are revealed.

## What does and does not get recorded

None of the tools adds to [Undo](/help/canvas/undo/): starting a timer or placing a dot is not the kind of thing you would want to Ctrl+Z. A [document in This Browser](/help/privacy-and-security/offline-mode/) has no live room to share them with.

<Tip>
  Share a Participant pass with everyone who should vote and add stickies, and a Viewer pass with
  anyone who only needs to watch. The roles do the gating for you, with no extra setup.
</Tip>
