# Palette

Follow the references below only as needed; never upfront.

- ./style-presets.md - when working on Style presets: One-click Presets category: theme colour + border variations for shapes, animated line styles for arrows
- ./palette-drag-ghost.md - when working on Palette drag ghost + drop preview: Drag-to-add shows a live translucent footprint of the shape at the cursor, replacing the browser drag image
- ./emoji-icons.md - when working on Emoji section in the Icons tab: Native colour emoji as line-art icon-catalogue entries via a new `text` prim: an Emoji category in the Icons tab (~60 collaboration/status emoji), inheriting search, drag, fold-into-shape, thumbnails, and MCP render automatically
- ./palette-category-browse.md - when working on Browsing the palette by category: The Icons and Stickers tabs browse by category tile with a breadcrumb (two panes in the category bar's flyouts), replacing the category filter dropdown; search always runs over the whole catalogue
- ./palette-top-level-categories.md - when working on Palette top-level categories and bands: the Tools tab's groups as top-level categories; the category bar's Common / Structure / Decorate / Dynamic / Screen bands; most categories render as rows with a blurb
- ./stickers.md - when working on Stickers: A Stickers category in the palette's Decorate band: ~193 colour emoji plus word badges in eleven groups (Badges, Reactions, Feelings, Status, Direction, Celebrate, Decorate, Meeting, Work, People, Fun), browsed and searched like the icon catalogues. it replaces the Emoji category that sat inside the Icons tab ([Emoji section in the Icons tab](emoji-icons.md)), ids unchanged
- ./technology-icons.md - when working on Technology icons: Technology palette category: full-colour AWS / Azure / generic-infra brand icons for architecture diagrams
- ./palette-favourites.md - when you meet a reference to Palette Favourites: removed 2026-10-03, superseded by each editor mode's fixed Popular category; records what went and what stayed
- ./build-category.md - when working on The Build palette category: A Common-band palette category for the elements that HOLD other work: mind node, lane, frame, table (the timeline moved to Concepts). They were filed by what they look like and scattered across Write / Draw / Data / Components; what groups them is the moment you reach for them, which is when you are deciding how the canvas is arranged. Tile ids unchanged, so saved Favourites survive the move
