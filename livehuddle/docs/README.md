Follow the references below only as needed; never upfront.

Documentation for livehuddle, the planned liveworkspace app for meeting, running workshops and collaborating
together in a shared space.

(Work Tracker #99). Nothing is built until the spec is approved, and then it is built by forking livediagram in-tree,
as the [Build plan](./specs/005-project-roadmap/build-plan.md) says.
