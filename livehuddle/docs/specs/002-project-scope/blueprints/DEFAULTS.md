# Project scope blueprint defaults

One row per default applied where a spec is silent or qualitative.

| #   | Blueprint            | Spec silence                                          | Default applied                                                                                                                                                                                                                                                                                                     |
| --- | -------------------- | ----------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| D1  | third-party-licences | How tall a text box is before it scrolls              | 24 lines: the opening of every common licence, including Apache-2.0's first section, fits                                                                                                                                                                                                                           |
| D2  | third-party-licences | The text box's type                                   | `text-xs leading-5` monospace, so a line is exactly 1.25rem and the height is computable at build time                                                                                                                                                                                                              |
| D3  | third-party-licences | How texts are named                                   | First 16 hex of the sha256 of the normalised text                                                                                                                                                                                                                                                                   |
| D4  | third-party-licences | Entry order                                           | By name, case-insensitive (`en`), then version                                                                                                                                                                                                                                                                      |
| D5  | third-party-licences | A vendored work's name                                | Its directory name (with `@scope/`), which is the name Next vendors it under                                                                                                                                                                                                                                        |
| D6  | third-party-licences | A vendored work's version when it has none            | `bundled in <parent> <parent version>`                                                                                                                                                                                                                                                                              |
| D7  | third-party-licences | Label of a text                                       | Its file name; an override's label names the upstream and version                                                                                                                                                                                                                                                   |
| D8  | third-party-licences | Which package links are shown                         | `homepage`, else `repository` (string, shorthand or `{ url }`), only when it resolves to `https:`                                                                                                                                                                                                                   |
| D9  | third-party-licences | Opening the page from the editor                      | A new tab, as the neighbouring GitHub row does, so an open document stays put                                                                                                                                                                                                                                       |
| D10 | third-party-licences | What "permissive and weak-copyleft" admits            | The sixteen ids in `LICENCE_ALLOWLIST`: today's shipped licences plus common permissive peers                                                                                                                                                                                                                       |
| D11 | third-party-licences | Parallel or sequential analysis                       | Sequential: deterministic logs, bounded memory beside turbo's own parallel builds                                                                                                                                                                                                                                   |
| D12 | third-party-licences | Footer placement                                      | In the footer's Legal column, last                                                                                                                                                                                                                                                                                  |
| D13 | third-party-licences | Sitemap weight                                        | Priority 0.2, monthly: a transparency page, not a destination                                                                                                                                                                                                                                                       |
| D14 | third-party-licences | The HTML budget                                       | 1.5x the page as first measured (173.5 KB for 54 works), rounded to 260,000 bytes: dozens more entries fit, inlined texts do not                                                                                                                                                                                    |
| D15 | third-party-licences | The page's header calls to action                     | The shared header without a landing-funnel surface: a transparency page is not a funnel step, so its CTAs carry no `via`                                                                                                                                                                                            |
| D16 | third-party-licences | The entry's disclosure affordance                     | The native `summary` marker, coloured: no second drawing of a chevron, no rotation to animate, no bytes per entry                                                                                                                                                                                                   |
| D17 | element-engine       | Where the placeholder's Delete sits and when it shows | Inside the card only: 24 screen px at every zoom, 12 px down and 12 px in from the top-right corner (clear of the grips' touch pads), stepped left of the indicator cluster with a 4 px gap when it sits there; on hover, focus or selection                                                                        |
| D18 | element-engine       | The smallest card that shows the button inside it     | At least 72 by 48 on screen, with room left of the indicators, and only where no line of words reaches the button (a 4px gap); otherwise none, and the selection toolbar's Delete removes it                                                                                                                        |
| D19 | element-engine       | Where a stored lane, stack or boundary paints         | At the back with a stored Frame (`isRetiredBackdrop`): it painted behind what it held, so its placeholder never covers what sat on it                                                                                                                                                                               |
| D20 | element-engine       | An image's stored hero caption                        | Kept on the image as stored and not drawn: the image is a kept kind, so it stays an image rather than a placeholder                                                                                                                                                                                                 |
| D21 | element-engine       | How a retired arrow draws                             | A faint dashed straight line between its resolved ends plus the placeholder card (160 by 96) on its middle: the line shows where it ran, the card names it and holds Delete (96 tall so the Delete corner clears its name, note and label at zoom 1); a card stretched to the line's box would cover what it joined |
| D22 | element-engine       | A retired arrow end that no longer resolves           | It takes the other end's point; with neither end left the card sits at the canvas origin, so it can still be selected and deleted                                                                                                                                                                                   |
| D23 | element-engine       | What a retired arrow does when what it pinned to goes | Nothing: it stays as stored (Delete no longer takes pinned arrows with it), so no stored data is dropped as a side effect                                                                                                                                                                                           |
| D24 | element-engine       | The names of part 4's types                           | Arrow (Line when `arrowEnds` is `none`), Drawing (every pen and highlighter stroke), Path, Annotation                                                                                                                                                                                                               |
| D25 | element-engine       | Copying a retired arrow                               | A new id, its pinned ends moved to the copies of what they pinned to and its free ends offset with the copy, as copies always did; nothing else about it changes                                                                                                                                                    |
| D26 | element-engine       | Auto layout without arrows                            | Deleted: with no arrow no tab is a graph, so it could only ever do nothing. The agents' `layout` keeps its row sweep (`layout-sweep.ts`)                                                                                                                                                                            |
| D27 | element-engine       | Multicolour branches from stored arrows               | Kept read only until part 5 deletes the diagram theming, so a stored tree keeps its colours meanwhile                                                                                                                                                                                                               |
