# Draw mode blueprint defaults

One row per default applied where a spec is silent or qualitative. Draw mode is gone ([Editor modes](../../007-editor/editor-modes.md)), and with it the whiteboard dock (Work Tracker #329): D33 (the dock beside the mode switch) and the rows of the retired round-one blueprint describe behaviour no board offers any more; those rows were removed with it.
