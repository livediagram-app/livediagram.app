Follow the references below only as needed; never upfront.

- ./element-menu-quick-bar.md - when working on the element menu's quick bar: Assign Action, Comment, Link and Note, and Clear Styles, above every category
- ./arrow-anchors.md - (Leaving livehuddle, Work Tracker #423) when working on Arrow anchors and auto-rebind: The sixteen anchor ids, the anchors each shape offers and where they sit, outline projection, the creation anchor, the converging fan, and the auto-rebind that moves an end to the facing side (same position class) only when its drawn path runs through a shape, plus same-side crossing swaps
- ./blueprints/README.md - when implementing a canvas spec that has a blueprint (arrow anchors, labels, bending, quick style panel)
- ./layout-cleanup.md - when working on Layout cleanup: the command palette's tidier, Auto-align (grid snap); Auto Layout (gone from livehuddle's editor in Work Tracker #423 part 4, its engine kept for graph input: deterministic graph layout / Tidy up: fewer crossings, long-edge lanes, neighbour placement, flow-face anchors, two-bend angled lines); no Tidy Up button (Work Tracker #583); no locks
- ./arrow-to-arrow.md - (Leaving livehuddle, Work Tracker #423) when working on Arrow-to-arrow connections: Snap an arrow endpoint to evenly-spaced points along another arrow's line (sequence-diagram messages)
- ./minimap.md - when working on Minimap: Bottom-left zoomed-out overview + viewport rect; tap/drag to navigate. Desktop only
- ./snap-override.md - when working on Snap override (free drag): Hold Cmd/Ctrl while dragging or resizing to disable alignment snapping + guides for a free, off-grid placement
- ./arrow-collision-avoidance.md - (Leaving livehuddle, Work Tracker #423) when working on Arrow collision avoidance at draw time: Freshly drawn arrows get a one-shot gentle curve when the straight line would cross (or graze) an unrelated element, or run flush along the boxes it connects. Applied at the end of the draw gesture as an ordinary curved arrow (`curveOffset`), adjustable or straightenable with the existing handles; repositioning, imports, and auto layout never trigger it
- ./shift-drag-duplicate.md - when working on Shift-drag duplicate: Holding Shift while move-dragging a selection duplicates it on release: the dragged elements stay at the drop point and clones re-fill the origin, one undo step, via the same duplicate machinery as the toolbar action. Move drags only (resize keeps Shift as aspect constraint)
- ./highlighter.md - (Leaving livehuddle, Work Tracker #423) when working on Highlighter: Wide semi-transparent marker, a one-shot Draw tile beside the two pens: a FreehandElement with `pen: 'highlighter'` (multiply blend, marker yellow), no shape recognition, no close-to-fill; not a selection mode (no panel, no Mode Button; a stored Highlighter Mode Button migrates to the default mode)
- ./polygon-tool.md - (Leaving livehuddle, Work Tracker #423) when working on Multi-point line / polygon tool: Click-to-place vertex tool committing a FreehandElement with `straightEdges` (no Catmull-Rom smoothing): click near start closes + fills, double-click/Enter finishes open, Backspace removes last vertex, Escape cancels
- ./element-shadows.md - when working on Element shadows: A Shadow category in the element style menu (shapes / stickies / images / link cards): preset tiles (None / Soft / Drop / Lifted / Hard) with hover preview + Offset X/Y, Blur, Opacity sliders on the debounced one-undo-step policy; fixed ink colour, numeric `shadow` field, box-shadow or drop-shadow() per wrapper transparency, feDropShadow defs for export parity, copied by the format painter
- ./arrow-route-behind.md - (Leaving livehuddle, Work Tracker #423) when working on Arrows pass behind intervening boxes: Arrows break around unrelated boxes they cross (default on, `routeBehind: false` opts out): an SVG mask punches margin-inflated holes per crossed box, frames/text/endpoint-owners never cut, hit band stays unmasked, per-arrow toggle in the Line section; every export draws the same gaps
- ./avatar-mode.md - when working on Avatar mode: A canvas tool, named Walk, entered from the Edit | Walk toggle at the start of the strip (an Editor's; `W`), Search or a board's button, that drops a Habbo-style walking pixel character onto the canvas: click / tap to walk, arrow keys steer, Space hops with a waved flag, right-click on the character toggles male / female, the shirt takes your participant colour, the camera follows near the edges, and the element it stands on gets a "you are here" ring. The canvas is read-only while active (pointer-inert layer + suppressed mutating shortcuts) and while walking the palette strip becomes the avatar palette (the look on the left, Actions and React on the right, Say); the character broadcasts as an ephemeral `avatar` presence op so everyone in the room sees everyone walking. An Editor or Participant can say something in a speech bubble (Enter, or the palette's Say) that floats up and away for everyone on the tab. An Avatar Pad on the tab is where everyone starts
- ./avatar-tour.md - when working on the Avatar tour: the optional guided tour of Avatar mode on the footer's Start Avatar Tour button (the avatar palette, the look, Actions and React, speaking, pushing), rerunnable from Settings
- ./eraser-panel.md - retired (2026-11-06): what the Eraser and its panel were; livehuddle has no Eraser (select and press Delete)
- ./two-pens.md - (Leaving livehuddle, Work Tracker #423) when working on Two pens instead of a pen and a mode: The Pencil splits into Freehand (kept as drawn) and Shape Pen (a rough shape snaps to the real one); there is no recognise-shapes toggle or preference, because which pen you picked is the setting
- ./format-panel.md - when working on Format Panel: the Format painter starts from the selection toolbar's Format Painter button; while it is active, a panel deciding which parts of a copied style travel: Fill / Border / Text / Effects / Size, all on by default, plus whether the brush stays loaded or empties after one paint. The field → toggle mapping is exhaustive by test against the painter's own projections, and the panel shows what the brush is holding
- ./element-size.md - when working on The Size category: A Size category in the element menu: exact width / height in canvas pixels, plus the aspect lock (which lived in the old Layer section) and the reset (which lived in Shape, so it only showed for morphable kinds). Boxes are drafts committed on blur or Enter, anchored top-left, clamped 8-20000px, and the lock carries the other dimension
- ./arrow-labels.md - (Leaving livehuddle, Work Tracker #423) when working on Arrow labels: labels sit on the line with a knockout gap, wrap to a width set by the arrow shape, fall beside the line when too short; export matches
- ./arrow-bending.md - (Leaving livehuddle, Work Tracker #423) when working on Bending arrows: drag the line to bend it (bow, bend point, segment slide), move frame for free arrows, and the double-press rule that stops fast double-clicks hitting fresh handles
- ./element-indicators.md - when working on Element indicators: the link / note / action / comment marks on an element and a mind root's Edit Outline / Tidy Map commands; Top (default, centred on round shapes), Footer or Off, placed inside any shape's outline with a pip fallback
- ./corner-radius.md - when working on corner presets and how a corner is drawn: None / Small / Medium / Large / Full, never more than a quarter of the shorter side (Full exempt), one shared `cornerRadiusPx` for canvas, exports and hit outlines; where corners are set
- ./quick-style-panel.md - gone from livehuddle (livediagram keeps it); records the Quick style panel: the left-edge panel of most-used style choices for selected shapes + arrows (7 theme-relative colours, then 3-option rows for width, style, text + icon alignment, Clear Styles), its boundary with the context menu, deterministic placement clear of the Palette, and per-kind style memory for the next user-drawn element

- ./drag-preview.md - when working on how a move, resize or reshape draws while it lasts, writes on release, and shows live to collaborators
