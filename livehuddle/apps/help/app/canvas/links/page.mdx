Links connect your board to the rest of your work. Shapes, text, sticky notes, images, drawings, tables and annotations can all become clickable jump points. Together they let a board point at the things it describes instead of just naming them.

## Linking an Element

Give a shape, text, sticky note, image, drawing, table or annotation a link (arrows and lines take none), and it gains a small "Follow link" badge whose hover card names the target. A link can point at:

- **A tab** in the same space, or **a specific element** on another tab.
- **Another space** entirely.
- **An external URL**, which opens in a new browser tab.

To add one, right-click the element and press **Add Link** in the row of buttons along the top of its menu (it reads **Edit Link** once there is one). The **Link element** dialog opens on three choices:

- **External URL**: type a **Web address** and press **Save link** (or Enter). Leave off the `https://` and it is added for you.
- **Tab**: pick one of the space's tabs.
- **Space**: pick one of your other spaces.

To change a link, open the same dialog again and pick a new target; the Remove link button at its foot takes the link off. The link follows the element if you move it, and like any edit it can be undone. For more on tab and element targets, see [Linking Across Tabs](/help/tabs/linking-tabs/).

## Link Cards Already in a Space

A Space no longer adds link cards: the palette has no Link Card, and search does not offer one. A link card already in a Space still shows its page's title, favicon and address, moves, resizes and deletes like any other element, and double-clicking it still changes its address. To link to a page, give an element a link as above.
