The **Write** elements hold the elements whose content is _words_. Everywhere else in the palette you place something with a shape and then maybe label it; here the text is the point and the shape is just what carries it.

They differ mostly in **whose words they are**. A Text label is the board's own structure: a title, a heading, the name of a room. A Sticky note is somebody's contribution: an idea, a question, a point to vote on.

## What the category contains

- A **Text** element is a free-standing label with no box around it: just words on the canvas. `T` drops one. Use it for titles, headings, and anything that labels a _region_ rather than an element. See [Text and Fonts](/help/canvas/text-and-fonts/).
- A **Sticky note** is a coloured note card, the one that reads as somebody's contribution rather than the author's structure. `N` drops one. It is what brainstorms and dot votes are made of. See [Sticky Notes](/help/palette/tools/sticky-notes/).

<Note>
  There is a third way to attach words, and it is not in this category: any element can carry a
  [note](/help/canvas/notes/) or a [comment](/help/collaboration/comments/) of its own. Those belong
  to the element they are on and move with it.
</Note>

## Rows, not pictures

Both writing elements are rectangles with text in them, so at tile size they would look nearly alike. In their [palette panel](/help/palette/toolbar-layout/) each one is a row with a one-line description instead: "a free-standing text label" against "a coloured note card" is what you are actually choosing between.

## Working with them

Each behaves like any other element once placed: select, restyle, lock, rotate and move it freely, and each can carry a [link](/help/canvas/links/) like anything else on the canvas.

Text styling is shared with the rest of the canvas rather than special to this category: font, size, weight and alignment all come from the same controls that style any label. See [Text and Fonts](/help/canvas/text-and-fonts/).

<Tip>
  `T` and `N` drop a text label and a sticky note without opening the palette at all, which is the
  fast way through a brainstorm: type, `N`, type, `N`.
</Tip>
