When you open the [search panel](/help/search-panel/the-search-panel/) from inside a space, its scope grows to include that space's own contents: its [tabs](/help/tabs/using-tabs/) and the elements on them. This is what turns search into a within-space jump tool, not just a way to open a different space. It works in view-only spaces too, since it only moves you around.

## Tabs

The **Tabs** group matches the space's tabs by name, and marks the one you are on with **current** so you can tell a jump from a no-op. Picking a tab switches to it. On a space with many tabs (or [tab folders](/help/tabs/tab-folders/)) this is quicker than scanning the tab bar.

## Elements

The **Elements** group matches elements by their label: the text on a shape, a sticky note, a text box, and so on. Each result shows which tab it is on ("on Payments"), and picking one switches to that tab and selects the element.

Search covers **every tab**, not only the ones you have visited. Tabs load lazily as you open them, so when you open search from the **Search** button the editor fetches the rest of the space's tabs in the background; on a large space, matches from those tabs can join the list a moment later. On a link shared for a single tab, only that tab's elements are searched.

## What it does not search

- **Unlabelled elements:** an element with no text (a bare shape, or a table, arrow or drawing saved before livehuddle stopped supporting them) has nothing to match, so it never appears.
- **Comments, notes and links** on elements, and the names of people in the space.
- **Other spaces' contents:** element text is only searched in the space you have open. From anywhere, other spaces are found by name.

The Elements group lists up to 12 matches across the whole space. If the one you want is missing, type more of its label.

<Tip>
  This scope only appears inside a space. From the Explorer page, search covers your spaces, spaces
  shared with you, folders, teams, settings and help instead, see [Finding Spaces and
  Folders](/help/search-panel/the-search-panel/search-documents/).
</Tip>
