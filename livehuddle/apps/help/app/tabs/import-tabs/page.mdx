**Import** brings content into the active tab from pasted text or a file. It is the counterpart to [exporting](/help/tabs/export-tabs/): export a tab from one space, import it into a tab somewhere else.

Import reads livehuddle's own tab export, so you can back a tab up and restore it, or move it from one space to another. A Space is for meeting, so livehuddle reads no other tool's files: to bring in a board from Excalidraw, draw.io, Mermaid or Markdown, use livediagram, livehuddle's sister app for diagrams.

## Importing a tab export

Open the tab's menu (the **⋯** button on the active tab, or right-click the tab) and choose **Import**. You can also run **Import…** from the [command palette](/help/search-panel/the-search-panel/command-palette/). The **Import to Tab** dialog reads a livehuddle tab export (a `.livehuddle-tab.json` file) and restores its elements exactly.

  <ImportMenu />
</Figure>

**Paste** the JSON into the box and press **Import**, or press **Import a file instead** to pick one from disk. Either way the tab updates once it parses.

## Images in an imported tab

When an imported tab carries images, they come across with it. Each one is resized in your browser (to at most 2048 pixels on its longest side) and saved to your [image gallery](/help/explorer/image-gallery/), so it counts towards the gallery's space like any image you add yourself. An image you already have is recognised and reused rather than stored twice.

While the images save, the panel counts them ("Importing images 3 of 12…"). When it finishes, the dialog tells you how many were imported, how many were already in your gallery, and how many were left as placeholders and why: the file didn't include the image, its format couldn't be read, it was too large, or your gallery is full. The rest of the tab always imports. Double-click a placeholder to add its image later.

In a [space in This Browser](/help/privacy-and-security/offline-mode/), images are kept inside the space in this browser instead of your gallery, up to a limit for each import.

## Import replaces the tab

Importing **replaces the active tab's contents** with what comes in, it does not merge. Because that is destructive, the dialog leads with an amber warning naming the tab about to be overwritten, so you can back out before committing. If you change your mind afterwards, undo (`Cmd` / `Ctrl` + `Z`) brings the previous canvas back. To keep the current canvas as it is, add a new tab first and import into that.

**Import** is greyed out while a tab is [locked](/help/tabs/locking-tabs/), since a locked tab is protected from edits, and the tab menu isn't offered on a view-only share link.
