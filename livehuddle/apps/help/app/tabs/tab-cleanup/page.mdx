A board that filled up fast in a meeting can end up slightly ragged: notes dropped in a hurry, pictures pulled to roughly the right size. Tidying cleans up the active tab in one step, so you do not have to nudge elements into place by hand.

## Auto-align

Open the [command palette](/help/search-panel/the-search-panel/command-palette/) (`Cmd` / `Ctrl` + `K`), type **Auto-align** and pick **Auto-align to Grid** under **Actions**. It snaps the current positions and sizes onto a tidy grid, straightening rows and columns while keeping your arrangement.

<Figure caption="Typing layout in the command palette lists Auto-align under Actions.">
  <SearchCommandPalette />
</Figure>

Tidying acts on the whole tab at once, and it is a single step you can undo (`Cmd` / `Ctrl` + `Z`) if the result is not what you wanted.

<Figure caption="Auto-align takes a scattered handful of notes and snaps them into tidy rows on the grid in one step.">
  <CleanupBeforeAfter />
</Figure>

## More on layout

This is the [Layout Cleanup](/help/tools/layout-cleanup/) tool; see that guide, and [Auto-Align](/help/tools/layout-cleanup/auto-align/), for how it decides where things go.

Tidying isn't offered on a view-only share link.

<Tip>
  Auto-align is safe to run often: it never moves anything far, and running it again on a tidy tab
  changes nothing.
</Tip>
