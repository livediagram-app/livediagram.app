Keyboard shortcuts let you switch between editing and walking and run common actions without reaching for the palette. Edit and Walk sit on single keys, so you can move between building the board and walking it in a single tap, and the built-in shortcut reference in Settings lists everything in one place. `⌘` below is the Command key on a Mac; on Windows and Linux use Ctrl.

## The shortcut reference

Run **Keyboard Shortcuts** from [search](/help/search-panel/) (`⌘K`) and [Settings](/help/user-interface/settings/) opens on its **Keyboard** category. Below the on/off switch, **All Shortcuts** lists every binding the editor knows, in collapsible groups by purpose, so you never have to memorise the full set. You can also get there yourself: open **Settings** from the sliders icon in the editor's bottom bar and pick **Keyboard**.

The two sides of the [Edit | Walk toggle](/help/selection-modes/select/) have keys of their own:

- `E` for **Edit**, to select and build. `V` and `Escape` go back to Edit too.
- `W` for **Walk**, to walk the Space as your character in [Avatar mode](/help/selection-modes/avatar-mode/). It walks only from Edit: while you walk, `W` is Wave.
- `S` opens the [palette strip](/help/palette/toolbar-layout/)'s **Search**; where the strip isn't shown, it goes to Edit instead.

There is no key for panning or erasing: hold `Space` and drag to pan, and press `Delete` or `Backspace` to remove what you have selected. While you walk, the letters and digits play the avatar palette's Actions and React instead; Settings lists them under **While walking (Avatar mode)**.

The reference in Settings stays available in every role. On a view-only link, only the keys that change nothing still work: zoom and zoom to fit, search, and `Tab` to step through elements. Everything that edits is switched off. A view-only visitor and a [Participant](/help/collaboration/sharing/) have the same keys, and are always walking: the arrow keys move their avatar, and `E`, `V` and `Escape` don't take them out of Avatar mode.

## Editing shortcuts

These are the chords that edit the selection.

| Keys           | Does                            |
| -------------- | ------------------------------- |
| `⌘Z`           | Undo                            |
| `⌘⇧Z`          | Redo (Ctrl Y works too)         |
| `⌘X`           | Cut the selection               |
| `⌘C`           | Copy the selection              |
| `⌘V`           | Paste, offset from the original |
| `⌘D`           | Duplicate the selection, offset |
| `⌘A`           | Select everything on the tab    |
| `Delete` / `⌫` | Delete the selection            |
| `⌘⇧]` / `⌘⇧[`  | Bring to front / send to back   |

**Cut, copy and paste use your operating system's clipboard**, not a private one, so a selection copied on one tab pastes onto another, into a different space, or into a second browser window. A paste lands offset from the original rather than exactly on top of it, so you can see what arrived.

## Moving around and selecting

| Keys           | Does                                                                                                      |
| -------------- | --------------------------------------------------------------------------------------------------------- |
| `⌘K`           | Open search and commands (`⌘.` does the same)                                                             |
| `⌘+` / `⌘-`    | Zoom in / out                                                                                             |
| `⌘0`           | Reset the zoom to 100%                                                                                    |
| `⇧1`           | Zoom to fit everything on the tab                                                                         |
| `Tab`          | Select the next element while the canvas has focus (Shift for the previous one)                           |
| `F6`           | Move to the next part of the editor: header, palette, canvas, controls, tabs (Shift for the previous one) |
| Arrow keys     | Nudge the selection 1px, or 10px with Shift                                                               |
| `⇧` + click    | Add an element to the selection, or take it out                                                           |
| `⇧` + drag     | Drop a duplicate (the original stays put)                                                                 |
| `Space` + drag | Pan the canvas whatever tool you are holding                                                              |
| `Space`        | Edit the selected element's label                                                                         |
| Just type      | Replace the selected element's label                                                                      |
| `Escape`       | Cancel the current mode, or clear the selection                                                           |
| Hold `⌘`       | Show each palette tile's shortcut badge                                                                   |

## Keys that place an element

A few letters pick up an element, ready to place: click the canvas to drop it at its default size, or drag to draw it to the size you want. A brainstorm can run without visiting the palette at all:

- `T` a **text** label, `N` a **sticky note**.

## The number row

Two keys also sit on a digit, along the top of the keyboard:

| Key | Does |
| --- | ---- |
| `1` | Edit |
| `8` | Text |

They keep the slots Excalidraw's tool row gives them, so if you have that muscle memory it carries straight over.

## Hold Shift for the power moves

Shift is the editor's power modifier. While you hold it, a small hint bar near the top of the canvas names what Shift is doing right then, so these are easy to discover:

- **Shift-click elements** to build a [multi-selection](/help/canvas/selecting-and-grouping/multi-select/); Shift-click again to remove one.
- **Shift while resizing** an element (or drawing one to size) locks its proportions.
- **Shift while move-dragging a selection** drops a duplicate: the originals stay put, a translucent ghost follows your cursor, and the copy lands where you release, all in one undo step.
- **Shift + arrow keys** nudge the selection in big (10px) steps.

## Turning shortcuts off

Shortcuts are handy, but they are not for everyone: if you dictate into the browser, or share it with something that needs the keys, they get in the way. You can switch them off with the **Keyboard Shortcuts** switch at the top of the **Keyboard** category in **Settings**: open **Settings** from the sliders icon in the editor's bottom bar, pick **Keyboard**, and flip the switch.

<Figure caption="Flip the Keyboard Shortcuts switch in Settings so a stray key press never changes your tool.">
  <ShortcutsToggle />
</Figure>

Turning them off switches off the editor's shortcuts, not just the single letters: the tool keys, `Delete`, `Escape`, and the chords such as `⌘Z` and `⌘C` all stop, and the browser's own behaviour for those keys comes back. A few keep working because they are part of how the canvas is driven rather than shortcuts: pasting with `⌘V` (it goes through the browser's own paste), `Space` + drag to pan, and holding `⌘` to show the palette's badges. Use the on-screen controls (undo and redo sit in the bottom-right corner) while they are off. This choice is saved in your browser and, unlike most preferences, deliberately stays per device rather than following you across sign-in: that way you can keep shortcuts on where you have a full keyboard and off on a device where you don't.

The editor is also careful about context: even with shortcuts on, typing into a text label or an input never triggers a tool key. A `v` typed into a label is just a `v`, never a switch to Select.

<Tip>
  If a single key keeps switching your tool while you work, open **Settings** on the **Keyboard**
  category and flip the switch at the top to turn shortcuts off. You can turn them back on the
  moment you want the speed again.
</Tip>
