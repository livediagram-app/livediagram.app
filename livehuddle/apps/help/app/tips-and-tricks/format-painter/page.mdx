The format painter copies the styling of one element and applies it to others, so a board stays visually consistent without re-dialling every colour, border, and text setting by hand. Style one element exactly how you want it, then spread that look across the canvas.

## Painting a style

The format painter is the **Format Painter** button on the selection toolbar, the small toolbar above an element you have selected. Pressing it opens the **Format** panel, and a message under the palette strip guides you:

<Step n={1}>
  Select the element whose look you want to reuse, and press **Format Painter** on its toolbar. The
  brush takes that element's style, and the panel's preview shows it.
</Step>

<Step n={2}>
  The message under the strip then asks you to tap elements to paint the style onto them. Every
  element you click now takes on the base element's formatting, and the base stays loaded so you can
  keep going.
</Step>

Click **Done** in the message, press `Escape`, or click empty canvas to put the brush down.

## Choosing what it copies

The **Format** panel decides what the brush carries. Under **Copies**, five switches, all on by default:

- **Fill**: the fill colour, a header's fill, and its theme preset.
- **Border**: stroke colour, width, pattern and corners.
- **Text**: colour, size, weight, italic, underline, strikethrough, font and alignment.
- **Effects**: shadow, opacity, and animations.
- **Size**: width, height, aspect-ratio lock, padding, and an icon's size and weight.

Switch every one off and the panel warns you that the brush has nothing to paint.

Under **After painting**, **Keep the brush** (the default) paints one element after another, and **Paint once** empties the brush after a single apply, for a quick one-off.

## How painting works

The target ends up looking like the source in everything the brush carries that the source has, defaults included. If the source uses the theme's colour and the target is red, painting turns the target back to the theme colour rather than leaving the red in place. The same goes for shadows, borders, and text styling. Painting between different kinds of element carries what they share: an image source, say, has no border or text to give, so the target keeps its own. Text formatting you applied to part of the target's label (a bold word, a coloured phrase) gives way to the painted style too; links in the label stay.

One thing stays put by design: the painter never touches position, so where your elements sit on the canvas is never disturbed. Each paint is an ordinary edit, so `⌘Z` undoes it.

Because it only changes elements, the format painter is available to Editors only: Participants and view-only visitors don't get it. It sits on the selection toolbar, so there is nothing to press until you have selected something.

<Tip>
  Build one "reference" element with the exact colours, border, and text you want, then use the
  Format tool to bring every related element into line in a few quick clicks. Switch **Size** off
  first if the targets should keep their own dimensions.
</Tip>
