Auto-Align is the gentle tidier. It rounds every boxed element's size to a 10 px grid and lines elements up on the grid by the edges and centres they already (nearly) share, so sticky notes and pictures that were almost aligned become exactly aligned and tiny drift collapses, while what was already lined up stays lined up. The use case is "these things are a few pixels off", not "this board has no layout".

## What it does

- It **keeps what is lined up, lined up.** Elements whose centres or edges sit within a few pixels of each other snap onto one shared grid line, so a column of notes of different widths stays centred.
- It **keeps even spacing even.** Rows of notes that were an equal step apart stay an equal step apart.
- It **never moves anything far**: an element moves at most the few pixels to the line it already nearly shares, so a note that was roughly in place stays roughly in place, only neater.
- It **never makes things worse.** A snap that would make two elements overlap is skipped for both.
- It works on **every element on the active tab**, not just a selection.
- **Elements keep their proportions.** A square note stays square and a wide picture stays wide. An element whose aspect ratio you locked keeps its ratio.
- **Running it again changes nothing.** Once a tab is tidy, Auto-align says the tab is already tidy and moves nothing.

## Running it

<Step n={1}>
  Open the [command palette](/help/search-panel/the-search-panel/command-palette/) (⌘K / Ctrl+K) and
  type **Auto-align**.
</Step>

<Step n={2}>Choose **Auto-align to Grid** under the palette's **Actions**.</Step>

<Step n={3}>Everything on the tab snaps to the grid in a single undoable step.</Step>

If the result isn't what you wanted, one undo (⌘Z / Ctrl+Z) restores the previous positions exactly. Auto-Align needs edit access.

## When to use it

Reach for Auto-Align when the board already looks right and you just want it crisp: rows of notes that should share a baseline, rooms that should share an edge, pictures that should be the same size. It tidies what is there; it never invents a layout, so a board that needs one is still yours to arrange.

<Tip>
  Auto-Align is safe to run often. Since running it again changes nothing and it never moves
  anything far, it's a low-risk way to keep a board looking tidy as you work.
</Tip>
