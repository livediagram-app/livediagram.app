## How to run it

Press the **Tidy Up** button (the broom in the bottom-right corner, just left of the Theme & canvas button) and choose **Auto-align** in its panel. Rest the mouse on it first and the tab is tidied behind the panel, so you can see the result before you commit; move away and everything goes back.

You can also open the [command palette](/help/search-panel/the-search-panel/command-palette/) (⌘K / Ctrl+K), type **Auto-align** and pick **Auto-align to Grid** under **Actions**. It runs on the whole active tab as a single undoable step, so if the result isn't what you hoped, one undo puts everything back exactly as it was.

<Figure caption="Typing layout in the command palette lists the tidiers under Actions.">
  <SearchCommandPalette />
</Figure>

Tidying is for editors: it isn't offered to a participant or in a view-only session.

<Note>
  Tidying works entirely offline and deterministically. It never calls out to anything, so it's
  always available.
