# Document

Follow the references below only as needed; never upfront.

- ./document.md - when naming things: a document holds tabs, a tab holds pages; one tab kind and one editor mode (Pages)
- ./document-structure.md - when working on Document structure: Documents contain tabs; elements can link across tabs
- ./per-tab-storage.md - when working on Per-tab storage: Split tabs into their own rows so autosave scope shrinks
- ./tab-document-many-to-many.md - when working on Tab ↔ document many-to-many: Link table so a tab can live in multiple documents
- ./tab-folders.md - when working on Tab folders: Group a document's tabs into one-level named folders that fan out from one chip
- ./document-snapshots.md - when working on Document previews: livedocuments renders for liveworkspace's previews (the export door, an SVG of the first tab or one tab, drawn on request in the document's Durable Object); the platform stores and serves the Explorer thumbnail, the live image and the share card
- ./layers.md - when working on Layers: Photoshop-style per-tab layers: Tab.layers bands + element layerId, active layer receives new elements, visibility/lock/reorder, band-scoped z-order, a Layers panel (a popover over its bottom-right cluster button), hidden layers excluded from exports behind an export-dialog toggle
- ./offline-mode.md - when working on Offline Mode: Per-document mode (the This Browser save location, chosen on purpose with Take Offline) that saves only to the browser (IndexedDB), never to the API, and opens instantly without waiting on the server — images embedded locally, server-only features (teams / AI / live) hidden and Share explaining and offering Sync Document, which converts the open document in place with no reload, an "Offline" badge in the header + Explorer. Convertible both ways: "Save to your account" (Offline → Cloud) and "Take offline" (Cloud → Offline, deleting the server copy, with confirmation). Folded into the marketing privacy area + a help article
- ./name-length.md - when working on Tab and document name length: Tab + document names capped at 60 chars with whitespace collapsed and word-boundary ellipsis truncation; enforced by the api worker on every stored name (editor, API tokens, MCP, copies) and at the editor's mutation points (auto-naming, renames, /new wizard) with `maxLength` on the inputs as a visible second line of defence
- ./save-locations.md - when working on Save Locations: The New Document wizard's "Save Offline, This Browser Only" toggle becomes a **Save location** row of tiles (livedocuments, the default for everyone, and This Browser), built on the same `PlacementCard` as the Save In row so the two read as one family. A toggle could only ever answer yes or no; a catalogue (`lib/save-locations.ts`, `NewDocumentSettings.saveLocation`) is what a third store (GitHub, say) can be added to as one entry, one glyph, and one create branch. Only shipped locations are shown, no "coming soon" tiles
- ./stroke-points.md - when reading or writing a freehand stroke's points: the `packedPoints` binary block (16-bit x, y and optional 8-bit pressure per point, base64), its precision guarantee, lazy memoised decoding, validation rejections and the migration of stored `{ nx, ny }` points
- ./blueprints/README.md - when implementing or changing a document-model feature from its blueprint
