- ./last-seen-copy.md - when implementing or changing the last seen copy a cloud document warm-opens from: keeping, forgetting, clearing and reading it
- ./version-history.md - when implementing or changing version history: the tab_versions table and its triggers, the named versions in the snapshots store, the routes, restore and copy, the editor's panel
- ./DEFAULTS.md - when a document blueprint applies a default the spec leaves open
- ./COMPLETENESS.md - when checking which completeness categories a document blueprint covers
