# Editor

Follow the references below only as needed; never upfront.

- ./editor-app.md - when working on Editor app: the Pages editor app (clean routes, no `/live` prefix)
- ./load-recovery.md - when working on a document that will not load: the load's watchdog and time limits, the opening screen's self-healing reload, the load-error screen's recovery card (Copy Diagnostics, Repair This Browser), what a repair clears and keeps, and the help centre's Repair page
- ./start-diagramming.md - when working on an empty tab's template start (Start Making Pages): when it shows, Recommended and groups, search, the palette tray's Show Templates, the hidden first page and deletable last page, the tour waiting, its look
- ./new-document-route.md - when working on Dedicated route for new-document creation: The welcome / create-new flow at `/new`, split from the editor
- ./user-preferences.md - when working on User preferences: Per-user editor preference flags (footer settings dialog)
- ./split-view.md - when working on Side by side tabs: dragging a tab to the right edge to open it beside the active tab, each tab keeping its side under one header, the editor following a click or a resting pointer between panes with no view jump, the live other pane, the drop zone and ghost, resizing, persistence
- ./zen-mode.md - when working on Zen mode: Distraction-free focus mode: hide all chrome, keep canvas + zoom
- ./panel-docking.md - when working on Panel corner docking: Choose which corner each corner panel (AI, Minimap, tool panels) sits in: desktop drag with snap-to-corner guides, free drop kept where released, stacking + reflow within a corner, device-local localStorage layout
- ./command-palette.md - when working on Command palette (⌘K): Cmd/Ctrl+K opens the Search panel; the Actions command registry widens to app-level verbs (undo/zen/layout/dialogs) + a view-safe read-only subset
- ./element-tours.md - when working on element tours: the tour of one complex element type (the Sankey diagram) started from the footer's Start Tour button while its element is selected ("Start Sankey Tour"), its steps on the real element, its menu steps opening the element's menu, the Show Me closed section in Settings, share roles and telemetry
- ./show-me.md - when working on Show Me: the on-demand guided tour of one surface (the Share dialog, the page panel), its button beside Help, live controls, Escape, telemetry tokens, and how to add one to a new surface
- ./toolbar-layout.md - when working on Toolbar layout: The editor's one panel layout, on every device: the Palette as one Excalidraw-style strip at the top of the canvas (the selection mode, then the category bar, each category a button opening a flyout of its tiles; a far-right Search popover finds any element type). The top-left menu button opens the Explorer as a popover; Layers and Collaborate are popovers over their bottom-row buttons; every other panel docks in its corner. The retired Floating layout and `panelLayout` preference
- ./ui-scale.md - when working on UI scale: the Appearance sliders (80% to 120%, 100% in the middle, desktop only) that scale the panels, the toolbar and the bottom-right corner buttons with CSS `zoom`, together or each on its own, and nothing else
- ./power-user-mode.md - when working on Power user mode: a preset of recommended settings that restores untouched ones when switched off, power-user-only settings such as Minimal chrome (hide captions, titles and hints, keep controls), and the once-ever offer
- ./pages-mode.md - when working on pages (infographic, article, slide and flashcard kinds): page sizes, backgrounds and patterns, the page panel, layouts and their hover preview, page actions and reordering, snapping, re-fitting content, putting content onto a page and Split Into Pages, Fit to Content pages, page export, page slides and the Slides button
- ./pages-tour.md - when working on the Pages tour: the optional guided tour of each page kind, started from the footer's "Start Pages Tour" button while in Pages, its steps, Settings replay and telemetry
- ./flashcards.md - when working on flashcards: the flashcard page kind, text-only cards, Too long for this card and Split Onto a New Card, the stack, flipping between cards, the card number and speaking time, Blank Flashcards and the flashcard templates
- ./article-pages.md - when working on article pages: the writing and its blocks, flowing across linked pages, the page toolbar, zones (objects and drawings in the text, wrap), margin notes, article style and looks, export and collaboration of the writing (carets included)
- ./blueprints/README.md - when implementing an editor spec from its blueprint (appearance, pages, article pages, power user mode, UI scale, load recovery)
