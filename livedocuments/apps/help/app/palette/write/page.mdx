The palette's **Write** category holds the elements whose content is _words_. Everywhere else in the palette you place something with a shape and then maybe label it; here the text is the point and the shape is just what carries it.

There is no Page element among them: on a tab of pages the page itself is where you write, and an [article](/help/pages/articles/) is the place for paragraphs. Write holds the words you put _on_ a page.

## What the category contains

- The **text styles**, **Title**, **Subtitle**, **Heading**, **Subheading**, **Paragraph** and **Quote**, each add a free-standing text element with no box around it, already set as that style: a Title is large and bold, a Paragraph is body copy that wraps at its width, a Quote is italic. `T` drops a Paragraph. Use them for titles, column headings, body copy, and anything that labels a _region_ rather than an element, since a shape's own label is the better way to name a shape. A style is only a starting point: restyle the text like any other. See [Text and Fonts](/help/canvas/text-and-fonts/).
- A **Sticky note** is a coloured note card, the one that reads as somebody's contribution rather than the author's structure. `N` drops one. See [Sticky Notes](/help/palette/tools/sticky-notes/).
- A **Pointer note** is a short note with a line out to a dot. Drag the dot onto a corner or edge of a shape and the note follows that shape wherever it moves: use it for "this is where it fails" remarks. See [Pointer Notes](/help/palette/pointer-notes/).

## Picking between them

All of them put their words **on the page**, where everyone reads them without doing anything. The question is what the words belong to.

Text in one of the styles belongs to the page: it is part of what the page says. A Sticky note belongs to whoever wrote it: it reads as a remark or an idea rather than the finished design. A Pointer note belongs to one spot: it says something about a particular element and stays joined to it.

<Note>
  There is another way to attach words, and it is not in this category: any element can carry a
  [comment](/help/collaboration/comments/) thread of its own. It belongs to the element it is on and
  moves with it.
</Note>

## Cards, not pictures

Shapes show as a grid of pictures, because the picture is the explanation. The Write elements are all text, so at tile size they would look nearly alike. In their [palette panel](/help/palette/toolbar-layout/) each one is a card with a one-line description instead, because "the name at the top of a page" against "a note that points at a spot" is what you are actually choosing between.

## Working with them

Each behaves like any other element once placed: select, restyle, lock, [rotate](/help/canvas/rotation/) and move it freely, like anything else on the page.

Text styling is shared with the rest of the canvas rather than special to this category: font, size, weight and alignment all come from the same controls that style a shape's label. See [Text and Fonts](/help/canvas/text-and-fonts/).

<Tip>
  `T` and `N` drop a Paragraph and a sticky note without opening the palette at all: type, `N`,
  type, `N`.
</Tip>
