## List your <Noun plural />

<AppNote app="livehuddle">

A space **list** returns the spaces in your personal library (spaces in a team library are not included), as metadata only, not the tab contents:

```bash
curl https://www.livehuddle.app/api/documents \
  -H "Authorization: Bearer $TOKEN"
```

</AppNote>

```bash
  -H "Authorization: Bearer $TOKEN"
```

</AppNote>

Nodes are **shape** elements with a position and size; this creates one tab with two boxes. Ids are shared across all of <AppName />, not just your account, so use a fresh UUID for the <Noun />, each tab and each folder; an id someone else already holds is refused or swapped for a new one:

</AppNote>

<AppNote app="livehuddle">

`POST /documents` creates a space. You supply the `id`, a `name`, and optionally the `tabs` to seed it with. Each element has a position and size; this creates one tab with two sticky notes. ## Update a tab

Scripts and agents change a tab with a **changeset**: a short list of edit operations, applied together or not at all. Anyone with the <Noun /> open sees the change arrive straight away, it is credited to you, and it can be undone as one unit for 30 days. Changes people make in the editor at the same time are kept.

<AppNote app="livediagram">

```bash
curl -X POST https://www.livediagram.app/api/documents/$DOC/tabs/$TAB/changesets \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "summary": "rename the API box, add a database",
    "operations": [
      { "op": "set", "target": "n2", "fields": { "label": "Orders API" } },
      { "op": "add", "element": { "id": "n3", "type": "shape", "shape": "cylinder", "x": 0, "y": 320, "width": 160, "height": 80, "label": "Orders DB" } },
      { "op": "rm", "target": "n1" }
    ]
  }'
```

</AppNote>

## Delete and restore

`DELETE /documents/$DOC` moves the <Noun /> to the [Trash](/help/account-and-data/trash/), where it waits for 30 days, and answers `204`. While it is there, reading or changing it answers `410 document_trashed`. Add `?permanent=true` to delete it for good straight away.

<AppNote app="livediagram">

```bash
curl -X DELETE https://www.livediagram.app/api/documents/$DOC \
  -H "Authorization: Bearer $TOKEN"

# What you can restore: your own Trash and every team's you belong to
curl https://www.livediagram.app/api/trash \
  -H "Authorization: Bearer $TOKEN"

curl -X POST https://www.livediagram.app/api/trash/$DOC/restore \
  -H "Authorization: Bearer $TOKEN"
```

</AppNote>

<AppNote app="livedocuments">

```bash
curl -X DELETE https://www.livedocuments.app/api/documents/$DOC \
  -H "Authorization: Bearer $TOKEN"

# What you can restore: your own Trash and every team's you belong to
curl https://www.livedocuments.app/api/trash \
  -H "Authorization: Bearer $TOKEN"

curl -X POST https://www.livedocuments.app/api/trash/$DOC/restore \
```

</AppNote>

</AppNote>

<AppNote app="livedocuments">

`DELETE /trash/$DOC` deletes one trashed document for good; emptying the whole Trash happens in the Explorer. A read-only token can list the Trash but not restore or purge.

</AppNote>

<AppNote app="livediagram">

To put a canvas you own away instead, `POST /documents/$DOC/archive` moves it to your Archived: out of every list, with its share links ended. `POST /documents/$DOC/unarchive` brings it back, to the top of My Work, or into the folder or team you name with `{ "folderId": "…" }` or `{ "teamId": "…" }`. `GET /documents?archived=1` lists what is archived.

</AppNote>
