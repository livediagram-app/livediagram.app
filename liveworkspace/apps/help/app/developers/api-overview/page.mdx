## The base URL

The API lives under `/api` on your <AppName /> host. On the hosted service that is:

<AppNote app="livediagram">

```
https://www.livediagram.app/api
```

Every path in these docs is relative to that base, so `GET /documents` means `GET https://www.livediagram.app/api/documents`.

</AppNote>

## Authenticating in one line

Send an API token as a bearer header on each request:

<AppNote app="livediagram">

```bash
curl https://www.livediagram.app/api/documents \
  -H "Authorization: Bearer lwt_your_token_here"
```

</AppNote>

<AppNote app="liveplanner">

```bash
curl https://www.liveplanner.app/api/projects \
  -H "Authorization: Bearer lwt_your_token_here"
```

</AppNote>

<AppNote app="livedocuments">

```bash
curl https://www.livedocuments.app/api/documents \
  -H "Authorization: Bearer lwt_your_token_here"
```

</AppNote>

<AppNote app="livedesign">

```bash
curl https://www.livedesign.app/api/designs \
  -H "Authorization: Bearer lwt_your_token_here"
```

</AppNote>

<AppNote app="livehuddle">

```bash
curl https://www.livehuddle.app/api/documents \
  -H "Authorization: Bearer lwt_your_token_here"
```

</AppNote>

API tokens are a [signed-in-only](/help/account-and-data/signing-in/) feature. [Authentication](/help/developers/authentication/) covers how to create one and how token access compares to the guest path.

## What you can do

The token-callable surface mirrors the app:

<AppNote app="liveplanner">

- **Plans and tabs**: list, read, create, rename, copy, and delete plans; start a tab from a template; read a tab as JSON, as a text view or as an SVG picture; change a tab with changesets, and revert one.
- **Cards and card types**: read, add, change, move and delete the cards (items) a plan's boards show, and change its card types.
- **Folders**: organise plans into folders, personal or in a team you belong to.
- **Sheets**: read and change the cells of a plan's Sheets, their rows and columns, and their titles.
- **Comments**: read, add, reply to, resolve and reopen comment threads, on a tab or on a card.
- **Forms**: build a Form tab's [form](/help/plan/forms/), publish or close its link, and send a test response, the same calls the CLI's `form` commands make.
- **Automations**: list, add, change, switch on and off, test and run a plan's [Automations](/help/plan/automations/) rules, and read their Audit Trail. These need an Editor of the whole plan; a read-only token only lists rules and reads the Audit Trail.
- **Sharing**: create, list, extend and revoke share links, and set or remove a share password.
- **Trash**: list what you can restore, restore it, or delete it for good.

</AppNote>

<AppNote app="livediagram">

- **Canvases and tabs**: list, read, create, rename, copy, and delete canvases; read a tab as JSON, as a text view or as an SVG picture; change a tab with changesets, and revert one.
- **Comments and presence**: read, add, reply to, resolve and reopen comments, edit or delete the ones an agent wrote, and show what an agent is doing on a tab.
- **Folders**: organise canvases into folders, personal or in a team you belong to.
- **Sharing**: create, list, extend and revoke share links, and set or remove a share password.
- **Trash and Archived**: list what you can restore, restore it, or delete it for good; archive a canvas you own and bring it back.
- **Images and shape libraries**: upload and reference images, and manage your shape libraries.

</AppNote>

<AppNote app="livedocuments">

- **Documents and tabs**: list, read, create, rename, copy, archive and delete documents; read a tab as JSON, as a text view or as an SVG picture; change a tab with changesets, and revert one.
- **Comments and presence**: read, add, reply to, resolve and reopen comment threads, and show people what your agent is working on.
- **Folders**: organise documents into folders, personal or in a team you belong to.
- **Pages**: add, change, lay out and move a tab's slides, infographics and flashcards, and write articles from Markdown.
- **Sharing**: create a share link for a document or one tab. Listing, extending and revoking links, and share passwords, are in the Share dialog.
- **Trash**: list what you can restore, restore it, or delete it for good.
- **Images**: upload and reference images.

</AppNote>

<AppNote app="livedesign">

- **Designs and tabs**: list, read, create, rename, copy, archive and delete designs; read a tab as JSON, as a text view or as an SVG picture; change a tab with changesets, and revert one.
- **Components**: list a design's components, make one, and change a main so every instance redraws.
- **Comments**: read, add, reply to, resolve and reopen comments, and show what an agent is doing on a tab.
- **Folders**: list your folders, and create a design straight into one, personal or in a team you belong to.
- **Pages**: add, change, lay out and move a tab's logo, wireframe and photo pages.
- **Sharing**: create, list, extend and revoke share links, and set or remove a share password.
- **Trash**: list what you can restore, restore it, or delete it for good.
- **Images**: upload and reference images.

</AppNote>

<AppNote app="livehuddle">

- **Spaces and tabs**: list, read, create, rename, copy, and delete spaces; read a tab as JSON, as a text view or as an SVG picture; change a tab with changesets, and revert one.
- **Comments**: read the comment threads a space already holds. livehuddle has no comments, so adding, replying and resolving answer `410 comments_gone`.
- **Folders**: organise spaces into folders, personal or in a team you belong to.
- **Sharing**: create, list, extend and revoke share links, and set or remove a share password.
- **Trash**: list what you can restore, restore it, or delete it for good.
- **Images and shape libraries**: upload and reference images, and read the shape libraries you already have (they are read-only now).

</AppNote>
