A <Noun /> spread across many tabs is far more useful when you can move between them from the <Noun /> itself. Any shape, sticky, text box or other boxed element (except a video or embed, whose link is its address) can carry a **link**, and that link can point at another tab in the same <Noun />. Follow it, and the editor jumps you there. It turns a multi-tab <Noun /> into something you navigate like a small site.

## What an element can link to

A single link on an element can target any one of these:

- **A tab** in this <Noun />. Following the link switches to that tab.
- **A file.** Another <Noun />, or a file from any other liveworkspace app. Following it opens that file.
- **An external URL.** Following it opens the address in a new browser tab.

A linked element carries a small link badge (unless your [element indicators](/help/canvas/element-indicators/) are set to Off). Hover it and its card reads **Follow link** and names the target (for example `Goes to tab "DB internals"`), so you can tell where a link leads before you click it. Click the badge to follow the link.

## Linking an element to a tab

<Step n={1}>
  Right-click the element you want to turn into a jump point, open **Resources** at the foot of its
  menu and press **Add Link** (**Edit Link** once it has one).
</Step>

<Step n={2}>
  In the Resources dialog's link list, press **Tab** and pick the target tab. The tab you are on is
  marked **This tab**. **External URL** takes a web address and **Save Link**, and a row for each
  app's files lists your recent ones there, with a search.
</Step>

<Step n={3}>
  Click the element's badge to follow the link. The link travels with the element if you later move
  it.
</Step>

To change or remove a link, open **Resources** on the element again and press **Edit Link**: pick a new target, or press **Remove Link**, last in the list. Arrows can't carry links, and [link cards](/help/canvas/links/) manage their address in their own **Link** section instead.

## When the target tab goes away

Deleting a tab removes every link that pointed at it, so you are never left with a badge that leads nowhere. Renaming or reordering the target tab doesn't affect its links: the hover card always shows the tab's current name.

Some patterns this enables:

- **Drill-down.** A "Database" node on the Overview tab links to a "DB internals" tab, so a click dives into the detail.
- **Deep-dives.** A leaf branch or summary page links to its own tab for deeper structure.
- **Cross-references.** A process step links to the tab where a related decision is written up, with no duplicated content.

Anyone who can open the <Noun /> can follow links, including on a view-only share link; adding or editing links needs edit access.

<Tip>
  For an external address, only http, https, and mailto links are allowed, and https:// is added if
  you leave off the scheme. See [Links and Link Cards](/help/canvas/links/) for more on linking
  elements to the web.
</Tip>

<AppNote app="livedesign">
  On a [wireframe](/help/pages/wireframe-pages/) tab you can also link an element to another screen
  of the tab for a clickable prototype: drag the round link handle from the selected element onto a
  screen, or press it to open the **Link Element** dialog on its **Screen** choice. A Participant
  can set a Screen link on an element of their own; every other link needs edit access.
</AppNote>
