The [search panel](/help/search-panel/the-search-panel/) isn't only for finding things, it's also a **command palette**: type the name of an action and run it, without hunting through menus. If you've used ⌘K in tools like VS Code, Linear, or Slack, this is the same idea.

## Opening it

- **Keyboard:** press `Cmd` / `Ctrl` + `K` anywhere in the editor. The older `Cmd` / `Ctrl` + `.` opens the same panel; they're interchangeable.
- **Button:** open **Tools** in the bottom bar and choose **Search…**.
- It works in **read-only** views, just like opening search.

<AppNote app="livedesign,livediagram,livedocuments,liveplanner">
  It also works in **[zen mode](/help/tools/zen-mode/)**.
</AppNote>

<AppNote app="livedesign,livediagram,livedocuments,livehuddle">
  The conventional command-palette shortcut is `⌘K`, so it's the one to reach for. **Search…** is
  the first row of the **Tools** menu.
</AppNote>

<AppNote app="liveplanner">**Search** in the bottom bar opens it too.</AppNote>

The palette and search are one surface, so you can find a <Noun /> and run a command from the same box. Commands only exist inside a <Noun />: on the Explorer page, search finds things but has no actions to run.

## Running a command

Start typing and matching commands appear in an **Actions** group, below any <Noun plural />, tabs or elements that also match. Click the one you want, or arrow down to it and press `Enter`. Commands match on their name and on a few related words. At most 10 actions show at once, so type a little more to narrow a long list.

<AppNote app="livedesign,livediagram,livedocuments">
  "tidy" finds Auto Layout and "front" finds Bring to Front.
</AppNote>

<AppNote app="livehuddle">
  "tidy" finds Auto-align to Grid and "front" finds Bring to Front.
</AppNote>

<AppNote app="liveplanner">
  "download" finds Export… and "hotkeys" finds Keyboard Shortcuts. Actions sit below any plans or
  tabs that also match.
</AppNote>

<AppNote app="livediagram">
  Type several words and each one only has to appear somewhere: "export png" finds Export….
</AppNote>

Commands only show once you've typed something, so an empty box just lists places to jump to and never runs an action by accident.

<AppNote app="livedesign,livediagram,livedocuments,livehuddle">
  Because the Actions group sits below the navigation groups, the preselected first result is still
  a place to go when your query also names a tab or element; arrow down to the command to run it
  deliberately.
</AppNote>

Every command does exactly what its menu item or shortcut does: it's the same action under a different name, so nothing behaves differently depending on how you reach it.

## What you can run

The list follows what you're doing, so it only offers commands that apply right now:

## In read-only views

When you're on a Viewer or Participant share link, the palette still offers the actions that don't change anything. Every command that would change the <Noun /> simply isn't listed.

<AppNote app="livedesign">
  The palette still offers Enter or Exit zen mode, Fit to Screen, Export…, Collaborators, and the
  tools that only change how you look at the canvas (Select, Hand, Laser Pointer and Spotlight, plus
  the Inspect Tool and Show or Hide Flow View on a wireframe tab). The Eraser Tool and the Format
  Painter aren't listed.
</AppNote>

<AppNote app="livediagram">
  The palette still offers Enter or Exit zen mode, Fit to Screen, Export…, Collaborators, and the
  tools that only change how you look at the canvas (Select, Hand, Laser Pointer, Spotlight and
  Isometric View). The Eraser, the Format Painter and Slide Deck aren't listed.
</AppNote>

<AppNote app="livedocuments">
  The palette still offers Enter or Exit zen mode, Fit to Screen, Find in Tab, Export…,
  Collaborators, and the tools that only change how you look at the canvas (Select, Hand, Laser
  Pointer and Spotlight). A Participant also gets Find and Replace, since they may edit the text.
  The Format Painter isn't listed.
</AppNote>

<AppNote app="livehuddle">
  The palette still offers Fit to Screen, Export… and Collaborators. Participants and Viewers are
  always walking, so Walk is never offered, and nothing takes them out of it.
</AppNote>

<AppNote app="liveplanner">
  On a Viewer or Participant link, the palette keeps the commands that change nothing: Enter or Exit
  zen mode, Export… and Collaborators.
</AppNote>

<Tip>
  Forgotten a shortcut? Open the palette with `⌘K`, type the first few letters of what you want to
  do (like "export" or "layout"), and run it, no need to remember where it lives.
</Tip>
