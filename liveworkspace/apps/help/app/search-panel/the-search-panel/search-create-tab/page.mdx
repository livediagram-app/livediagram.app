As well as finding things, the [search panel](/help/search-panel/the-search-panel/) can run **actions**: editor commands offered as results. One of the handiest is creating a [tab](/help/tabs/using-tabs/): when you are inside a <Noun /> and your query looks like you want a new tab, search offers a **Create New Tab** result.

## When it appears

The action surfaces when your query matches its name or keywords, for example typing `tab`, `new`, `create`, `add` or `page`. It only shows inside a <Noun /> you can edit, where there is something to add a tab to: never from the Explorer page, and never for a Viewer or Participant.

<AppNote app="livediagram,liveplanner,livehuddle">
  The keywords also include `sheet` and `board`.
</AppNote>

**Create New Tab** is an ordinary editor command, listed in the **Actions** group of the results. That group sits below the navigation matches, so an actual match still wins the default `Enter`, and you arrow down to the command to choose it deliberately. When nothing else matches, the action is the first result and `Enter` runs it straight away.

## What it does

Picking **Create New Tab** does exactly what the `+` button at the end of the tab bar does:

- It adds a new tab named "Tab" plus one more than the number of tabs (Tab 3, Tab 4, ...) at the end of the tab bar, and switches to it.
- The new tab takes the current tab's look, so it matches the rest of the <Noun />.
- It opens on a start screen, so you can begin from a template or close it for a blank start.

<AppNote app="livedesign,livedocuments">
  The new tab takes the current tab's theme, canvas background and font, and opens on **Start Making
  Pages**, so you can begin from a template or close it for one empty page. See [Working with
  Pages](/help/pages/working-with-pages/).
</AppNote>

<AppNote app="livediagram">
  The new tab takes the current tab's theme, canvas background and font, and opens in the current
  tab's mode (a Draw tab makes a Draw tab, a Workshop tab a Workshop tab), on that mode's own start,
  so you can begin from a template or close it for a blank canvas.
</AppNote>

<AppNote app="livehuddle">
  The new tab takes the current tab's theme, canvas background and font, and opens on its start, so
  you can begin from a template or close it for a blank canvas.
</AppNote>

<AppNote app="liveplanner">
  It opens on **Start Planning**, where you pick a Board, Sheet, Dashboard or Form for it, from a
  template or blank. See [Planning Basics](/help/plan/planning-basics/).
</AppNote>

From there it is an ordinary tab: rename it, fold it into a [folder](/help/tabs/tab-folders/), or start working in it. Changed your mind? Delete the tab from its tab menu.

<Tip>
  Think of search actions as shortcuts for "I know what I want to do". The panel doubles as a
  [command palette](/help/search-panel/the-search-panel/command-palette/): alongside creating a tab,
  it can run many other editor actions, from renaming the tab to sharing the <Noun />, all matched
  the same way.
</Tip>
