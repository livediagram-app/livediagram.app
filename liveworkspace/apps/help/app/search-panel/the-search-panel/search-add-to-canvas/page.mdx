Inside the editor, the [search panel](/help/search-panel/the-search-panel/) is not only for getting around, it can also add to the canvas. Alongside the navigation results, your query is matched against the [palette](/help/palette/) catalogue, so you can place an element by name instead of hunting for it in the palette.

## Add to canvas

When a search matches a palette item, it appears in an **Add to canvas** group, each row marked with a plus-in-a-box. Picking one closes the panel and does what pressing the tile does.

<AppNote app="livedesign,livedocuments">
  Every palette tile is searchable: shapes, text, sticky notes, tables, charts, images, embeds, concept graphics and components, plus every icon and sticker. Most arm the same tap-or-drag placement the palette uses, so you then drop the element exactly where you want it. It is the quickest route from "I need a rocket icon" to having it on the page.
</AppNote>

<AppNote app="livediagram">
  Every palette tile is searchable: shapes, text, arrows, sticky notes, tables, images, embeds, web components, and event-storming notes, the pens, plus every icon, sticker, and technology icon. Most arm the same tap-or-drag placement the palette uses, so you then drop the element exactly where you want it, and a pen arms drawing. It is the quickest route from "I need an AWS Lambda icon" to having it on the board.
</AppNote>

<AppNote app="livehuddle">
  Every palette tile is searchable, and nothing else is: sticky notes, text, images, link cards, the Space pieces (portals, the Avatar button, furniture, rooms and amenities), plus every icon and sticker. Each arms the same tap-or-drag placement the palette uses, so you then drop the element exactly where you want it. It is the quickest route from "I need a coffee machine" to having it on the board.
</AppNote>

Picking a result does exactly what clicking the same tile in the palette does, so the element arrives with the same defaults and you can undo it with `Cmd` / `Ctrl` + `Z` like any other addition.

## How matches are ranked

Items match on their name and on everyday synonyms. The element you actually named comes first: an exact name match, then names that start with what you typed, then names that contain it, and finally items that only match on a synonym. Up to 10 items are listed; type a little more to narrow a long list.

<AppNote app="livedesign,livedocuments">
  So "database" finds the cylinder, and "table" lists the Table before anything whose description merely mentions tables.
</AppNote>

<AppNote app="livediagram">
  So "database" finds the cylinder and "swimlane" finds the lane, and "table" lists the Table before anything whose description merely mentions tables. Where an emoji sticker shares its name with an icon (Gift, Rocket), search lists the icon once; the sticker is still in the palette's Stickers.
</AppNote>

<AppNote app="livehuddle">
  So "post-it" finds the sticky note and "couch" finds the sofa, and "table" lists the Meeting Table before anything whose description merely mentions tables.
</AppNote>

The group only appears once you have typed something (an empty box never dumps the whole palette), and it sits below the <Noun plural />, tabs, elements and actions that match, so `Enter` still goes to a real match first. Arrow down to the item you want, or click it.

## Why search the palette

The palette groups its contents into categories, which is great for browsing but slower when you already know what you want. Searching by name skips the browsing, and you place it.

<AppNote app="livedesign,livedocuments">
  The categories include Shapes, Components, Icons and Media. Type "cylinder", "table", "pie" or an icon's name. For the palette and its categories, see [The Palette](/help/palette/).
</AppNote>

<AppNote app="livediagram">
  The categories include Shapes, Components, Devices, Icons and Tech. Type "cylinder", "table", "arrow", or a cloud service name. For the palette and its categories, see [The Palette](/help/palette/) and [Technology Icons](/help/palette/technology/).
</AppNote>

<AppNote app="livehuddle">
  The categories include Write, Rooms, Seats, Travel and Stickers. Type "sofa", "plant", "confetti", or a sticker's name. For the palette and its categories, see [The Palette](/help/palette/).
</AppNote>

## When it is not offered

- **Outside a <Noun />:** from the Explorer, search sticks to finding what you can open, folders, teams, help and settings. There is no canvas to add to.
- **As a Viewer or Participant:** Add to canvas results are left out.

<AppNote app="livedesign,livediagram">
  A Participant adds stickies and text from the palette's Participate category instead.
</AppNote>

<AppNote app="livedocuments">
  Neither can add to the canvas.
</AppNote>

<AppNote app="livehuddle">
  Neither adds anything to the space.
</AppNote>

<AppNote app="livedesign,livediagram,livedocuments">
  **Images:** the image tiles (Image, Avatar, Hero) only appear where the editor can upload images, as in the palette.
</AppNote>

<Tip>
  The icon catalogues load in the background when the editor opens. If you search in the first
  moments after opening a <Noun />, icon results join the list as soon as they arrive, with no need to
  reopen search.
</Tip>
