<AppName /> gives you a curated set of eleven typefaces so a <Noun /> can read as crisp, friendly,
formal, or hand-drawn without becoming a font free-for-all. You can apply a font to one element or
set it as the default for a whole tab, and the two levels work together so you only set what you
actually want to override.

## The Eleven Fonts

The set spans a deliberate spread of voices:

- **Inter**: a clean, neutral sans-serif for everyday <Noun plural />.
- **Poppins**: a geometric sans with a modern feel.
- **Nunito**: a rounded sans that reads as friendly.
- **Oswald**: a condensed sans with headline presence.
- **Space Grotesk**: a grotesque sans with a technical edge.
- **Lora**: a serif for a more formal, editorial look.
- **Bodoni Moda**: a high-contrast display serif for bold statements.
- **Roboto Slab**: a slab serif with extra weight and presence.
- **Roboto Mono**: a monospace, handy for code or technical labels.
- **Kalam**: a handwriting face for a sketched, informal feel.
- **Shantell Sans**: a marker-pen face for loud, hand-drawn emphasis.

Both pickers show each name in its own typeface, so you can see the voice before you choose it.

## Setting a Font on One Element

Right-click the element, open **Appearance**, then **Text**, and expand **Font**. Click a tile to set that typeface on the element alone; with a mouse, hovering a tile previews it on the canvas first. The **Text** section only appears once the element has a label, so type something first. Select several elements and the multi-selection menu's **Text** row sets the font on all of them at once.

<AppNote app="livediagram,livehuddle">
  You can press the **More** button on the element's toolbar instead, which is the way in on a touch
  screen. In the multi-selection menu, Text is in the menu itself, not under Appearance.
</AppNote>

## Setting a Tab Default

To set the typeface for everything on a tab at once, open the **Tab Style** dialog, and press **Text** under **Fine-tune** to open its panel. The **Tab Style** bar across the panel's top returns you to the dialog's home.

<AppNote app="livediagram,livehuddle">
  Open it with the **Theme & Canvas** button in the bottom-right corner of the editor (named
  **Style** on a wide screen).
</AppNote>

<AppNote app="livedesign">
  Open it with the **Theme & Canvas** button in the bottom-right corner of the editor.
</AppNote>

<AppNote app="livedocuments">Open it with the **Style** button on a page's title bar.</AppNote>

- **Preview** at the top shows a small sample in the tab's font, size and finish.
- **Typeface** is a carousel of cards, six to a page, each showing its name in its own face. Picking one letters the whole tab in it at once: it becomes the tab's font, and any element that had its own font follows the tab again. **Editor default** clears the tab font, back to <AppName />'s built-in face.
- **Size of New Text** has the **Text Size** slider with the **Scale** icon beside it. The preview follows the slider as you drag. Setting a size sets every label already on the tab to it, and each element you add from then on takes it too. A new <Noun /> starts at Small, and a tab you add takes the font and size of the tab you added it from.

<AppNote app="livediagram,livedesign,livehuddle">The slider runs from 6 to 48 pixels.</AppNote>

<AppNote app="livedocuments">The slider runs from 24 to 72 pixels.</AppNote>

Every pick is an ordinary edit, so undo takes it back.

## How the Levels Combine

Any piece of text resolves its font in order: an element's own font wins first, then the tab's default, then <AppName />'s built-in face. This means you can set one tab-wide typeface and only override the few labels you want to stand out.

<AppNote app="livediagram">
  Notes on an [event storming board](/help/canvas/event-storming-boards/) are the one twist: they
  are written in a marker face unless you give them a font of your own.
</AppNote>

<AppNote app="livediagram,livedesign,livedocuments">
  Arrows follow the same rules: there is no font picker for them, so they normally use the tab
  default, but a font applied another way (for example with the [format
  painter](/help/selection-modes/format-painter/)) sticks to the arrow like any other override.
</AppNote>

Fonts travel with your work: exports to PNG, SVG and PDF carry the faces you used.

<Tip>
  Text stays visible in a fallback face while a font loads, so your <Noun /> is always readable,
  even offline or where Google Fonts is blocked.
</Tip>
