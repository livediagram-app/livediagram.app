## Editing Labels

Shapes, text elements and sticky notes can all carry text, so you can annotate a <Noun /> wherever you need to. There are a few ways in:

- **Double-click** an element to edit its label.
- With one element selected, press `Space` to start editing its label, or **just start typing**: the first character replaces the existing label.

<AppNote app="livediagram,livedesign,livedocuments">
  Table cells and arrows carry text too: double-click an arrow to edit its caption, or a table cell to edit that cell.
</AppNote>

<AppNote app="livediagram,livehuddle">
  - **Double-click empty canvas** to drop a new text element right there and start typing in it. On a touch screen, a double-tap with your finger zooms in instead; use the palette's Text to add text there.
  - Press `T` (or pick Text from the palette) to add a text element, then tap or drag on the canvas to place it.
</AppNote>

<AppNote app="livedesign">
  - **Double-click empty canvas** to drop a new Paragraph right there and start typing in it. On a touch screen, a double-tap with your finger zooms in instead; use a text style from the palette's Write to add text there.
  - Press `T` to add a Paragraph, or pick a text style from the palette's **Write** (Title, Subtitle, Heading, Subheading, Paragraph, Quote or Caption), then tap or drag on the canvas to place it. A text's right-click **Text** menu switches it to another style under **Text Style**; see [Write Elements](/help/palette/write/).
</AppNote>

<AppNote app="livedocuments">
  - **Pick a text style from Write**: **Title**, **Subtitle**, **Heading**, **Subheading**, **Paragraph** or **Quote**. Each starts set as that style (a Title is 64 pixels and bold, a Paragraph 24), and then tap or drag on the page to place it: a drag sets how wide it is, so it wraps there. A heading's box fits its words; a paragraph or a quote wraps at its width.
  - **Double-click empty canvas** to drop a Paragraph right there and start typing in it. On a touch screen, a double-tap with your finger zooms in instead; use a style from Write to add text there.
  - Press `T` to add a Paragraph, then tap or drag on the canvas to place it.
</AppNote>

Labels can run over several lines: `Enter` starts a new line. Click outside the element or press Escape to finish: either keeps what you typed, and undo takes it back. While you edit, a small toolbar above the element formats the words you select (bold, italic, underline, strikethrough, headings and lists, alignment and colour); see [Formatting Label Text](/help/canvas/text-and-fonts/formatting-label-text/). Edits go through the normal history, so undo and redo cover label changes like any other edit.

<AppNote app="livediagram,livedesign,livedocuments">
  In an arrow caption `Enter` finishes the edit instead, and `Shift+Enter` starts a new line.
</AppNote>

<AppNote app="livediagram">
  A [mind map](/help/palette/mind-maps/) node is the same, since there `Enter` adds the next node.
</AppNote>

<AppNote app="livedocuments">
  New text is always **left aligned**, the way a document reads. Change it from the right-click menu: **Appearance**, then **Text**, then **Alignment**. A style's size is where it starts: restyle it like any other text.
</AppNote>

## Per Element or Per Tab

Fonts work at two levels. You can set a font on a single element so one label stands out (from the **Text** section of its right-click menu), or set a default for the whole tab so every label shares the same typeface unless it overrides it (from the **Text** panel of the **Tab Style** dialog). The tab default also covers a default text size for new elements, keeping a fresh canvas tidy. [Choosing Fonts](/help/canvas/text-and-fonts/choosing-fonts/) explains how an element falls back to the tab's font when it has none of its own.

<AppNote app="livediagram,livedocuments,livehuddle">
  The **Text** section sits under **Appearance**.
</AppNote>


## Text Size

An element's text size lives beside its font, in the right-click menu's **Text** section. Drag the **Text Size** slider, or press the **Scale** icon to the right of it to fit the text to the element instead. The text changes as you drag and settles when you let go, so one drag is one undo. The arrow keys move it a pixel at a time. The same slider sets the tab's size for new text. New elements take the tab's default size, which starts at Small on a fresh canvas.

<AppNote app="livediagram,livedesign,livehuddle">
  The slider covers any size from 6 to 48 pixels, with marks at 6, 12, 24, 36 and 48 to guide you.
</AppNote>

<AppNote app="livediagram">
  The **Text** section is under **Appearance**.
</AppNote>

<AppNote app="livediagram,livedesign,livedocuments">
  The same slider sets an arrow's caption, a table cell and a chart's key.
</AppNote>

<AppNote app="livedocuments">
  An element's text size lives beside its font, under **Appearance**, then **Text**, in the right-click menu. Drag the **Text Size** slider to any size from 24 to 72 pixels for a text element or a shape, with marks at 24, 36, 48, 60 and 72 to guide you (a sticky note, an arrow's caption, a table cell or a chart's key runs from 6 to 48, since those are small print), or press the **Scale** icon to the right of it to fit the text to the element instead. Text that is smaller than the slider, from before or from a template, keeps its size until you move the slider. New elements take the tab's default size, which starts at Small on a fresh canvas; a text style from **Write** keeps its own.
</AppNote>


## Text Colour

A text element's colour is in its right-click menu under **Appearance**, then **Colours**. **Reset to Theme** puts the theme's text colour back. To colour only some of the words, select them while editing and use the colour swatch on the editing toolbar.

<AppNote app="livediagram">
  The colour is also one click away in the [Quick Style Panel](/help/canvas/quick-style-panel/) while the element is selected.
</AppNote>

<AppNote app="livedesign,livedocuments">
  The colour is also one click away on the [Quick Style bar](/help/canvas/quick-style-panel/) while the element is selected.
</AppNote>


<Tip>
  Switching the [theme](/help/canvas/themes/) only recolours your <Noun />, it never changes your
  fonts, so the typefaces you pick stay put when you restyle.
</Tip>
