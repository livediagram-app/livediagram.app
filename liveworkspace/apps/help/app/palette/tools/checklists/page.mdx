A checklist is a card of checkable to-do rows, a visual home for the task lists that end up in plans. It is a real canvas element, so you can place, resize, recolour, lock and move it like anything else, and its colours follow the tab's [theme](/help/canvas/themes/) like any shape.

## Ticking rows

Clicking a checkbox on the canvas toggles that row, no edit mode needed. Done rows tick the box, **strike through** the text, and mute it, and a **done count** (for example "2/5") appears in the card's bottom-right corner once at least one row is done.

Ticks **sync live**, so in a shared session everyone sees a box tick the moment it is clicked, and two people ticking different rows at once both land. A tick is the room's answer rather than an edit, so it is **not undoable**: click the box again to untick it. A tick changes the shared list, so only Editors can tick: for a Participant or a Viewer, or on a locked checklist or tab, the boxes don't respond.

<AppNote app="livediagram">
  The boxes also don't respond on a locked layer.
</AppNote>

## Editing the rows

Right-click the checklist and open **Checklist** to edit the rows: retitle any row, toggle its done state, remove it with **×** (a checklist keeps at least one row), or **+ Add Row** (up to 30 rows per checklist, each up to 200 characters). Text, add and remove edits commit as normal undoable changes; the done toggle here is a tick like the canvas box, so it isn't undoable. Double-clicking the card does nothing on purpose: the boxes are the only thing to click on the canvas.

The card's colours follow the tab's theme like any shape, and you can restyle it from **Appearance** in the same menu.
