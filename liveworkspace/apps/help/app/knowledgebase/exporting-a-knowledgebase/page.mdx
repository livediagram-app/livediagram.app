Your pages are yours to take anywhere. Export the page you are reading, or download a whole Knowledgebase as a `.zip` of Markdown files to move it into Confluence, Notion, Obsidian or a Git repository.

## Export a Page

<Step n={1}>
  Open the page.
</Step>

<Step n={2}>
  Press the Knowledgebase's name at the top of the sidebar and choose **Export**.
</Step>

<Step n={3}>
  Choose a format.
</Step>

<Figure caption="Export: the formats the open page saves to, and Markdown Folder for the whole Knowledgebase.">
  <ExportFormatsScene />
</Figure>

| Format       | What you get                                                                                 |
| ------------ | -------------------------------------------------------------------------------------------- |
| **PDF**      | The page as one PDF, drawn as it stands: one tall page, not split onto paper sheets          |
| **Print**    | The page, or the whole Knowledgebase, sent to your printer, each page its own sheet          |
| **PNG**      | A high-resolution image of the page                                                          |
| **SVG**      | A scalable vector image of the page                                                          |
| **Word**     | A `.docx`, its headings as Word styles; Word lays the writing out on its own paper            |
| **Markdown** | The page's writing as Markdown, in the form Import reads back. Copy it, or save a `.md`       |
| **Markdown Folder** | The whole Knowledgebase as a `.zip` of Markdown files. See below                      |
| **JSON**     | A liveknowledge file that imports back with everything kept                                  |

Every export uses the [Knowledgebase Style](/help/knowledgebase/knowledgebase-style/).

## Export a Whole Knowledgebase

<Step n={1}>
  Press the Knowledgebase's name at the top of the sidebar and choose **Export**.
</Step>

<Step n={2}>
  Choose **Markdown Folder**, then **Download .zip**.
</Step>

The zip is built in your browser, a page at a time; a bar shows how far it has got, and **Cancel** stops it. When it is done it downloads as `<Knowledgebase name>.zip`:

- One `.md` file a page, named after its title, and a page's subpages in a folder of its name.
- Each file opens with the page's title, owner, last update, verification date and labels (as front matter), then the title as a heading and the writing.
- Links between pages as relative links, so they work in any Markdown viewer and import back as page links. A `[[Title]]` and a copied link to a page become links too.
- Pictures, cover pictures included, as files under `pictures/`. A picture that could not be read keeps its description, and the panel says how many.
- Connected files are left out: they belong to other apps.

To bring it back, or into another Knowledgebase, use **Import** and **Markdown Folder** with the `.zip`. See [Import From a Markdown Folder](/help/knowledgebase/import-a-markdown-folder/).

The CLI writes the same files to a folder, to keep beside a repository:

```bash
liveknowledge export Handbook docs/handbook
```

`liveknowledge export --all --to backup` writes every Knowledgebase you can read instead. See [The liveknowledge CLI](/help/developers/liveknowledge-cli/).

## Other Copies of Your Work

- **Google Drive:** keep a copy of every Knowledgebase in your own Drive. See [Google Drive](/help/account-and-data/google-drive/).
- **Your Data:** in Settings, under Account, **Download All My Data** makes one zip of everything you own in every liveworkspace app, and emails you a link when it is ready.

## Good to Know

- A PDF of a page is one tall page. Splitting it onto A4 sheets is not offered yet: use **Word** or **Print** for paper.
- Markdown export leaves out what Markdown cannot hold, and the panel names what was left out.
- Export never changes the page.
- A link that opens only one page exports that page alone: Markdown Folder is offered to people who can read the whole Knowledgebase.
