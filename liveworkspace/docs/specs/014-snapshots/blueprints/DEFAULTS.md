# Snapshots blueprint defaults

One row per default applied where the spec is silent. Each code is cited in the blueprint's "Defaults ledger".

| #    | Blueprint | Default applied                                                                                                            |
| ---- | --------- | -------------------------------------------------------------------------------------------------------------------------- |
| SND1 | snapshots | the five kept count automatic `before-revert` snapshots too, so the cap is one number people can read.                     |
| SND2 | snapshots | comment threads on cards and Automations rules stay as they are on a plan's revert: conversation and set-up, not content.  |
| SND3 | snapshots | the item's name stays as it is on a revert; only its content changes.                                                      |
| SND4 | snapshots | a kept snapshot let go is not removed at once: it rejoins the five and the next take prunes to the newest five.            |
| SND5 | snapshots | the Kept by a Rule badge explains itself in a hover card (the design system's part for what a badge means), not a tooltip. |
