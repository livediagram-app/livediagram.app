# Index blueprints

Follow the references below only as needed; never upfront.

- ./index.md - when working on the index Worker as a whole: routing, callers, the access rule, grants, the Drive
  flag, crons, config, logs, constants and tests
- ./items.md - when making, reading, moving, copying or opening items, or listing them, their folders, Hide from Recent and
  Recent
- ./sharing.md - when working on share links, share passwords, guesses or Shared with me
- ./inbox.md - when an app pushes a summary, threads, actions or forms, or when building the Inbox
- ./events.md - when recording events, reading an item's History, or the daily sweep
- ./connected-tabs.md - when working on connected tabs: the build order, the connections table, the make, open and removal doors, each app's column and door
- ./kits.md - when working on project kits: the run's wire shapes, the index's two routes, the apps' template door, tests
- ./sheet-sources.md - when working on sheet sources: the index's two routes, the doors' contract, the watch and the change signal, limits and tests
- ./live-embeds.md - when working on live embeds: the element's fields and checks, the embed ticket, the slots, the host's
  side of the frame's messages, snapshots, limits and tests
- ./team-audit-log.md - when working on the team audit log: its table, the write path beside each event, the sweep, anonymising and the admins' read and CSV, and the Audit Log on a team's view
- ./approvals.md - when working on approvals: the tables, the routes and their checks, the revision, the notice and email, the editor kit
- ./request-access.md - when working on Request Access: the build order, the two tables, the ask off the response's path, grant and decline, the Inbox read, the notices
- ./webhooks.md - when working on connections (what webhooks became): the tables, the outbox statement, the dispatcher, the address check, the messages
- ./archive.md - when working on Archived: the archive, the archive scope, the move out, the refusals and the
  Explorer's Archived view
- ./this-browser.md - when working Offline as a Space: its folders, its store, Sync keeping its place, its
  sidebar row and Home tile
- ./trash.md - when working on the Trash, purges, the daily sweep or closing an account
- ./default-folders.md - when working on where a new item lands by default
- ./guest-merge.md - when a guest becomes an account, or on the migration's handoff
- ./dialog-hero-header.md - when implementing the dialog hero header: its files, the frame's and the art's API, the tokens, the tests
- ./footer-tools-menu.md - when implementing the footer's Tools menu: its files, the item shape, the trigger and the rows
- ./inbox-notices.md - when implementing Inbox notices: the watch, the rows that notify, seen rows, the notice and its
  card, the editor's door, the `shares` read
- ./DEFAULTS.md - when you need a default the index specs leave open
- ./COMPLETENESS.md - when checking which completeness categories each index blueprint covers
