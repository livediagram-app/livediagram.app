# Site blueprint defaults

One row per default applied where a spec is silent. Each code is cited in its blueprint's "Defaults ledger".

| #     | Blueprint | Default applied                                                                                     |
| ----- | --------- | --------------------------------------------------------------------------------------------------- |
| SITE1 | site      | a sign-in's `return` path is honoured only when it is a path on this site; anything else goes home. |
| SITE2 | site      | the site asks who is signed in once per page load.                                                  |
| SITE3 | site      | the last app a browser came from picks what New makes, never what the lists show.                   |
