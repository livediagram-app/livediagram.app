# Suggestions blueprint defaults

One row per default applied where a spec is silent. Each code is cited in its blueprint's "Defaults ledger".

| #   | Blueprint          | Default applied                                                                                         |
| --- | ------------------ | ------------------------------------------------------------------------------------------------------- |
| SG1 | canvas-suggestions | one gesture is the changes within 500 ms of each other, sent once no pointer is held.                    |
| SG2 | canvas-suggestions | Accept All applies oldest first, ties by id.                                                             |
| SG3 | canvas-suggestions | a conflicted suggestion keeps its row, flagged, until its author takes it back or an Editor rejects it. |
| SG4 | canvas-suggestions | Suggesting starts off for an Editor on every visit; it is not remembered.                                |
| SG5 | canvas-suggestions | a Participant's suggestions show to every Participant on the tab, as comments do.                        |
