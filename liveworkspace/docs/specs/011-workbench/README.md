# Workbench

Follow the references below only as needed; never upfront.

- ./workbench.md - when working on workbench pairings, tickets and sessions: where it runs, the addresses, the store, the handoff, ending access
- ./tab-style.md - when working on the Tab Style dialog every editor shares: its views, its frame, the surfaces and
  the profile a product hands it
- ./label-editor.md - when working on the label editor all five editors share: what is
  shared, what each product binds, mixed-direction lines
- ./phone-drawers.md - when working on a tool panel (Layers, Tidy Up, Collaborate, Timer, Vote, Poll, ...) on a phone:
  the bottom drawer every editor's tool popovers open as, its handle, focus, safe area and which panels
- ./phone-apps-drawer.md - when working on a phone's top row in any editor: the logo and Apps in the menu card, the
  corner card's actions in the Apps drawer, its tiles per role, the unread dot and the 56 px row
- ./editor-preferences.md - when working on how an editor keeps a person's settings: the browser's copy, the
  account's, the merge on load (a cleared setting clears everywhere), writing, saving and fitting
- ./sidebar-width.md - when working on how wide an editor's left sidebar is (Contents, the page tree): the default
  that steps up on wide windows, the drag handle, the kept width and cut-off names
- ./blueprints/README.md - when implementing a workbench spec: the blueprints hold the engineering detail derived from it
