# Workbench blueprints

Follow the references below only as needed; never upfront.

- ./workbench.md - when working on workbenches: pairing, tickets, sessions, the store's tables and alarm, the apps'
  session checks, allowances and ending access
- ./tab-style.md - when implementing the shared Tab Style dialog: its files, the profile's types, the resolve,
  constants and tests
- ./label-editor.md - when implementing the shared label editor: its files, the binding, the mixed-direction lines,
  measurements and tests
- ./phone-drawers.md - when implementing the tool panels' phone drawer: PhoneDrawer, its use in MovablePanel and
  PopoverOrSheet, and tests
- ./phone-apps-drawer.md - when implementing a phone's top row and Apps drawer: the store, the tiles, the menu
  card's buttons, EditorCornerActions on a phone, and tests
- ./editor-preferences.md - when implementing the editors' one preferences store: its files, the binding each
  editor passes, the merge, the load, the save queue, constants and tests
- ./first-edit.md - when implementing the first-edit path: the name card's flag, the name tray, the shared
  empty-canvas card, where each editor wires them, and tests
- ./sidebar-width.md - when implementing the left sidebars' width: the steps, the store, the resize handle, the
  film variable, the tooltip's `focused`, constants and tests
- ./page-layout-preview.md - when implementing the layout hover preview: createPageLayoutPreview, the settle, each
  product's placer, constants and tests
- ./DEFAULTS.md - when you need a default the workbench specs leave open
- ./COMPLETENESS.md - when checking which completeness categories the workbench blueprint covers
