# Accounts blueprints

Follow the references below only as needed; never upfront.

- ./accounts.md - when working on the accounts Worker as a whole: routing, its doors, crons, closing an account,
  telemetry, config, logs, constants and tests
- ./sign-in.md - when working on email codes, Google, Turnstile, the code limits or signing in on an app's address
- ./sessions-and-guests.md - when working on sessions, guests, the workspace token, bearers, the guest merge or
  returning guests of the old livediagram.app
- ./teams.md - when working on teams, invitations, the join link, reminders or the change feed
- ./tokens.md - when working on API tokens or their expiry warnings
- ./oauth.md - when working on the OAuth provider, registering clients, token claims or the device grant
- ./settings-and-profiles.md - when working on settings or profiles
- ./push.md - when working on phone notifications: devices, Web Push and VAPID, the pusher, the Phone settings and the service worker
- ./email.md - when working on any email accounts sends, the onboarding series or what apps' notification emails ask
- ./DEFAULTS.md - when you need a default the accounts specs leave open
- ./COMPLETENESS.md - when checking which completeness categories each accounts blueprint covers
