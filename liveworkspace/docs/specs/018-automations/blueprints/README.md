# Automations blueprints

Follow the references below only as needed; never upfront.

- ./engine.md - when building on or changing `@liveworkspace/automations`: its two entries, files, exports, tables, what an app injects, and its tests
- ./item-engine.md - when wiring an app with no cards into Automations, or changing the item engine: the kinds registry, the kit, the tables and SQL triggers, the wake, the route table, the "Wiring an app" checklist and the measured costs
- ./ui.md - when changing the Automations screen or builder, or mounting it in an editor: `@liveworkspace/automations-ui`, the `AutomationsKit` an app provides, what liveplanner's kit supplies and the "Mounting the screen in an editor" checklist
- ./cross-app.md - when changing the steps that act in other apps: the five kinds, the index route and grant, the target door each app serves, the chain and the caps, the builder's panels
