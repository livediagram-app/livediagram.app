# Notifications blueprints

Follow the references below only as needed; never upfront.

- ./toasts.md - when implementing the shared toast: its files in `packages/ui/src/toast`, the queue, the provider and
  its nesting, the notification list's store, the collapse into the bell, constants and tests
- ./callouts.md - when implementing the shared Callout: its interface, look per tone, migration and tests
- ./suggestions.md - when implementing suggestions: the shared module in `packages/workbench/src/components/suggest`, the
  notice slot, the memory, the gate, the write-up helper, each app's trigger file, constants and tests
- ./DEFAULTS.md - when you need a default the notifications specs leave open
- ./COMPLETENESS.md - when checking which completeness categories the notifications blueprint covers
