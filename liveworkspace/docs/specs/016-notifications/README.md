# Notifications

Follow the references below only as needed; never upfront.

- ./toasts.md - when working on toasts in any editor, the Explorer or Settings: the one toast, its tones, timing,
  standing toasts, the footer's bell, the notification list and what is kept
- ./callouts.md - when showing a note or an error in place (a panel, dialog, form, Settings row or page) or a
  canvas-anchored hint: the one Callout, its tones, sizes, action and the floating ones
- ./suggestions.md - when offering to carry an item's content into another app (Make These a Plan, Write It Up, Add
  to Knowledgebase, Bring In Your Diagrams and Docs, Send to a Plan): triggers, the rules, the one switch, telemetry
- ./blueprints/README.md - when implementing a notifications spec: the blueprints hold the engineering detail derived from it
