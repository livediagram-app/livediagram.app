Everything the livedesign editor does, it does by calling a REST API. That API is open to you too: with an [API token](/help/account-and-data/api-tokens/) your own scripts and integrations can read, create, and update designs, tabs, folders, images, themes and more, exactly as the app does. Account administration (teams, tokens, deleting the account) stays with the signed-in app.

If you want to connect an AI assistant rather than write code, you usually want the [MCP server](/help/account-and-data/connect-ai-mcp/) instead. It wraps this API in tools Claude and other MCP clients can call directly. To work from a terminal or a coding agent without writing requests yourself, use [the livedesign CLI](/help/developers/cli/).

## The base URL

The API lives under `/api` on your livedesign host. On the hosted service that is:

```
https://livedesign.app/api
```

On a self-hosted instance it is `/api` on your own domain. Every path in these docs is relative to that base, so `GET /designs` means `GET https://livedesign.app/api/designs`.

## Authenticating in one line

Send an API token as a bearer header on each request:

```bash
curl https://livedesign.app/api/designs \
  -H "Authorization: Bearer lvd_your_token_here"
```

API tokens are a [signed-in-only](/help/account-and-data/signing-in/) feature. [Authentication](/help/developers/authentication/) covers how to create one and how token access compares to the guest path.

## What you can do

The token-callable surface mirrors the app:

- **Designs and tabs**: list, read, create, rename, copy, and delete designs; read a tab as JSON, as a text view or as an SVG picture; change a tab with changesets, and revert one.
- **Comments**: read, add, reply to and resolve comments.
- **Folders**: organise designs into folders, personal or in a team you belong to.
- **Pages**: add, change, lay out and move a tab's pages, and write articles from Markdown.
- **Sharing**: create, list, extend and revoke share links, and set or remove a share password.
- **Trash**: list what you can restore, restore it, or delete it for good.
- **Images and themes**: upload and reference images, and manage your saved custom themes.

[Working with Designs](/help/developers/working-with-designs/) walks through the common calls with copy-pasteable examples. [Edit Operations Reference](/help/developers/working-with-designs/edit-operations/) lists the changeset vocabulary, [Images, Pages and More](/help/developers/working-with-designs/images-and-pages/) covers uploads, pages and articles, and [Comments and Presence for Agents](/help/developers/agent-comments-presence/) shows how an agent talks to people and shows what it is doing.

## The full reference

The complete, machine-readable description of every endpoint, request shape, and response shape is published as an **OpenAPI 3.1** design, with no authentication required:

```bash
curl https://livedesign.app/api/openapi.json
```

Point Postman, an OpenAPI viewer, or a client generator at that URL to explore the whole surface or scaffold a client. Endpoints an external token can use are tagged `x-token-usable`.

<Tip>
  The realtime collaboration WebSocket is not part of the REST reference. The OpenAPI design lists
  the upgrade endpoint, but the live message protocol is intentionally separate.
</Tip>
