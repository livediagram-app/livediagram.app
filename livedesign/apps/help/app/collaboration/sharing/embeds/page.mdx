An embed places a live copy of a design inside another page, like a wiki, a doc, Notion, or your own site. It shows the canvas, hides the editor chrome, and stays up to date as the design is edited. It is the simplest way to keep a design visible where your readers already are.

## What an embed shows

The embed is built from a share link, and it **honours that link's role**: a **Viewer** or **Participant** pass embeds a read-only canvas, while an **Editor** pass embeds an editable one, so readers of the host page can change the design right there. Pick the pass to match: a Viewer pass when the page is for an audience, an Editor pass when it is for collaborators.

Inside the frame, the embed:

- shows the canvas with pan, zoom, and pinch,
- hides the header, tab bar, palette and every floating panel, leaving a clean view with just the zoom controls in the bottom-right corner,
- defaults to the hand (pan) tool, so a drag pans the view; an editable embed still selects and edits on click, and right-click menus work,
- keeps a small **Open in livedesign** badge in the bottom-left corner that opens the full share view in a new tab,
- shows a compact tab switcher beside the badge when the design has more than one tab: it shows the current tab's name and opens a list of the tabs,
- skips the "what's your name" prompt: readers join under a random guest name.

One editing feature stays off inside the frame: image uploads are unavailable in an embed, so adding pictures still happens in the full editor. An embed also draws no [element indicators](/help/canvas/element-indicators/) (the small link, note, action and comment icons on elements): they are editor chrome, so the picture stays clean.

Because the embed joins the same realtime room as any viewer, it **live-updates**: when the design changes, the embedded view follows along.

## Adding an embed to a page

<Step n={1}>Open the **Share** dialog and create or pick a pass for the design.</Step>
<Step n={2}>Open the pass's **Embed** menu, under its link, and choose **Copy iframe** for a ready-made `<iframe>` snippet, or **Copy embed URL** for the bare URL.</Step>
<Step n={3}>Paste it into your page, wiki, or doc: the iframe snippet drops in directly, while the embed URL suits tools that turn a pasted link into an embed themselves.</Step>

<Figure caption="Each pass's Embed menu copies either the bare embed URL or a ready-made iframe snippet.">
  <ShareEmbedMenu />
</Figure>

The snippet is 800 by 500 pixels with a hairline border and rounded corners, which you can adjust in the markup. If the design has a [share password](/help/collaboration/sharing/share-passwords/), readers are prompted for it inside the embed frame (the **Password Protection** switch notes that embeds are included). A link scoped to [one tab](/help/collaboration/sharing/one-tab/) embeds that tab only.

## When an embed stops working

An embed lives exactly as long as its share link. If you revoke the link, or it [expires](/help/collaboration/sharing/share-link-expiry/), the frame shows a small not-found message instead of the design. Create a new pass and paste its snippet to bring it back.

## Privacy

An embed only exposes what the share link exposes: a Viewer or Participant pass's embed is a read-only view (an embed has no way to put a name on what someone adds), and only an Editor pass's embed can change the design. Anyone who can read the host page's source can also see the embed URL, so treat an editable embed like handing out the edit link itself.
