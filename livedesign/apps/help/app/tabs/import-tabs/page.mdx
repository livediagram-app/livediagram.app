**Import** brings content into the active tab from pasted text or a file. It is the counterpart to [exporting](/help/tabs/export-tabs/): export a tab from one document, import it into a tab somewhere else.

## Importing JSON

Open the tab's menu (the **⋯** button on the active tab, or right-click the tab) and choose **Import**. You can also run **Import…** from the [command palette](/help/search-panel/the-search-panel/command-palette/). The **Import to Tab** dialog opens at **JSON**, which reads a livedesign tab export (a `.livedesign-tab.json` file) and restores it exactly, pages and all, the highest-fidelity round trip.

<Figure caption="The tab menu holds Import, beside Export and Clear.">
  <ImportMenu />
</Figure>

**Paste or write** the text into the box and press **Import**, or press **Import a file instead** to pick one from disk. Either way the tab updates once it parses.

Dropping a `.json` file straight onto the canvas doesn't import it: a small note points you to **Import** in the tab menu, since importing replaces the tab.

## Import replaces the tab

Importing **replaces the active tab's contents** with what comes in, it does not merge. Because that is destructive, the dialog leads with an amber warning naming the tab about to be overwritten, so you can back out before committing. If you change your mind afterwards, undo (`Cmd` / `Ctrl` + `Z`) brings the previous pages back. To keep the current tab as it is, add a new tab first and import into that.

**Import** is greyed out while a tab is [locked](/help/tabs/locking-tabs/), since a locked tab is protected from edits, and the tab menu isn't offered on a view-only share link.

<Figure caption="Because importing overwrites the tab, the Import to Tab dialog leads with a warning naming the tab, above the paste box.">
  <ImportWarning />
</Figure>

<Tip>
  Want to combine tabs instead of replacing one? Import into a fresh tab, then copy the elements you
  want across to your working tab.
</Tip>
