**Import** brings content into the active tab from pasted text or a file. It is the counterpart to [exporting](/help/tabs/export-tabs/): export a tab from one design, import it into a tab somewhere else.

## Importing JSON

Open the tab's menu (the **⋯** button on the active tab, or right-click the tab) and choose **Import**. You can also run **Import…** from the [command palette](/help/search-panel/the-search-panel/command-palette/). The **Import to Tab** dialog offers two formats. **JSON** reads a livedesign tab export (a `.livedesign-tab.json` file) and restores it exactly, pages and all, the highest-fidelity round trip.

<Figure caption="The tab menu holds Import, beside Export and Clear.">
  <ImportMenu />
</Figure>

Pick a format, then paste or write the text into the box and press **Import**, or press **Import a file instead** to pick one from disk. Either way the tab updates once it parses.

## Importing an SVG

**SVG** brings a logo, icon or brand mark in as **shapes you can edit**: every shape in the file becomes a path you can recolour, reshape with the [Pen](/help/palette/tools/drawing/) and combine. Paste the SVG markup or pick a `.svg` file. Unlike JSON, an SVG **adds** to the tab instead of replacing it: the shapes land on the page you are on, scaled to fit inside its margins, and stay selected so your next move takes them all. A bold line icon fills the page too: any line that would land thicker than Extra thick (the thickest line preset) becomes a filled shape in the line's colour, keeping its rounded or square ends and corners. Thinner lines stay lines you can restyle.

You can skip the dialog too: **drop** an `.svg` file on a page, or **paste** one (or SVG markup copied from a design tool or code editor) onto the canvas.

- Shapes keep their colours, outlines and opacity. Outline widths snap to the nearest of the five line weights.
- A letter or mark with holes, such as an O, comes in as one shape with its holes.
- What a shape can't carry is listed when the import finishes: text (outline it before exporting, or retype it), masks, filters and clip paths, embedded pictures and pattern fills. A gradient fill takes its first colour.
- A very large file (over 2 MB, or over 5,000 shapes) is placed as a picture instead, and a note says so.

Dropping a `.json` file straight onto the canvas doesn't import it: a small note points you to **Import** in the tab menu, since importing replaces the tab.

## A JSON import replaces the tab

A JSON import **replaces the active tab's contents** with what comes in, it does not merge (an SVG adds to the page instead, above). Because that is destructive, the dialog leads with an amber warning, worded for JSON, naming the tab about to be overwritten, so you can back out before committing. If you change your mind afterwards, undo (`Cmd` / `Ctrl` + `Z`) brings the previous pages back. To keep the current tab as it is, add a new tab first and import into that.

**Import** is greyed out while a tab is [locked](/help/tabs/locking-tabs/), since a locked tab is protected from edits, and the tab menu isn't offered on a view-only share link.
