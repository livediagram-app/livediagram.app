- ./zen-mode.md - when working on Zen mode: Distraction-free focus mode: hide all chrome, keep canvas + zoom
- ./panel-docking.md - when working on Panel corner docking: Choose which corner each corner panel (AI, Minimap, Poll, Vote, tool panels) sits in: desktop drag with snap-to-corner guides, free drop kept where released, stacking + reflow within a corner, device-local localStorage layout

- ./editor-tour.md - when working on the Diagram tour ("Getting started with Diagrams?", Yes / No, six steps, the welcome tour until October 2026): offered and run only on a Diagram tab; a zero-document user's first document owes it (handoff flag, waiting for a Diagram tab when the document opened in another mode), a centred welcome offer (declining is one equal-weight click, once-ever via `tourSeen`), then 6 anchored steps (palette, selection modes, categories, the element menu, tabs, theme), waiting for the tab's start to be done driving the real panels/menus; ends as skipped on leaving Diagram; replayable via Settings' Tours › Diagram Tour; its engine and stage are shared with the [Plan tour](../026-plan/plan-tour.md) and the [Workshop tour](../012-collaboration/workshop-tour.md)

- ./show-me.md - when working on Show Me: the on-demand guided tour of one surface (card type editor, Share dialog, Dashboard Settings, logo page panel), its button beside Help, live controls, Escape, telemetry tokens, and how to add one to a new surface
- ./toolbar-layout.md - when working on Toolbar layout: The editor's one panel layout, on every device: the Palette as one Excalidraw-style strip at the top of the canvas (selection mode, category picker, the category's first 12 tiles, and a More button whose popover, hung from the button, holds the full category; a far-right Search popover finds any element type, other modes' in a closed accordion). The top-left menu button opens the Explorer as a popover; Layers and Collaborate are popovers over their bottom-row buttons; every other panel docks in its corner. The retired Floating layout and `panelLayout` preference
