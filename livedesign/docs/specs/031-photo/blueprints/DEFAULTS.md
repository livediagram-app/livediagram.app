# Photo blueprint defaults

One row per default applied where a spec is silent or qualitative.

| #   | Blueprint    | Spec silence                                  | Default applied                                                                                                                                                                 |
| --- | ------------ | --------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| D1  | photo-engine | Where a group's children sit in the array     | Contiguous directly below the group entry, so one pass with a group stack composites the tree                                                                                   |
| D2  | photo-engine | How a remote `put` places a new layer         | Above the layer the sender had under it (`after`), else on top                                                                                                                  |
| D3  | photo-engine | Bicubic's kernel                              | Keys cubic, a = -0.5 (Photoshop's "Bicubic"), area-average when shrinking past half                                                                                             |
| D4  | photo-engine | Gaussian blur's method                        | Exact separable kernel to sigma 2.5; four box passes past it (constant time, about 1 level off)                                                                                 |
| D5  | photo-engine | Dissolve's pattern                            | A hash of the layer id and the pixel's place, so it holds still and matches on every client                                                                                     |
| D6  | photo-engine | Luma for Hue, Saturation, Colour, Luminosity  | W3C's 0.3 R + 0.59 G + 0.11 B, as the blend spec defines it                                                                                                                     |
| D7  | photo-engine | GPU fallback refresh                          | CPU view throttled to 15 frames a second                                                                                                                                        |
| D8  | photo-engine | Tile encoding                                 | PNG at the browser's default compression, in the codec worker                                                                                                                   |
| D9  | photo-engine | The CPU view's worker                         | None: drawn on the main thread for the visible rect only (it is a fallback)                                                                                                     |
| D10 | photo-engine | The tile cache's coarse-pointer budget        | 128 MB, as the image display copy caps phones                                                                                                                                   |
| D11 | photo-engine | Order of Levels' and Curves' channels         | Each colour channel's own setting first, then the RGB one                                                                                                                       |
| D12 | photo-engine | Brightness/Contrast's curve                   | Brightness lifts midtones by b/150 x 0.5 x (1 - (2v-1)^2), ends fixed; contrast scales about 0.5 (x2.5 at 100, x0.5 at -50)                                                     |
| D13 | photo-engine | How effects meet the layer                    | Drawn into the layer's own picture before its blend: shadow, glow, the layer (overlay on it), stroke                                                                            |
| D14 | photo-engine | Clipped layers                                | Blended as a group with their base (Photoshop's default): the base drawn alone, the clipped layers onto it keeping its alpha, the result blended by the base's mode and opacity |
| D15 | photo-engine | Adjustment layers and alpha                   | Change colour only: the backdrop's alpha is kept, the change mixed by mask and opacity                                                                                          |
| D16 | photo-engine | Drop shadow's angle                           | The light's angle (Photoshop's): 120 puts the shadow below right                                                                                                                |
| D17 | photo-engine | 3D table size for per-pixel adjustments (GPU) | 33 a side, trilinear                                                                                                                                                            |
| D18 | photo-engine | Hard Mix at the exact half                    | A give of half a level (`HARD_MIX_GIVE`), the same on the CPU and the GPU, so a float's rounding never flips a pixel                                                            |
| D19 | photo-engine | Keeping a large merge responsive              | Composited on the main thread in 256-row bands, yielding every 12 ms; at once under 1 MP                                                                                        |
| D20 | photo-engine | When a photo page is framed on focus          | Once the rail and panel have laid out, waiting at most 1.5 s for them                                                                                                           |
| D21 | photo-engine | How many own brush presets are kept           | 24, the oldest dropped first                                                                                                                                                    |
| D22 | photo-engine | Removing a gradient stop                      | Dragged 28 px off the strip                                                                                                                                                     |
| D23 | photo-engine | Select and Mask's Refine Edge band            | 6 px either side of the edge                                                                                                                                                    |
| D24 | photo-engine | When the brush cursor turns precise           | Under 4 screen px across, or with Caps Lock on (Photoshop's)                                                                                                                    |
| D25 | photo-engine | Content-Aware Fill's least reach              | 32 px round the hole, the reach otherwise one hole's size                                                                                                                       |
| D26 | photo-engine | Built-in brush presets                        | Seven: Soft Round, Hard Round, Airbrush, Chalk, Ink, Marker, Spray                                                                                                              |
| D27 | photo-engine | Built-in gradient presets                     | Nine: Foreground to Background, Foreground to Transparent, Black to White, Spectrum, Sunset, Ocean, Copper, Violet to Orange, Chrome                                            |
| D28 | photo-engine | A peer's change to a tile being worked on     | Held per tile while it is painted or committing here; this person's commit wins it; a cancel takes it up                                                                        |
| D29 | photo-engine | The social formats' pixel sizes               | Each platform's documented upload size in 2026, an Instagram Post at 4:5 (1080 x 1350), the size its feed shows                                                                 |
| D30 | photo-engine | Where Make Sizes crops                        | About the centre (the Centre anchor), the picture scaled to fill (cover); the pixels past the edges kept so the Move tool re-crops                                              |
| D31 | photo-engine | What Make Sizes does with elements on top     | Leaves them on the source page: they are not the photo, and their text does not scale with it                                                                                   |
| D32 | photo-engine | How All Sizes names its files                 | `<page name or Page n> <w>x<h>.<ext>`, a repeat gaining " 2", " 3"; the .zip `<design name> - All Sizes.zip`                                                                    |
