# Photo

Follow the references below only as needed; never upfront.

A **photo page** is one of the kinds of page: a picture made of layers, edited pixel by pixel with
brushes, selections, adjustments and filters, the way an image editor works, inside the design and alongside its
other pages.

- ./photo-pages.md - when working on the photo page itself: making one, its size, the tools rail, the options flyout, the Photo panel, the title-bar menus, navigation, share roles, collaboration, exports, telemetry, limits
- ./photo-layers.md - when working on the layer stack: layer kinds, blend modes, opacity, masks, clipping, locks, groups, layer effects, text layers, layer operations, the composite
- ./photo-tools.md - when working on a photo tool: selections, painting, retouching, fills, gradients, move and transform, crop, eyedropper, text, shapes, the clipboard
- ./photo-adjustments.md - when working on adjustments (adjustment layers and destructive ones) or filters: the catalogue, their parameters, previews, auto adjustments
- ./photo-store.md - when working on where pixels live: tiles, the blob store, its api routes, sync, undo, offline designs, copies, retention, limits
- ./blueprints/README.md - when implementing a photo spec from its blueprint
