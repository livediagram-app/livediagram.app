# Tags

**Removed (October 2026).** Tags moved to liveworkspace's index, and then the shared Explorer dropped them to keep it simple: there is no Tags view, tag picker, chip or tag search in the Explorer, no Tags help article, and an old `/explorer/tags` link replaces itself with Home. The index's tag API is to be removed separately. Tags may come back later. (A card's own tags on the canvas, and the colours they take ([Tag colours](../009-elements/tag-colours.md)), are a different thing and stay.)

The document is [one-explorer.md](../../../../liveworkspace/docs/one-explorer.md); the calls and types are in [one-explorer-contracts.md](../../../../liveworkspace/docs/one-explorer-contracts.md) "Folders, tags, favourites, defaults". The Explorer that shows it is the shared package, [`@liveworkspace/explorer`](../../../../packages/explorer/README.md).
