The [search panel](/help/search-panel/the-search-panel/) isn't only for finding things, it's also a **command palette**: type the name of an action and run it, without hunting through toolbars and menus. If you've used ⌘K in tools like VS Code, Linear, or Slack, this is the same idea.

## Opening it

- **Keyboard:** press `Cmd` / `Ctrl` + `K` anywhere in the editor. This is the conventional command-palette shortcut, so it's the one to reach for. The older `Cmd` / `Ctrl` + `.` opens the same panel; they're interchangeable.
- **Button:** the **Search** button in the bottom bar opens it too.
- It works in **[zen mode](/help/tools/zen-mode/)** and in **read-only** views, just like opening search.

The palette and search are one surface, so you can find a document and run a command from the same box. Commands only exist inside a document: on the Explorer page, search finds things but has no actions to run.

## Running a command

Start typing and matching commands appear in an **Actions** group, below any documents, tabs or elements that also match. Click the one you want, or arrow down to it and press `Enter`. Commands match on their name and on a few related words, so "tidy" finds Auto Layout and "front" finds Bring to front. At most 10 actions show at once, so type a little more to narrow a long list.

Commands only show once you've typed something, so an empty box just lists places to jump to and never runs an action by accident. Because the Actions group sits below the navigation groups, the preselected first result is still a place to go when your query also names a tab or element; arrow down to the command to run it deliberately.

Every command does exactly what its menu item or shortcut does: it's the same action under a different name, so nothing behaves differently depending on how you reach it.

## What you can run

The list follows what you're doing, so it only offers commands that apply right now:

- **With something selected:** Delete selection, Duplicate selection, Lock / unlock selection, Bring to front and Send to back. For a single shape or other boxed element also Rotate 90°, 180° or 270°, Reset rotation, Add / edit note and Add comment, plus Clear animation when it has one and the shape markers (Add … marker, Clear marker) for a plain shape.
- **History:** Undo and Redo, shown only when there's something to undo or redo.
- **Document and tab:** Create new tab, Rename tab, Rename document, Delete document, Open theme, Open canvas options, and Share document (owner only, and not for a document saved only in this browser).
- **Cleanup:** Auto Layout (tidy up), one Auto Layout command per layout style (Flowchart (down), Flowchart (right), Tree and Mindmap), and Auto-align to grid. See [Layout Cleanup](/help/tools/layout-cleanup/).
- **Dialogs:** Export…, Import…, Browse templates, Open settings, and Keyboard shortcuts.
- **View:** Enter (or Exit) zen mode, Fit to screen, and Collaborators, which opens the [list of people in the document](/help/collaboration/live-presence/#collaborators).
- **Tools:** pick up the Select tool, Hand tool, Eraser tool, Format painter, Laser pointer, Spotlight, Avatar mode, Slide Deck or Isometric view without opening the palette. Type "laser" and you get the laser, not just the article about it.

A few rules keep the tool list honest, matching the palette's own tool menu: the tool you're already holding isn't offered; everything except Select and Hand needs something on the canvas first; Spotlight and Slide Deck are desktop-only; and the Format painter isn't offered on a Draw whiteboard, whose dock replaces it.

On an Event Storming board where reading a wall photo is available, **Add notes from a photo** joins the list too.

## In read-only views

When you're viewing a document you can't edit (a view-only share link, for example), the palette still offers the actions that don't change anything: Enter or Exit zen mode, Fit to screen, Export…, Collaborators, and the tools that only change how you look at the canvas (Select, Hand, Laser pointer, Spotlight, Avatar mode, Slide Deck and Isometric view). The Eraser, the Format painter and every command that would change the document simply aren't listed.

<Tip>

  do (like "export" or "layout"), and run it, no need to remember where it lives.
</Tip>
