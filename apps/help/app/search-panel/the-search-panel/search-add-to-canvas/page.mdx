Inside the editor, the [search panel](/help/search-panel/the-search-panel/) is not only for getting around, it can also add to the canvas. Alongside the navigation results, your query is matched against the [palette](/help/palette/) catalogue, so you can place an element by name instead of hunting for it in the palette.

## Add to canvas

When a search matches a palette item, it appears in an **Add to canvas** group, each row marked with a plus-in-a-box. Every palette tile is searchable: shapes, text, arrows, sticky notes, tables, images, embeds, web components, and event-storming notes, plus every icon, sticker, and technology icon. Picking one closes the panel and arms the same placement gesture the palette uses, so you then tap or drag on the canvas to drop the element exactly where you want it. It is the quickest route from "I need an AWS Lambda icon" to having it on the board.

Picking a result does exactly what clicking the same tile in the palette does, so the element arrives with the same defaults and you can undo it with `Cmd` / `Ctrl` + `Z` like any other addition.

## How matches are ranked

Items match on their name and on everyday synonyms, so "database" finds the cylinder and "swimlane" finds the lane. The element you actually named comes first: an exact name match, then names that start with what you typed, then names that contain it, and finally items that only match on a synonym. That is why "table" lists the Table before anything whose description merely mentions tables. Up to 10 items are listed; type a little more to narrow a long list.

The group only appears once you have typed something (an empty box never dumps the whole palette), and it sits below the documents, tabs, elements and actions that match, so `Enter` still goes to a real match first. Arrow down to the item you want, or click it.

## Why search the palette

The palette groups its contents into categories (Shapes, Components, Devices, Icons, Tech and more), which is great for browsing but slower when you already know what you want. Searching by name skips the browsing: type "cylinder", "table", "arrow", or a cloud service name, and place it. For the palette and its categories, see [The Palette](/help/palette/) and [Technology Icons](/help/palette/technology/).

## When it is not offered

- **Outside a document:** from the Explorer, search sticks to finding documents, folders, teams, settings and help. There is no canvas to add to.
- **Read-only views:** when you can only view a document, Add to canvas results are left out, the same way the palette is.
- **Images:** the image tiles (Image, Avatar, Hero) only appear where the editor can upload images, as in the palette.

<Tip>
  The icon catalogues load in the background when the editor opens. If you search in the first
  moments after opening a document, icon results join the list as soon as they arrive, with no need
  to reopen search.
</Tip>
