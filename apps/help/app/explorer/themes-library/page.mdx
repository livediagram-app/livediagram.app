The **Colour schemes** view sits in the Explorer's **Library** section, beside the [Image gallery](/help/explorer/image-gallery/), and holds the [custom colour schemes](/help/canvas/themes/custom-themes/) you have built. It is where your colour schemes live between diagrams, so a palette you crafted once is ready to reuse everywhere.

## Your colour scheme library

Each saved colour scheme shows as a **swatch preview** with its name, so you can recognise it at a glance, plus a **New colour scheme** card to start another. If you have not built any yet, the view simply says so and offers that New colour scheme card.

<Figure caption="Saved colour schemes appear as swatch preview cards, each named and ready to edit, duplicate, or apply.">
  <ThemesLibrary />
</Figure>

Each colour scheme carries three actions:

- **Edit** opens it in the colour scheme builder to tweak its colours.
- **Duplicate** creates a copy as a starting point for a variation.
- **Delete** removes it. Any diagram still using a deleted colour scheme falls back to the default colour scheme, and the removal cannot be undone.

## Where colour schemes get used

Saved colour schemes appear alongside the built-in ones wherever you pick a colour scheme, so applying your own palette to a diagram is no different from choosing a built-in. See [Colour Schemes](/help/canvas/themes/) for applying them, and [Custom Colour Schemes](/help/canvas/themes/custom-themes/) for building one in the first place.

<Tip>
  Duplicate a colour scheme before a big change rather than editing in place, so you keep the original as a
  fallback while you experiment with the copy.
</Tip>
