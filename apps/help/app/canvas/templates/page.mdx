A blank canvas is freeing, but sometimes you would rather start with structure already in place. Templates give you a ready-made diagram as a starting point, complete with a theme applied, so you can begin from something shaped roughly like what you need and adapt it, instead of building every diagram from nothing.

## Starting from a template

When you [create a new document](/new), you can pick a template rather than an empty canvas. Each template arrives with its elements laid out and a [theme](/help/canvas/themes/) already applied, so the look is coherent from the first moment. From there it is an ordinary document: move, edit, add, and delete elements exactly as you would on any canvas.

## What's in the catalogue

The templates browse by category, and the picker skips a category that has nothing in it:

| Category        | Templates                                                                                                                                                                                                                           |
| --------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Mind maps**   | Mind map, Tree mind map, Bubble map                                                                                                                                                                                                 |
| **Flowcharts**  | Flowchart, Swimlane flowchart, Decision tree, Approval workflow, Data flow diagram                                                                                                                                                  |
| **Hierarchies** | Org chart, Pyramid, Fishbone, OKR tree, Opportunity solution tree, Sitemap                                                                                                                                                          |
| **Agile**       | Kanban, Retrospective, Start, Stop, Continue, Mad, Sad, Glad, 4Ls retrospective, Sailboat retrospective, Prioritization matrix, User story map, Affinity map, [Lean Coffee and Town Hall Q&A](/help/palette/collaborate/qa-boards/) |
| **Projects**    | Gantt chart, Timeline, Horizontal milestone timeline, Vertical milestone timeline, Roadmap, RACI matrix, Risk matrix, Meeting agenda, Article, Objectives planner                                                                   |
| **Strategy**    | SWOT, Flywheel, User journey, Comparison table, Venn diagram, Business Model Canvas, Empathy map, User persona, Stakeholder map, Funnel                                                                                             |
| **Design**      | Mobile wireframe, Laptop wireframe, Web page wireframe, Slide deck, Storyboard, Logo design, Group card, Floor plan, Crazy 8s                                                                                                       |
| **Technical**   | System architecture, Cloud architecture, Database schema, Sequence diagram, Class diagram, State machine, Event storming, Incident postmortem                                                                                       |

**Blank Canvas** sits apart from the categories as its own quick pick, since starting from nothing is not a kind of diagram. **Whiteboard** closes the category tiles, last: it makes a tab that opens in [Draw mode](/help/canvas/draw-mode/), a board for free drawing without distractions.

Each one arrives as real elements rather than a picture: a Gantt chart's bars are shapes you drag, a wireframe's frames are [device frames](/help/palette/devices/) you can rearrange. Nothing in a template is locked or special.

## Changing the theme

A new document starts on the Default theme, so the new-document screen only asks for a template and where to save it. Once you are on the canvas, open the Tab Look & Feel dialog to try a different [theme](/help/canvas/themes/), including any of your [custom themes](/help/canvas/themes/custom-themes/): it recolours the whole template at once.

## Making it your own

A template is just a head start, not a constraint. Everything in it is fully editable: rename and recolour the elements, restyle the whole thing with a different theme, or strip out the parts you do not need. Because the document works the same as any other, you can also add [tabs](/help/tabs/using-tabs/), invite others, and share it once you have shaped it into what you want.

<Tip>
