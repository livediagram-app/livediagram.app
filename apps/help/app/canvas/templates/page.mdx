A blank canvas is freeing, but sometimes you would rather start with structure already in place. Templates give you a ready-made diagram as a starting point, complete with a theme applied, so you can begin from something shaped roughly like what you need and adapt it, instead of building every diagram from nothing.

## Starting from a template

When you [create a new diagram](/new), you can pick a template rather than an empty canvas. Each template arrives with its elements laid out and a [theme](/help/canvas/themes/) already applied, so the look is coherent from the first moment. From there it is an ordinary diagram: move, edit, add, and delete elements exactly as you would on any canvas.

## What's in the catalogue

The templates browse by category, and the picker skips a category that has nothing in it:

| Category               | Templates                                                                                                      |
| ---------------------- | -------------------------------------------------------------------------------------------------------------- |
| **Mind maps**          | Mind map, Tree mind map, Bubble map                                                                            |
| **Flowcharts**         | Flowchart, Swimlane flowchart, Decision tree, Approval workflow, Data flow diagram                             |
| **Hierarchies**        | Org chart, Pyramid, Fishbone, OKR tree, Sitemap                                                                |
| **Agile**              | Kanban, Retrospective, Prioritization matrix, User story map, Affinity map                                     |
| **Project Management** | Gantt chart, Timeline, Horizontal milestone timeline, Vertical milestone timeline, Roadmap, RACI matrix         |
| **Strategy**           | SWOT, Flywheel, User journey, Comparison table, Venn diagram, Business Model Canvas, Empathy map, Funnel        |
| **Design**             | Mobile wireframe, Laptop wireframe, Web page wireframe, Slide deck, Storyboard, Logo design, Live card, Floor plan |
| **Technical**          | System architecture, Cloud architecture, Database schema, Sequence diagram, Class diagram, State machine        |

**Blank diagram** sits apart from the categories as its own quick pick, since starting from nothing is not a kind of diagram.

Each one arrives as real elements rather than a picture: a Gantt chart's bars are shapes you drag, a wireframe's frames are [device frames](/help/palette/devices/) you can rearrange. Nothing in a template is locked or special.

## Choosing a theme as you start

The new-diagram screen pairs templates with the same theme picker you see in the Tab Appearance dialog, organised into categories. You can swap the theme as you choose a template, including any of your [custom themes](/help/canvas/themes/custom-themes/), so the starting point matches your style before you have placed a single new element.

## Making it your own

A template is just a head start, not a constraint. Everything in it is fully editable: rename and recolour the elements, restyle the whole thing with a different theme, or strip out the parts you do not need. Because the diagram works the same as any other, you can also add [tabs](/help/tabs/using-tabs/), invite others, and share it once you have shaped it into what you want.
