Auto Layout is the structural tidier (the command palette calls it "Auto Layout (tidy up)"). Rather than nudging the positions you already have, it reads the arrow graph, works out how shapes connect, and computes brand-new positions, arranging connected shapes into clean layers. Unlike Auto-Align, it can legitimately move an element right across the canvas to give the diagram a proper layout.

## What it does

- It reads the **arrow graph**, splits it into connected groups, and lays out each group, using a layered arrangement for flow-like diagrams and breaking cycles where the graph loops back on itself.
- It keeps connections **readable**: each shape settles beside the shapes it connects to, an arrow that skips a level gets its own lane instead of running through the shape in between, and arrows leave and arrive on the sides facing the flow.
- It **infers direction** from where your shapes roughly sit now, so the result follows the orientation you were already drawing in.
- It works on the **whole active tab**. Shapes that aren't wired to anything (loose stickies, text, or images) pass through with their positions untouched, and spacing respects each element's size.
- It leaves **locked elements where they are**: a [locked element](/help/canvas/locking/), or anything on a [locked layer](/help/canvas/layers-visibility-and-locking/), is not moved or resized, and the rest of the diagram is laid out as if it were not there. Unlock it first if you want it included.
- It is **origin-preserving**: the laid-out block stays pinned to the diagram's current top-left, so the result appears where you're already looking instead of jumping to the canvas origin.
- It finishes with a **grid snap** (the same one [Auto-Align](/help/tools/layout-cleanup/auto-align/) runs), so the tidied output is also grid-aligned.

## Layout styles

One arrangement doesn't fit every diagram, so alongside the smart default there is a command per style. All of them read the same arrow graph and differ only in the shape of the result:

- **Auto Layout (tidy up)** (the smart default): a layered arrangement with the direction inferred from where your shapes roughly sit now.
- **Auto Layout: Flowchart (down)** and **Auto Layout: Flowchart (right)**: the same layered arrangement, but with the direction forced top-to-bottom or left-to-right, whatever your current positions suggest.
- **Auto Layout: Tree**: an org-chart arrangement. Roots sit at the top and every parent is centred over its own children, so hierarchies read cleanly level by level.
- **Auto Layout: Mindmap**: a radial arrangement. The most-connected shape becomes the hub in the centre and its branches fan out around it, with each level on a wider ring.

If a diagram isn't a perfect tree (a shape with two parents, or a loop), Tree and Mindmap still work: they lay out the main skeleton and reconnect the extra arrows across it.

## Running it

<Step n={1}>
  Open the [command palette](/help/search-panel/the-search-panel/command-palette/) (⌘K / Ctrl+K) and
  type **Auto Layout**.
</Step>

<Step n={2}>
  Under **Actions**, choose **Auto Layout (tidy up)**, or one of the styles below it.
</Step>

<Step n={3}>The whole tab is laid out anew in a single undoable step.</Step>

<Figure caption="Typing layout in the command palette lists Auto Layout and its styles under Actions.">
  <SearchCommandPalette />
</Figure>

Because it's one undoable operation, you can try a style and undo it in a single step (⌘Z / Ctrl+Z) if you preferred the previous arrangement, so it costs nothing to try two or three and keep the one that reads best.

## When to use it

Reach for Auto Layout when a diagram has grown organically and lost its shape, or when shapes were placed without much thought and you want the connections to drive the layout. If the diagram already looks right and only needs its drift cleaned up, use Auto-Align instead.

Auto Layout needs edit access and leaves a [locked tab](/help/tabs/locking-tabs/) alone, so unlock the tab first.

<Note>
  Auto Layout is deterministic and works offline, available in every deployment. It is separate from
  the AI [Clean](/help/tools/ai/ai-tools/) mode, which is optional and only exists where an AI
  provider is configured.
</Note>
