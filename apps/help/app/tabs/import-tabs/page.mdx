**Import** brings content into the active tab from pasted text or a file. It is the counterpart to [exporting](/help/tabs/export-tabs/): export a tab from one document, import it into a tab somewhere else.

## Import formats

From the tab ellipsis menu, expand the **Content** section and choose **Import**, then pick a format:

- **JSON** reads a livediagram tab export (a `.livediagram-tab.json` file) and restores its elements exactly, the highest-fidelity round trip.
- **Mermaid** reads a [Mermaid](https://mermaid.js.org/) flowchart (`graph` / `flowchart`), state diagram (`stateDiagram`), or ER diagram (`erDiagram`) and lays it out on the canvas, keeping every connection, its style (dashed, thick, two-headed, headless), `click` links, and any `subgraph` or composite-state blocks, which come in as frames drawn around their nodes. Other Mermaid diagram types (sequence, gantt, pie, …) aren't supported.
- **Markdown** turns a Markdown outline into a themed tree diagram, the same conversion as [Markdown Import](/help/tools/markdown-import/), so you can draft structure in text and bring it onto the canvas.
- **Excalidraw** reads a `.excalidraw` scene (what [excalidraw.com](https://excalidraw.com/)'s Save to disk produces) and keeps its shapes, labels, arrow connections, freehand drawings, sticky notes, frames, and images. On a [whiteboard](/help/canvas/whiteboards/) it comes in as whiteboard marks; on any other tab as diagram elements. It also reads a PNG or SVG exported from Excalidraw with **Embed scene** switched on (a `.excalidraw.png` or `.excalidraw.svg` file), which carries the whole scene inside the picture. The hand-drawn look flattens to clean strokes, and groups come apart into separate items.

## Paste from Excalidraw

You don't need a file to bring a drawing across. In Excalidraw, select what you want and copy it (Ctrl+C, or Cmd+C on a Mac), then click into a livediagram tab and paste (Ctrl+V or Cmd+V). The drawing lands where your pointer is, or in the middle of the view, and stays selected so you can move or restyle it at once. One undo takes the whole paste back.

- On a **whiteboard**, strokes become pen strokes, text becomes text boxes that fit their words, and Excalidraw's black ink follows the board: dark on a light board, light on a dark one. Its blue, green, red and orange become the matching pen colours.
- On a **diagram tab**, the drawing comes in as diagram elements, just as importing the file would.
- You can also **drag** a `.excalidraw` file, or a PNG or SVG exported from Excalidraw with **Embed scene** on, straight onto the canvas.

When something couldn't come across exactly (Excalidraw groups, for example), a small note at the bottom of the canvas lists what changed. Pasting adds to the tab; it never replaces what is already there.

Each format opens the same two-step panel: **paste or write** the content into the editor and press **Import**, or press **Import a file instead** to pick one from disk. Either way the tab updates once it parses.

## Images in an imported file

When an imported file carries images, they come across with it. Each one is resized in your browser (to at most 2048 pixels on its longest side) and saved to your [image gallery](/help/explorer/image-gallery/), so it counts towards the gallery's space like any image you add yourself. An image you already have is recognised and reused rather than stored twice.

While the images save, the panel counts them ("Importing images 3 of 12…"). When it finishes, the dialog tells you how many were imported, how many were already in your gallery, and how many were left as placeholders and why: the file didn't include the image, its format couldn't be read, it was too large, or your gallery is full. The rest of the file always imports. Double-click a placeholder to add its image later.

In an [offline document](/help/privacy-and-security/offline-mode/), images are kept inside the document in this browser instead of your gallery, up to a limit for each import.

## Import replaces the tab

Importing **replaces the active tab's contents** with what comes in, it does not merge. Because that is destructive, the dialog leads with a warning naming the tab about to be overwritten, so you can back out before committing. If you want to keep the current canvas, add a new tab first and import into that.

Import is unavailable while a tab is locked, since a locked tab is protected from edits.
