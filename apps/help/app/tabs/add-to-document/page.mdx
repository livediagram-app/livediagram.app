Sometimes a tab you built in one document belongs in another too: a glossary, a shared timeline, an architecture board two projects both rely on. **Add to Document** adds the active tab to another document you own, without leaving the editor.

## Adding a tab to another document

<Step n={1}>Open the tab's menu (the **⋯** button on the active tab, or right-click the tab).</Step>
<Step n={2}>Choose **Add to Document**.</Step>
<Step n={3}>
  In the **Add to Document** dialog, pick the destination. Each document shows as a tile with a
  preview of its canvas, and the filter box at the top narrows a long list. A message confirms when
  the tab has been added.
</Step>

The option is greyed out when there is nowhere to add the tab to: if this is your only document, until you create another, and on a [Plan](/help/canvas/plan-mode/) tab, whose cards belong to this document's items. It isn't offered on a view-only share link.

<Figure caption="Add to Document opens a dialog of your other documents, each with a preview of its canvas, and a filter box to narrow the list.">

</Figure>

## One tab, shared between documents

Add to Document doesn't make a copy: it is the same tab in both places. Edit its elements, restyle it, or rename it from either document and the change lands in the other as well. If the other document is already open in another window, reload it to see the latest edits.

Two things stay per-document, so each document can organise the shared tab its own way: the tab's position in the tab bar, and which [tab folder](/help/tabs/tab-folders/) (if any) it sits in.

Removing the tab from one document doesn't touch the others; the tab and its contents are only deleted for good when you remove it from the last document containing it. Deleting a whole document works the same way: a tab it shares stays, with its history, in every other document it is in, and the delete confirmation tells you how many tabs that is before you go ahead.

<Tip>
  Prefer an independent copy you can tailor per project? Use **Duplicate** in the same menu first,
  then add the duplicate to the other document.
</Tip>
