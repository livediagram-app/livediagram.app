A session button starts one of the [session tools](/help/collaboration/session-tools/) for everyone in the room: a countdown [timer](/help/collaboration/session-tools/timer/), a [dot vote](/help/collaboration/session-tools/voting/), or a [poll](/help/collaboration/session-tools/polls/) you write in advance.

## Adding one

The **Session** row of the [Behaviour](/help/palette/behaviour/) category opens into three buttons, one per tool: **Timer**, **Dot vote** and **Poll**. Pick the one you want and it drops ready to press, rather than dropping a generic button you then have to point at a tool.

It is how a board carries its own running order: put "5 minutes" over the writing column and "Vote — 3 dots each" over the results, and anyone can run the session.

## A Timer becomes the clock

A **Timer** goes further than starting something elsewhere: it counts down on the board itself, with its own **pause**, **resume**, **reset** and **remove** controls. It is the same timer as the pill in the top bar, so pause it on the board and it pauses there too.

## Changing the setting

Each button carries a **…** menu on its own face for the setting you change most: length presets on a Timer, dots each on a Dot vote, and the question and answers on a Poll.

Changing a Timer's length **while it is counting restarts it** at the new one, keeping it running (or paused) as it was. Extend a timer between rounds rather than mid-round.

For the full range, right-click and open **Session**, which has room for a proper number input.

A button stays the tool you picked it as. If you want a countdown where you put a vote, drag a **Timer** out of the palette instead — the palette has one tile per tool, so choosing there is the whole decision.

## How a Poll button asks

A Poll button carries its **answers** as well as its question, and you pick the shape they take — the same five the [poll](/help/collaboration/session-tools/polls/) composer offers:

- **Yes / No**, and **+ Abstain** for the version with a way out.
- **Choices** — the answers you write yourself, two to six of them.
- **Rating 1-5**.
- **Free text**, for answers people type.

Only **Choices** reads a written list. Switch to Yes / No and the list is left alone but unused, so you can try a shape and come back without retyping anything. A Choices button with fewer than two answers has nothing to press, so it shows as not set up until you add a second one — every other shape is ready as soon as it has a question.

## Who can start one

Starting a tool needs edit access, so on a view-only link the button shows as unavailable, though you can still take part once somebody starts it.
