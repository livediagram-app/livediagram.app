**Popular** is the palette's first category, and the one it opens on. It holds twelve of the tiles people reach for most, picked from across the palette, so your everyday vocabulary isn't spread over Shapes, Write, Draw and Build. Each tile behaves exactly like the same tile in its home category: click it and then tap the canvas to drop it or drag to draw it at a size, or drag the tile straight onto the canvas. Tiles preview the tab's theme the same way.

## What's in it

Popular is picked per editor mode, because a diagram and a visual page are built from different things.

In **Diagram** mode: Square, Circle, Diamond, Text, Arrow, Frame, Note (a sticky note), Image, Shape Pen, Table, Code (a code block) and Entity.

In [Illustrate](/help/canvas/illustrate/) mode: Text, Square, Circle, Image, Bubble (a speech bubble), Pie, Bar, Donut, Stat row, Process, Timeline and Callout.

[Plan mode](/help/canvas/plan-mode/) has no Popular: its palette opens on **Cards**, since a plan is worked from its boards. An [Event Storming board](/help/canvas/event-storming-boards/) opens on its own notation instead. [Draw mode](/help/canvas/draw-mode/) shows its own set of pens rather than the palette's categories.

The list is fixed and the same for everyone: using a tile never reorders it, and it can't be edited. Everything else is a category away in the palette's category picker, or a search away in the editor's [Search panel](/help/search-panel/the-search-panel/search-add-to-canvas/).

## Every time you open a document

The [palette strip](/help/palette/toolbar-layout/) opens on Popular each time a document loads, rather than on the last category you used, and shows its twelve tiles (fewer on a narrow window, with the rest behind **More**).

<Tip>
  Several Popular tiles have a single-key shortcut, so you can skip the palette altogether: **R**
  for a square, **O** a circle, **D** a diamond, **T** text, **A** an arrow, **F** a frame and **N**
  a sticky note. Hold **⌘** (Ctrl on Windows) to see each tile's shortcut on the palette. See
  [Keyboard Shortcuts](/help/tips-and-tricks/keyboard-shortcuts/).
</Tip>
