The palette's **Tools** tab gathers the elements that are not plain shapes. It opens on a grid of **categories** — one tile each for **Write &amp; Draw**, **Structure**, **Blocks**, and **People &amp; Media**. (**Behaviour** and **Data** used to live here; each is now its own palette category, one click away in the category picker.) Click a category to see its tools; a **breadcrumb** at the top ("‹ Tools › Write &amp; Draw") tells you where you are and takes you back in one click. Hovering a category tile describes what is inside it.

Not sure which category holds the tool you're after? A **search box** sits above the navigation, just like the one on the Icons tab: type a name ("table", "chart", "pencil") and the categories give way to a single grid of every matching tool. Clear the search to return to where you were.

## The categories

**Write &amp; Draw** holds everything you put down yourself. The wordy elements: **Text** drops a free-standing label, **Sticky Note** is a coloured note card, and **Annotation** is a small note marker for callouts. And the gesture tools: **Pencil** lets you sketch freehand, with an optional shape-recognition mode; **Highlighter** lays a wide translucent marker stroke for calling attention to things; **Polygon** places straight-edged outlines point by point; and **Arrow** drops a plain connector you can position by hand.

**Structure** is for organising: **Table** is an editable grid of cells, **Frame** is a labelled container you group work inside, and **Timeline Rail** is a horizontal track for sequencing events.

**Blocks** holds the rich content cards: **Code Block** is a dark monospace card for syntax-highlighted snippets, **Checklist** is a card of tickable to-do rows, and **Link Card** is a clickable preview of a URL.

**Behaviour** is no longer one of these categories — the elements that _do_ something when somebody interacts with them (Selection Mode buttons, Portals, Session buttons, Reveal zones, and Pickers) are their own palette category now. See [Behaviour Elements](/help/palette/behaviour/).

**Data** likewise: the charts and meters are their own category. See [Data and Chart Elements](/help/palette/tools/data-elements/).

**People &amp; Media** covers pictures and figures: **Image** places an uploaded picture, **Avatar** places a circular image, and **User** places an actor figure, both handy for people in a flow.

Each behaves like any other element once placed: select, restyle, group, and move it freely.

## Guides in this tab

Several tools have their own walkthroughs, listed below and linked here:

- [Drawing and Sketch](/help/palette/tools/drawing/) covers the Pencil, Highlighter, and Polygon tools, plus shape recognition.
- [Images](/help/palette/tools/images/) covers uploading and placing pictures, avatars, and user figures.
- [Tables](/help/palette/tools/tables/) covers the editable grid: adding one, filling cells, and rows/columns.
- [Sticky Notes](/help/palette/tools/sticky-notes/) covers the coloured note card for short annotations.
- [Code Blocks](/help/palette/tools/code-blocks/) covers the dark monospace card for syntax-highlighted snippets.
- [Checklists](/help/palette/tools/checklists/) covers the card of checkable to-do rows you tick on the canvas.
- [Portals](/help/palette/tools/portals/) covers linking two portals and travelling between them, including across tabs.
- [Data and Chart Elements](/help/palette/tools/data-elements/) covers the **Data** category: Pie Chart, Bar Chart, Line Chart, Progress Bar, Progress Ring (a donut meter), and Rating (stars).
- [Behaviour Elements](/help/palette/behaviour/) covers the **Behaviour** category: Selection Mode buttons, Portals, Session buttons, Reveal zones, and Pickers.

The **Arrow** tool lives here too, but arrows are deep enough to deserve their own guide: see [Arrows](/help/palette/arrows/).
