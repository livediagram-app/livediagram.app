Keyboard shortcuts let you switch tools and run common actions without reaching for the palette. The main canvas tools sit on single keys, so you can move between selecting, panning, and pointing in a single tap, and the built-in shortcut reference in Settings lists everything in one place. `⌘` below is the Command key on a Mac; on Windows and Linux use Ctrl.

## The shortcut reference

Run **Keyboard Shortcuts** from [search](/help/search-panel/) (`⌘K`) and [Settings](/help/user-interface/settings/) opens on its **Keyboard** category. Below the on/off switch, **All Shortcuts** lists every binding the editor knows, in collapsible groups by purpose, so you never have to memorise the full set. You can also get there yourself: open **Settings** from the gear in the editor's bottom bar and pick **Keyboard**.

The most useful canvas-tool keys are:

- `V` to **Select** (the default on desktop), with `S` kept working as a legacy alias where the [palette strip](/help/palette/toolbar-layout/)'s **Search** isn't shown; where it is, `S` opens Search.
- `H` for the **Hand** (pan) tool, the default on touch viewports.
- `F` to draw a **Frame**, the section backdrop that carries what you draw inside it.
- `Z` to toggle [Zen mode](/help/tools/zen-mode/) on and off. `Escape` exits it too, once nothing is selected (the first press clears the selection).

One more switches mode rather than tool, and has an article of its own: `I` for [Isometric mode](/help/selection-modes/isometric-mode/) (hold Shift and drag to rotate its camera).

The reference in Settings stays available in every role. On a view-only link, only the keys that change nothing still work: `V` (or `S` or `1`), `H`, `I` and `Z`, zoom and zoom to fit, search, `Tab` to step through elements, and `Escape`. Everything that edits is switched off. A [Participant](/help/collaboration/sharing/) sits in between: they can type into labels, delete, undo and redo, but the tool keys that add elements stay off, and so do copy, cut, duplicate, select all, lock, layer order and nudging.

## Editing shortcuts

These are the chords that edit the selection.

| Keys           | Does                                                          |
| -------------- | ------------------------------------------------------------- |
| `⌘Z`           | Undo                                                          |
| `⌘⇧Z`          | Redo (Ctrl Y works too)                                       |
| `⌘X`           | Cut the selection                                             |
| `⌘C`           | Copy the selection                                            |
| `⌘V`           | Paste, offset from the original                               |
| `⌘D`           | Duplicate the selection, offset                               |
| `⌘⇧L`          | Lock or unlock the selection                                  |
| `⌘A`           | Select everything on the tab (hidden and locked layers aside) |
| `Delete` / `⌫` | Delete the selection                                          |
| `⌘⇧]` / `⌘⇧[`  | Bring to front / send to back                                 |

**Cut, copy and paste use your operating system's clipboard**, not a private one, so a selection copied on one tab pastes onto another, into a different document, or into a second browser window. A paste lands offset from the original rather than exactly on top of it, so you can see what arrived, and arrows between copied elements come along and reconnect to the copies.

## Moving around and selecting

| Keys            | Does                                                                                                                                            |
| --------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| `⌘K`            | Open search and commands (`⌘.` does the same)                                                                                                   |
| `⌘+` / `⌘-`     | Zoom in / out                                                                                                                                   |
| `⌘0`            | Reset the zoom to 100%                                                                                                                          |
| `⇧1`            | Zoom to fit everything on the tab                                                                                                               |
| `Tab`           | Select the next element while the canvas has focus (Shift for the previous one)                                                                 |
| `F6`            | Move to the next part of the editor: header, palette, canvas, controls, tabs (Shift for the previous one)                                       |
| `Tab` / `Enter` | On a [mind map](/help/palette/mind-maps/) node or a flowchart step you picked: add a child / a sibling (a node the `Tab` walk reached walks on) |
| Arrow keys      | Nudge the selection 1px, or 10px with Shift                                                                                                     |
| `⇧` + click     | Add an element to the selection, or take it out                                                                                                 |
| `⇧` + drag      | Drop a duplicate (the original stays put)                                                                                                       |
| `Space` + drag  | Pan the canvas whatever tool you are holding                                                                                                    |
| `Space`         | Edit the selected element's label                                                                                                               |
| Just type       | Replace the selected element's label                                                                                                            |
| `Escape`        | Cancel the current mode, or clear the selection                                                                                                 |
| Hold `⌘`        | Show each palette tile's shortcut badge                                                                                                         |

## Keys that place an element

The rest of the letters pick up an element, ready to place: click the canvas to drop it at its default size, or drag to draw it to the size you want. A diagram can be built without visiting the palette at all:

- `R` a **square**, `O` a **circle**, `D` a **diamond**, `C` a **cylinder**, `G` a **parallelogram**.
- `A` an **arrow**, `T` a **text** label, `N` a **sticky note**.

## The number row

The main tools also sit on a digit, along the top of the keyboard:

| Key | Tool    | Key | Tool   |
| --- | ------- | --- | ------ |
| `1` | Select  | `4` | Circle |
| `2` | Square  | `5` | Arrow  |
| `3` | Diamond | `8` | Text   |

The digits are deliberately laid out to mirror Excalidraw's tool row, so if you have that muscle memory it carries straight over. `6`, `7`, `9` and `0` pick nothing.


The chords (undo, copy, zoom and the rest) are the same in every mode. While a [Plan](/help/canvas/plan-mode/) board fills the canvas, the tool keys and the chords that act on canvas elements (`⌘D`, `⌘A`, lock, front and back, zoom) stand down; undo, redo, search and Zen still work.

## Hold Shift for the power moves

Shift is the editor's power modifier. While you hold it, a small hint bar near the top of the canvas names what Shift is doing right then, so these are easy to discover:

- **Shift-click elements** to build a [multi-selection](/help/canvas/selecting-and-grouping/multi-select/); Shift-click again to remove one.
- **Shift-click table cells** to select several cells and style or clear them together.
- **Shift while resizing** an element (or drawing one to size) locks its proportions.
- **Shift while move-dragging a selection** drops a duplicate: the originals stay put, a translucent ghost follows your cursor, and the copy lands where you release, connected arrows included, all in one undo step.
- **Shift while placing a quick-connect arrow** chains the next arrow from the same source, so a hub fans out in one flow.
- **Shift-drag a selected arrow's head** splits a branch off its line, one trunk pointing at several targets. See [Arrows](/help/palette/arrows/).
- **Shift + arrow keys** nudge the selection in big (10px) steps.

## Turning shortcuts off

Shortcuts are handy, but they are not for everyone: if you dictate into the browser, or share it with something that needs the keys, they get in the way. You can switch them off with the **Keyboard Shortcuts** switch at the top of the **Keyboard** category in **Settings**: open **Settings** from the gear in the editor's bottom bar, pick **Keyboard**, and flip the switch.

<Figure caption="Flip the Keyboard Shortcuts switch in Settings so a stray key press never changes your tool.">
  <ShortcutsToggle />
</Figure>

Turning them off switches off the editor's shortcuts, not just the single letters: the tool keys, `Delete`, `Escape`, and the chords such as `⌘Z` and `⌘C` all stop, and the browser's own behaviour for those keys comes back. A few keep working because they are part of how the canvas is driven rather than shortcuts: pasting with `⌘V` (it goes through the browser's own paste), `Space` + drag to pan, and holding `⌘` to show the palette's badges. Use the on-screen controls (undo and redo sit in the bottom-right corner) while they are off. This choice is saved in your browser and, unlike most preferences, deliberately stays per device rather than following you across sign-in: that way you can keep shortcuts on where you have a full keyboard and off on a device where you don't.

The editor is also careful about context: even with shortcuts on, typing into a text label or an input never triggers a tool key. A `z` typed into a label is just a `z`, never a jump into Zen mode.

<Tip>
  If a single key keeps switching your tool while you work, open **Settings** on the **Keyboard**
  category and flip the switch at the top to turn shortcuts off. You can turn them back on the
  moment you want the speed again.
</Tip>
