The timer time-boxes an activity for the whole room. Set it going and a clock pill appears at the top of the canvas for every participant, ticking in sync. It comes in two flavours: a **countdown** for "you have five minutes", and a **stopwatch** for "let us see how long this takes".

## Setting it up

The Timer lives in the tab's menu under **Collaborate**, beside Vote and Poll.

You can also put the timer **on the board**: a [session button](/help/palette/behaviour/session-buttons/) set to Timer counts down where it sits, carrying its own pause, resume and reset. It is the same timer as the pill, not a second one, which is what lets a template ship its own running order.

<Step n={1}>
  Choose **Countdown** or **Stopwatch**. For a countdown, set the length by dragging the handle
  round the dial (the coloured wedge is the time; one lap is an hour), tapping a preset (1, 3, 5,
  10, 15, or 30 minutes), or using the **−** and **+** buttons for a minute at a time, up to two
  hours. The dial also takes the arrow keys.
</Step>

<Step n={2}>
  Press **Start** to begin. While it runs the dial becomes the clock, the wedge shrinking as time
  goes, and underneath it you can **Pause** and **Resume**, **Reset** back to the start, or **End**
  the timer altogether. A countdown also offers **+30s**, **+1 min**, and **+5 min** to give the
  room a little longer without starting over, and **Again** once it reaches zero.
</Step>

The wedge turns amber in the last minute and red at zero, so the dial reads at a glance. A tab runs one timer at a time: while one exists the panel shows it rather than the set-up, and you end it to start a different kind. The timer is scoped to the tab, so each tab can have its own. Because it syncs like everything else, anyone who joins late or reloads sees the current time straight away rather than a fresh clock.

## What everyone sees

The live clock shows as a floating pill near the top of the canvas, ticking smoothly while it runs. A countdown also **drains**: the pill starts fully tinted and empties from left to right as the time goes, so someone across the room can read how long is left without parsing the digits. It **flashes when it reaches 0:00** so the room knows time is up. A stopwatch has no end to work towards, so it gets no fill. People with edit access get inline pause, resume, and reset controls on the pill itself; view-only visitors see the same clock as a read-only display.

The pill sits in the shared top row of floating controls, alongside things like mode banners and the selection toolbar, so it never overlaps them: to the right of them on desktop, and underneath on mobile.

## How it stays in sync

Rather than sending a tick across the network every second, each participant's clock works out the time locally from a shared anchor point: the moment a countdown will end, or the instant a stopwatch started. Everyone computes the same value from that anchor, so the clock stays in step without constant network chatter. Pausing freezes the value, and resuming re-anchors it.

<Note>
  The clock is shared but not second-perfect across machines: tiny differences in device clocks are
  fine for a workshop timer. It is there to keep the room roughly together, not to referee a
  stopwatch race.
</Note>
