# Import and export blueprint defaults

One row per default applied where a spec is silent or qualitative.

| #   | Blueprint             | Spec silence                                                                   | Default applied                                                                                                                                                                                 |
| --- | --------------------- | ------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| D1  | import-image-pipeline | Order of the failure names                                                     | The order of `ImportImageFailure`: file problems, then limits, then transport                                                                                                                   |
| D2  | import-image-pipeline | Quality of the JPEG fallback                                                   | `0.85`, the same as WebP                                                                                                                                                                        |
| D3  | import-image-pipeline | Whitespace inside a base64 `data:` payload                                     | Stripped before decoding (hand-edited files wrap lines)                                                                                                                                         |
| D4  | import-image-pipeline | How an SVG is recognised without a declared type                               | `<svg` within the first 1 KB decoded as UTF-8                                                                                                                                                   |
| D5  | import-image-pipeline | Whether a refused offline image spends the budget                              | It does not; a smaller later image may still fit                                                                                                                                                |
| D11 | import-image-pipeline | How long WebP support is known                                                 | For the page: the first canvas answer decides; `null` answers decide nothing                                                                                                                    |
| D12 | import-image-pipeline | Whether a failed WASM load is remembered                                       | It is not; the next image tries again (a flaky network should not cost the import)                                                                                                              |
| D13 | import-image-pipeline | How to prove the Safari path where WebKit has WebP                             | The test makes the canvas answer WebP with PNG, which is what Safari does                                                                                                                       |
| D60 | office-import         | How much compressed input the inflater takes at a time                         | 16 KB, so one write can unpack at most ~16.5 MB (deflate's 1032:1) before the count is checked                                                                                                  |
| D61 | office-import         | How long a slide's imported notes may be                                       | 20,000 characters, an article block's own cap                                                                                                                                                   |
| D62 | office-import         | ZIP64 packages                                                                 | Refused as not a package: a file under the 50 MB cap never needs ZIP64                                                                                                                          |
| D63 | office-import         | A list level the numbering part does not define                                | Bulleted                                                                                                                                                                                        |
| D64 | office-import         | Which fonts make a run code                                                    | Any font named with "mono", or Courier, Courier New, Consolas, Monaco, Menlo, Lucida Console, Inconsolata, Source Code Pro, Fira Code, Andale Mono, Cascadia Code                               |
| D65 | office-import         | A slide shape with no box on the slide, its layout or its master               | Left out, uncounted (PowerPoint draws it nowhere either)                                                                                                                                        |
| D66 | office-import         | Where an imported article's zones stand before the editor lays the writing out | Parked in non-overlapping slots left of the first page, each image exactly in its zone; the first layout settles them                                                                           |
| D69 | office-export         | The deck's slide size when its pages differ                                    | The first page's shape; any other page is fitted inside it by one factor, centred                                                                                                               |
| D70 | office-export         | How much of an element's surroundings its picture takes                        | 4 px a side (strokes and antialiasing), 16 px for an arrow (its heads and label), its shadow's reach; then cut to the page                                                                      |
| D71 | office-export         | The resolution of the pictures                                                 | Twice the page's for an element or a zone, as a PNG (it may be see-through); the page's own for a background picture, as a JPEG at 0.9 (it is opaque), stored once however many slides share it |
| D72 | office-export         | Word's page colour and ink when the article's page is dark                     | White paper, slate-800 ink and slate-500 muted text; the accent made legible on white (`legibleOn`)                                                                                             |
| D73 | office-export         | An empty heading or an empty title, subtitle or quote                          | Left out; an empty body paragraph stays (it is a blank line on the page)                                                                                                                        |
| D74 | office-export         | When a numbered list starts again at 1                                         | After any block that is not a list item, and after a top-level bulleted or to-do item; an item nested deeper keeps the run going                                                                |
| D75 | office-export         | How a to-do item looks in Word                                                 | A list paragraph led by ☐, or ☒ with its text struck through and muted (slate-500) when done                                                                                                    |
| D76 | office-export         | Which font name the file carries                                               | The face's first family name from its CSS stack (`fontFaceName`); an app without it substitutes its own                                                                                         |
| D67 | office-import         | A deck with no slides                                                          | One empty slide page, as an empty document is one empty paragraph                                                                                                                               |
| D68 | office-import         | The Import dialog closed while an import is still running                      | The import finishes and replaces the tab; Undo still brings the old content back                                                                                                                |
| D77 | knowledgebase-import  | The most one page's source file may weigh                                      | 5 MB (`MAX_PAGE_SOURCE_BYTES`); the page is skipped and listed                                                                                                                                  |
| D78 | knowledgebase-import  | The most files an archive may list                                             | 20,000 (`MAX_ARCHIVE_ENTRIES`), so the listing stays small whatever the archive claims; past it the plan is blocked as too large                                                                |
| D79 | knowledgebase-import  | The heading a Notion toggle becomes                                            | The smallest, `###`                                                                                                                                                                             |
| D80 | knowledgebase-import  | How a nested list from Confluence is indented                                  | Four spaces a level, which reads as nested under both `-` and `1.` items                                                                                                                        |
| D81 | knowledgebase-import  | A line break (`br`) in Confluence's writing                                    | A space                                                                                                                                                                                         |
| D82 | knowledgebase-import  | The CPU budget of planning 500 pages with 50 links each                        | 400 ms (measured 84 ms), three times that on CI                                                                                                                                                 |
| D83 | knowledgebase-import  | Which destination is chosen first                                              | A New Knowledgebase: nothing of the open one changes until a page of it is picked                                                                                                               |
| D84 | knowledgebase-import  | What a new knowledgebase is called and where it is kept                        | The folder's or the file's name; where the open one is kept (its team library, or Offline)                                                                                                      |
| D85 | knowledgebase-import  | How many pages the review's tree lists                                         | 12 (`PLAN_PREVIEW_ROWS`), then "and <n> more"                                                                                                                                                   |
| D86 | knowledgebase-import  | How many of a kind of issue are named                                          | 5 (`ISSUE_EXAMPLES`); 20 failed pages or pictures in the summary (`DONE_LIST_ROWS`)                                                                                                             |
| D87 | knowledgebase-import  | How long a batch waits to be stored                                            | 60 s (`IMPORT_SAVE_WAIT_MS`), then the import stops and says saving stalled                                                                                                                     |
| D88 | knowledgebase-import  | Pages of a new knowledgebase saved at once                                     | 4 (`IMPORT_SAVE_CONCURRENCY`), parents before their subpages                                                                                                                                    |
| D89 | knowledgebase-import  | How long a page's save waits for its parent's first save                       | 15 s (`PARENT_SAVE_WAIT_MS`), then it is sent anyway                                                                                                                                            |
| D90 | knowledgebase-import  | Where a picture written inside other writing goes                              | After that block, as a zone of its own                                                                                                                                                          |
| D91 | knowledgebase-import  | What a link to a page that failed reads as                                     | Its words, with no address                                                                                                                                                                      |
| D92 | knowledgebase-import  | The CPU budget of writing 500 pages with 50 links each                         | 800 ms (measured 152 ms cold, 75 ms warm), three times that on CI                                                                                                                               |
| D93 | knowledgebase-import  | A folder that is picked or dropped                                             | The archive's root: its own name leaves every path                                                                                                                                              |
